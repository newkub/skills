# SonarQube vs CodeClimate

## เปรียบเทียบ

| หัวข้อ | SonarQube | CodeClimate |
|--------|-----------|-------------|
| **Scope** | Full code analysis | PR-focused |
| **Self-hosted** | Yes (Community) | Cloud only |
| **Languages** | 25+ languages | Popular languages |
| **Security** | SAST, vulnerabilities | Basic |
| **Coverage** | Built-in integration | External config |
| **Technical Debt** | Detailed tracking | Simplified |
| **On-premise** | Enterprise edition | No |
| **CI Integration** | Scanner | GitHub integration |
| **Cost** | Free self-hosted | Freemium SaaS |
| **Best For** | Enterprise, compliance | Open source, GitHub |

## เมื่อไหร่ใช้อะไร

- **SonarQube**: Full coverage, compliance, self-hosted needs
- **CodeClimate**: GitHub open source, quick PR checks
