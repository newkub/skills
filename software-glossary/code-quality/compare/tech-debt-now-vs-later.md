# Technical Debt: Pay Now vs Pay Later

## เปรียบเทียบ

| หัวข้อ | Pay Now (Refactor) | Pay Later (Ship) |
|--------|--------------------|------------------|
| **Speed** | Slower delivery | Faster to market |
| **Quality** | Clean, maintainable | Working but messy |
| **Future Cost** | Lower | Accumulates interest |
| **Risk** | Delayed features | Code collapse |
| **Morale** | Pride in craft | Velocity guilt |
| **Stakeholder View** | "Why so slow?" | "Ship it!" |
| **Measurement** | Code metrics | Feature velocity |
| **Timing** | Continuous | Deadlines first |
| **Bankruptcy** | Avoided | Sometimes acceptable |
| **Best For** | Foundation, scale | MVP, experiment |

## เมื่อไหร่ใช้อะไร

- **Pay Now**: Core systems, long-term ownership, scale preparation
- **Pay Later**: Experiments, MVPs, competitive pressure, pivots
