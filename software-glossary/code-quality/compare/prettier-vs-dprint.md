# Prettier vs dprint

## เปรียบเทียบ

| หัวข้อ | Prettier | dprint |
|--------|----------|--------|
| **Speed** | Standard | 10x faster (Rust) |
| **Languages** | Web-focused | Multi-language |
| **Config** | Opinionated, limited | Pluggable, configurable |
| **Plugins** | Few | Extensive ecosystem |
| **Maturity** | 2017, proven | 2020, growing |
| **Adoption** | Standard | Niche |
| **Migration** | Drop-in | Requires config |
| **CI Speed** | Acceptable | Fast |
| **Best For** | Web projects, standardization | Speed, multiple languages |
| **Together** | With ESLint | With Biome |

## เมื่อไหร่ใช้อะไร

- **Prettier**: Web development, universal standard, ecosystem
- **dprint**: Performance critical, multiple languages, flexibility
