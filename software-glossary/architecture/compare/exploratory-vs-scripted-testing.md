# Exploratory vs Scripted Testing

## เปรียบเทียบ

| หัวข้อ | Exploratory Testing | Scripted Testing |
|--------|--------------------|------------------|
| **Approach** | Simultaneous learning/test | Predefined steps |
| **Creativity** | High, tester-driven | Low, script-bound |
| **Documentation** | Session notes | Test cases |
| **Coverage** | Risk-based, deep | Breadth, repeatable |
| **Time** | Unstructured | Scheduled, estimated |
| **Skill Required** | Expert domain knowledge | Follow instructions |
| **Automation** | Cannot automate | Automatable |
| **Bugs Found** | Unexpected edge cases | Known scenario checks |
| **Regression** | Not suitable | Perfect for regression |
| **Best For** | New features, UX | Smoke tests, compliance |

## เมื่อไหร่ใช้อะไร

- **Exploratory**: New features, UX evaluation, edge case discovery
- **Scripted**: Regression suites, compliance, repeatable validation
