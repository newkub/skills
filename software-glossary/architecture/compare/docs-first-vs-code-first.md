# Documentation First vs Code First

## เปรียบเทียบ

| หัวข้อ | Documentation First | Code First |
|--------|---------------------|------------|
| **Approach** | Design, then build | Build, then document |
| **Clarity** | Requirements clear early | Discovery through coding |
| **Pivot Cost** | Low (paper changes) | High (code changes) |
| **Stakeholder Alignment** | Before coding | After MVP |
| **Speed** | Slower start | Faster start |
| **Quality** | Fewer rewrites | Iterative refinement |
| **Remote Work** | Essential | Tolerable |
| **Use Case** | APIs, complex systems | MVPs, internal tools |
| **Tools** | RFCs, ADRs, wiki | Comments, READMEs |
| **Review** | Doc review before code | Code review includes docs |

## เมื่อไหร่ใช้อะไร

- **Documentation First**: Public APIs, distributed systems, compliance
- **Code First**: Startups, prototypes, rapid experimentation
