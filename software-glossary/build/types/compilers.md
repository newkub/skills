# Compilers

## คำอธิบาย
เครื่องมือที่แปลงโค้ดจากภาษาหนึ่งไปเป็นอีกภาษาหนึ่ง (เช่น TypeScript → JavaScript)

## ลักษณะเฉพาะ
- **Source Maps**:  map โค้ดที่ compile กลับไปหา source
- **Type Checking**: ตรวจสอบ types ก่อน compile
- **Code Generation**: สร้างโค้ดเป้าหมาย
- **Optimization**: ปรับปรุงประสิทธิภาพโค้ด

## ประเภทของ Compilers
- **TypeScript Compiler**: tsc
- **Babel**: JavaScript transpiler
- **SWC**: Rust-based compiler
- **esbuild**: Go-based bundler/compiler

## ข้อดี
- Type safety
- Modern language features
- Better error detection
- Code optimization

## ข้อเสีย
- Build time overhead
- Configuration complexity
- Debugging complexity
- Learning curve

## เหมาะกับ
- TypeScript projects
- Modern JavaScript features
- Large applications
- Type-safe development
