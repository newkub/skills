# Bundlers

## คำอธิบาย
เครื่องมือที่รวบรวมไฟล์ JavaScript และ assets หลายๆ ไฟล์เป็นไฟล์เดียวที่ optimized แล้ว

## ลักษณะเฉพาะ
- **Code Splitting**: แบ่งโค้ดเป็น chunks
- **Tree Shaking**: ลบโค้ดที่ไม่ได้ใช้
- **Minification**: ลดขนาดไฟล์
- **Asset Optimization**: ปรับแต่งรูปภาพและ assets

## ประเภทของ Bundlers
- **JavaScript Bundlers**: Webpack, Rollup, Parcel
- **Module Bundlers**: esbuild, SWC
- **Asset Bundlers**: Vite, Snowpack

## ข้อดี
- Reduced file size
- Faster loading times
- Better caching
- Code organization

## ข้อเสีย
- Build complexity
- Configuration overhead
- Debugging challenges
- Build time

## เหมาะกับ
- Web applications
- SPAs (Single Page Applications)
- Large codebases
- Performance-critical apps
