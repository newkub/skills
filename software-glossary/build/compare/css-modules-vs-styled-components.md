# CSS Modules vs Styled Components

## เปรียบเทียบ

| หัวข้อ | CSS Modules | Styled Components |
|--------|-------------|-------------------|
| **Scope** | File-scoped CSS | Component-scoped |
| **Syntax** | Standard CSS | CSS-in-JS template |
| **Runtime** | Zero overhead | Small runtime |
| **Dynamic** | Limited | Props-based |
| **Tree Shaking** | With build tools | Natural with JS |
| **SSR** | Easy | Setup required |
| **Testing** | Snapshot CSS | Component snapshot |
| **Learning** | CSS knowledge | JS + CSS |
| **Best For** | CSS teams, static | React, dynamic styles |
| **Tooling** | Wide support | Babel plugin |

## เมื่อไหร่ใช้อะไร

- **CSS Modules**: CSS-first teams, performance, existing CSS
- **Styled Components**: React focus, dynamic theming, component logic
