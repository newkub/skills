# Babel vs SWC

## เปรียบเทียบ

| หัวข้อ | Babel | SWC |
|--------|-------|-----|
| **Speed** | Slower (JS) | 20x faster (Rust) |
| **Config** | Extensive presets | Minimal |
| **Plugins** | Massive ecosystem | Growing |
| **TypeScript** | Via preset | Native |
| **Minification** | Via plugin | Built-in |
| **Module System** | Flexible | ESM/CJS |
| **Maturity** | 2014, proven | 2020, modern |
| **Tooling** | Universal | Next.js, Vite |
| **Compatibility** | Maximum | Modern browsers |
| **Best For** | Legacy support, custom plugins | Speed, modern apps |

## เมื่อไหร่ใช้อะไร

- **Babel**: Legacy browser support, custom transformations, existing projects
- **SWC**: Performance critical, modern toolchains, new projects
