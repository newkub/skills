# npm vs Bun

## เปรียบเทียบ

| หัวข้อ | npm | Bun |
|--------|-----|-----|
| **Speed** | Baseline | 4x faster install |
| **Runtime** | Node.js only | Node.js compatible |
| **TypeScript** | Requires transpilation | Native support |
| **Bundling** | External tools | Built-in |
| **Testing** | Jest, Vitest | Built-in test runner |
| **Package Manager** | Separate install | All-in-one |
| **Maturity** | Battle-tested | 2022, emerging |
| **Ecosystem** | Universal | Growing |
| **Migration** | Default | Drop-in replacement |
| **Best For** | Stability, universal | Performance, modern |

## เมื่อไหร่ใช้อะไร

- **npm**: Production stability, maximum compatibility
- **Bun**: Development speed, modern tooling, performance
