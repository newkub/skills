# Lerna vs Changesets

## เปรียบเทียบ

| หัวข้อ | Lerna | Changesets |
|--------|-------|------------|
| **Purpose** | Monorepo management | Version/changelog management |
| **Versioning** | Fixed or independent | Changeset-based |
| **Changelog** | Auto-generated | Human-written summaries |
| **Publishing** | Automated | CI-triggered |
| **Maturity** | 2015, legacy | 2019, modern |
| **Maintenance** | Reduced focus | Active development |
| **Scope** | Full monorepo | Release management only |
| **Integration** | npm/yarn/pnpm | pnpm, Yarn, npm workspaces |
| **Migration** | From nothing | From Lerna or new |
| **Best For** | Legacy monorepos | Modern release management |

## เมื่อไหร่ใช้อะไร

- **Lerna**: Existing Lerna repos, full monorepo orchestration
- **Changesets**: Modern monorepos, changelogs, release automation
