# Webpack vs Vite

## เปรียบเทียบ

| หัวข้อ | Webpack | Vite |
|--------|---------|------|
| **Build Speed** | Slower | Faster (ESM) |
| **Dev Server** | Bundle on change | Native ESM, HMR |
| **Config** | Extensive | Minimal/zero |
| **Ecosystem** | Mature, plugins | Growing, modern |
| **Production** | Optimized bundles | Rollup-based |
| **Learning Curve** | Steep | Gentle |
| **Legacy** | 2012, battle-tested | 2020, modern |
| **HMR** | Implemented | Lightning fast |
| **Use Case** | Complex apps | Modern development |
| **Migration** | From nothing | From Webpack/CRA |

## เมื่อไหร่ใช้อะไร

- **Webpack**: Complex builds, legacy support, fine-grained control
- **Vite**: Modern projects, fast dev, quick prototyping
