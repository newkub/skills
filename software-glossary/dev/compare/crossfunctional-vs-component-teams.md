# Cross-Functional Teams vs Component Teams

## เปรียบเทียบ

| หัวข้อ | Cross-Functional Teams | Component Teams |
|--------|------------------------|-----------------|
| **Skills** | All disciplines included | Single specialty |
| **Ownership** | End-to-end feature | Component/Layer |
| **Dependencies** | Few external | Handoffs required |
| **Delivery** | Vertical slices | Horizontal progress |
| **Context** | Full user journey | Narrow expertise |
| **Communication** | Internal alignment | Cross-team coordination |
| **Growth** | T-shaped skills | I-shaped deep expertise |
| **Scalability** | Team autonomy challenges | Component scaling |
| **Handoffs** | Minimal | Frequent |
| **Best For** | Product development, agility | Platform, infrastructure |

## เมื่อไหร่ใช้อะไร

- **Cross-Functional**: Product features, customer value, agility needed
- **Component**: Platforms, specialized infrastructure, deep expertise
