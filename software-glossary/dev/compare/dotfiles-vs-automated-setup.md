# Dotfiles vs Automated Setup

## เปรียบเทียบ

| หัวข้อ | Dotfiles Repo | Automated Setup |
|--------|---------------|-----------------|
| **Approach** | Manual config files | Scripted installation |
| **Version Control** | Git-tracked configs | Scripts + configs |
| **Reproducibility** | Copy, symlink | One command |
| **Customization** | Per-machine tweaking | Standardized |
| **Tools** | Stow, bare repo | Ansible, Chezmoi |
| **Learning** | Understanding configs | Following scripts |
| **Sharing** | GitHub templates | Installer scripts |
| **Maintenance** | Manual updates | Automated sync |
| **Complexity** | Simple, transparent | Depends on tool |
| **Best For** | Personal customization | Team consistency |

## เมื่อไหร่ใช้อะไร

- **Dotfiles**: Personal machines, learning, fine control
- **Automated Setup**: New machines, teams, standardization
