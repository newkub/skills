# Pair Programming vs Code Review

## เปรียบเทียบ

| หัวข้อ | Pair Programming | Code Review |
|--------|------------------|-------------|
| **Timing** | Real-time while coding | After code complete |
| **Feedback Speed** | Immediate | Hours to days |
| **Knowledge Transfer** | Deep, continuous | Transfer at handoff |
| **Cost** | 2x dev time during coding | Async, parallelized |
| **Quality Gate** | Continuous | Checkpoint |
| **Social** | High collaboration | Lower interaction |
| **Learning** | Mentor in real-time | Feedback post-hoc |
| **Focus** | Shared attention | Reviewer context switch |
| **Rework** | Minimal | Can be significant |
| **Best For** | Complex logic, training | Async teams, standard flow |

## เมื่อไหร่ใช้อะไร

- **Pair Programming**: Complex architecture, onboarding, critical code
- **Code Review**: Daily workflow, async teams, scalable process
