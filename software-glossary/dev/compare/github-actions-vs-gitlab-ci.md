# GitHub Actions vs GitLab CI

## เปรียบเทียบ

| หัวข้อ | GitHub Actions | GitLab CI |
|--------|----------------|-----------|
| **Integration** | GitHub native | GitLab native |
| **Marketplace** | 20,000+ actions | Limited templates |
| **Pricing** | Minutes-based | Minutes-based |
| **Self-hosted** | Runners available | Self-hosted free |
| **Config** | .github/workflows | .gitlab-ci.yml |
| **Visibility** | Workflow visualization | Pipeline graph |
| **Security** | OIDC, secrets | Built-in vault |
| **Community** | Larger | Active |
| **Multi-platform** | Ubuntu, macOS, Windows | Docker-based |
| **Best For** | GitHub users, marketplace | GitLab users, self-hosted |

## เมื่อไหร่ใช้อะไร

- **GitHub Actions**: GitHub repos, marketplace actions, community
- **GitLab CI**: GitLab repos, self-hosted, integrated DevOps
