# Git vs Mercurial

## เปรียบเทียบ

| หัวข้อ | Git | Mercurial |
|--------|-----|-----------|
| **Popularity** | Dominant | Niche |
| **Branching** | Lightweight, fast | Named branches |
| **Learning Curve** | Steep | Gentle |
| **Interface** | Complex commands | Simpler UX |
| **Ecosystem** | Massive (GitHub, GitLab) | Smaller (Bitbucket) |
| **Rewriting History** | Easy (rebase) | Harder |
| **Extensions** | Hooks, filters | Built-in extensions |
| **Windows** | Good (MSYS2, WSL) | Native, better |
| **Use Case** | Open source, enterprise | Small teams, simplicity |
| **Philosophy** | Powerful, sharp tools | Safe, approachable |

## เมื่อไหร่ใช้อะไร

- **Git**: Universal standard, collaboration, CI/CD
- **Mercurial**: Simplicity preference, Windows development
