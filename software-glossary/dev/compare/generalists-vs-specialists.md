# Generalists vs Specialists

## เปรียบเทียบ

| หัวข้อ | Generalists | Specialists |
|--------|-------------|-------------|
| **Skills** | Broad across stack | Deep in one domain |
| **Flexibility** | Adapt to any task | Limited scope |
| **Hiring** | Common, interchangeable | Rare, expensive |
| **Innovation** | Cross-pollination | Breakthrough expertise |
| **Efficiency** | Learning curve per task | Immediate high output |
| **Dependency** | Self-sufficient | Critical person risk |
| **Career Growth** | Management, architecture | Principal, distinguished |
| **Team Role** | Utility player | Key contributor |
| **Problem Solving** | Holistic approach | Optimized solutions |
| **Best For** | Startups, small teams | Scale, complex challenges |

## เมื่อไหร่ใช้อะไร

- **Generalists**: Early stage, resource constraints, rapid pivots
- **Specialists**: Scale challenges, performance optimization, compliance
