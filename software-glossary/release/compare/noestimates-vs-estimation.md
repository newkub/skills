# No Estimates vs Estimation

## เปรียบเทียบ

| หัวข้อ | #NoEstimates | Traditional Estimation |
|--------|--------------|------------------------|
| **Philosophy** | Estimates waste time | Estimates enable planning |
| **Focus** | Flow, cycle time | Forecasting, velocity |
| **Stakeholder Communication** | "It will be ready when ready" | "3 weeks, 5 sprints" |
| **Planning** | Based on history | Based on predictions |
| **Meeting Time** | Minimal estimation meetings | Sprint planning overhead |
| **Commitment** | Trust-based | Contract-based |
| **Scope Flexibility** | Scope adjusts to time | Time adjusts to scope |
| **Best For** | Maintenance, flow work | Client projects, deadlines |
| **Controversy** | Radical, debates | Standard practice |
| **Prerequisite** | Stable flow, mature team | Any maturity level |

## เมื่อไหร่ใช้อะไร

- **#NoEstimates**: Kanban teams, maintenance, continuous flow, trust culture
- **Estimation**: Client work, fixed budgets, deadline-driven, planning needs
