# Story Points vs Time Estimation

## เปรียบเทียบ

| หัวข้อ | Story Points | Time Estimation |
|--------|--------------|-----------------|
| **Unit** | Relative complexity (1,2,3,5,8) | Hours/Days |
| **Focus** | Effort + uncertainty | Calendar time |
| **Accuracy** | Team-specific | Often wrong |
| **Pressure** | Less individual blame | Deadline stress |
| **Velocity** | Predictable throughput | N/A |
| **Learning** | Team calibration | Individual pressure |
| **Scope Creep** | Points adjust | Hours extend |
| **Communication** | Abstract to stakeholders | Concrete expectations |
| **Change** | Points stable | Hours volatile |
| **Best For** | Software complexity | Known, repetitive tasks |

## เมื่อไหร่ใช้อะไร

- **Story Points**: Software development, unknown work, team metrics
- **Time Estimation**: Maintenance tasks, fixed scope, client billing
