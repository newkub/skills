# Planning Poker vs Relative Estimation

## เปรียบเทียบ

| หัวข้อ | Planning Poker | Relative Estimation |
|--------|----------------|---------------------|
| **Method** | Consensus-based voting | Compare to reference |
| **Discussion** | Open, all voices | Brief, expert-led |
| **Precision** | Fibonacci (1,2,3,5,8) | Buckets (S,M,L,XL) |
| **Time** | Longer, inclusive | Faster |
| **New Teams** | Good calibration | Needs baseline |
| **Veteran Teams** | Repetitive | Efficient |
| **Outliers** | Discuss and converge | Re-bucket |
| **Anchor Bias** | Moderated by facilitator | Reference story |
| **Tools** | Cards, apps, fingers | Wall, spreadsheet |
| **Best For** | Team building, complex items | Experienced teams |

## เมื่อไหร่ใช้อะไร

- **Planning Poker**: New teams, complex unknowns, consensus culture
- **Relative Estimation**: Experienced teams, speed, known domain
