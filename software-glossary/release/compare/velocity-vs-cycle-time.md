# Velocity vs Cycle Time

## เปรียบเทียบ

| หัวข้อ | Velocity | Cycle Time |
|--------|----------|------------|
| **Unit** | Story points per sprint | Days per work item |
| **Purpose** | Capacity planning | Flow efficiency |
| **Gamification** | Easy to game | Harder to manipulate |
| **Predictability** | Forecast future capacity | Predict delivery time |
| **Estimation** | Requires estimation | No estimation needed |
| **Focus** | Output volume | Time to value |
| **Trending** | Sprint over sprint | Item over item |
| **Actionable** | Plan sprints | Identify bottlenecks |
| **Kanban** | Not applicable | Core metric |
| **Scrum** | Primary metric | Secondary insight |

## เมื่อไหร่ใช้อะไร

- **Velocity**: Scrum planning, forecasting, capacity discussions
- **Cycle Time**: Flow optimization, bottlenecks, Kanban teams
