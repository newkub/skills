# Push System vs Pull System

## เปรียบเทียบ

| หัวข้อ | Push System (Assignment) | Pull System (Kanban) |
|--------|---------------------------|----------------------|
| **Work Assignment** | Manager assigns tasks | Team pulls when ready |
| **Queue** | Hidden backlog | Visible WIP limits |
| **Overwhelm** | Common (too much assigned) | Controlled (blocked by limits) |
| **Predictability** | Estimates, deadlines | Flow, cycle time |
| **Multitasking** | Encouraged | Discouraged |
| **Focus** | Context switching | Single piece flow |
| **Bottlenecks** | Hard to see | Visible immediately |
| **Autonomy** | Low (assigned) | High (self-directed) |
| **Best For** | Urgent deadlines, incidents | Sustainable pace, quality |
| **Metrics** | Utilization percentage | Lead time, throughput |

## เมื่อไหร่ใช้อะไร

- **Push**: Urgent work, incidents, time-sensitive delivery
- **Pull**: Sustainable development, flow optimization, knowledge work
