# Synchronous vs Asynchronous Meetings

## เปรียบเทียบ

| หัวข้อ | Synchronous Meetings | Asynchronous Updates |
|--------|----------------------|----------------------|
| **Timing** | Scheduled, real-time | Any time, self-paced |
| **Participation** | Everyone present | Read when convenient |
| **Decision Speed** | Immediate consensus | Delayed feedback |
| **Documentation** | Meeting notes | Written updates |
| **Timezone** | Requires overlap | Global friendly |
| **Preparation** | Minimal | Requires writing |
| **Deep Work** | Interrupts | Preserves focus |
| **Relationship** | Face-to-face bonding | Transactional |
| **Complexity** | Good for nuance | Good for clarity |
| **Best For** | Brainstorming, conflict | Status updates, reviews |

## เมื่อไหร่ใช้อะไร

- **Synchronous**: Complex decisions, team building, urgent issues
- **Asynchronous**: Status updates, timezone spread, focus preservation
