# Retrospectives vs Post-mortems

## เปรียบเทียบ

| หัวข้อ | Retrospectives | Post-mortems |
|--------|----------------|--------------|
| **Timing** | Regular (sprint end) | After incidents |
| **Focus** | Process improvement | Incident analysis |
| **Tone** | Forward-looking, positive | Root cause, blameless |
| **Frequency** | Weekly/bi-weekly | As needed |
| **Participants** | Full team | On-call + stakeholders |
| **Output** | Action items | Incident report |
| **Scope** | General process | Specific incident |
| **Urgency** | Planned | Urgent follow-up |
| **Tools** | Fun formats, boards | Timeline, 5 Whys |
| **Goal** | Continuous improvement | Prevent recurrence |

## เมื่อไหร่ใช้อะไร

- **Retrospectives**: Regular cadence, team health, process refinement
- **Post-mortems**: Outages, incidents, learning from failures
