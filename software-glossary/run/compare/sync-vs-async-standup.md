# Synchronous vs Asynchronous Standups

## เปรียบเทียบ

| หัวข้อ | Synchronous Standup | Asynchronous Standup |
|--------|---------------------|----------------------|
| **Format** | Live meeting | Written updates |
| **Timezones** | Requires overlap | Any timezone |
| **Duration** | Time-boxed 15 min | Self-paced reading |
| **Interaction** | Real-time Q&A | Delayed threads |
| **Documentation** | Meeting notes | Written record |
| **Distractions** | Context switching | Minimal interruption |
| **Social** | Face time, bonding | Transactional |
| **Blockers** | Immediate help | Delayed response |
| **Best For** | Co-located, team building | Remote, deep work focus |
| **Tools** | Zoom, in-person | Slack, Twist, Geekbot |

## เมื่อไหร่ใช้อะไร

- **Synchronous**: Team bonding, complex blockers, office culture
- **Asynchronous**: Distributed teams, focus time, timezone spread
