# Incident War Room vs Async Incident Response

## เปรียบเทียบ

| หัวข้อ | War Room (Sync) | Async Incident Response |
|--------|-----------------|-------------------------|
| **Format** | Video call/physical room | Slack threads, PagerDuty |
| **Response Time** | Immediate collaboration | Delayed coordination |
| **Timezone Impact** | Requires overlap | 24/7 distributed |
| **Documentation** | Scribe takes notes | Natural async trail |
| **Decision Speed** | Fast consensus | Slower, deliberate |
| **Stress Level** | High intensity | Lower sustained |
| **Communication** | Voice, screen share | Text, links, dashboards |
| **Best For** | Sev1 outages, complex | Sev2/3, known runbooks |
| **Follow-up** | Post-incident meeting | Thread summary |
| **Cost** | Interrupts multiple people | On-call rotation only |

## เมื่อไหร่ใช้อะไร

- **War Room**: Critical outages, unknown cause, all hands needed
- **Async**: Known issues, runbook-driven, distributed teams
