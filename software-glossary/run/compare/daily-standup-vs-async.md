# Daily Standup vs Async Updates

## เปรียบเทียบ

| หัวข้อ | Daily Standup (Sync) | Async Updates |
|--------|----------------------|---------------|
| **Format** | 15-min meeting | Written updates (Slack/Email) |
| **Timezone** | Requires overlap | Any timezone |
| **Documentation** | Verbal, ephemeral | Written, searchable |
| **Blocker Resolution** | Immediate | Delayed (hours) |
| **Team Bonding** | Daily face time | Limited |
| **Focus Cost** | Context switching | No interruption |
| **Preparation** | Minimal | Requires writing |
| **Transparency** | Who attends sees it | Everyone sees it |
| **Questions** | Real-time clarify | Thread-based |
| **Best For** | Co-located, tight teams | Distributed, deep work |

## เมื่อไหร่ใช้อะไร

- **Daily Standup**: Team building, rapid blocker clearing, office culture
- **Async Updates**: Remote-first, focus-driven, timezone distributed
