# Live Demo vs Recorded Demo

## เปรียบเทียบ

| หัวข้อ | Live Demo | Recorded Demo |
|--------|-----------|---------------|
| **Risk** | Technical failure | Pre-tested, reliable |
| **Interactivity** | Q&A real-time | Async comments |
| **Preparation** | Rehearsal needed | Editing needed |
| **Audience Size** | Small to medium | Unlimited |
| **Timezone** | Scheduled | On-demand |
| **Authenticity** | Genuine, impressive | Polished, perfect |
| **Feedback** | Immediate reactions | Delayed analytics |
| **Distribution** | Once | Reusable |
| **Pressure** | High performance | Relaxed recording |
| **Best For** | Client meetings, pitch | Documentation, training |

## เมื่อไหร่ใช้อะไร

- **Live Demo**: Sales, stakeholder buy-in, interactive exploration
- **Recorded Demo**: Documentation, tutorials, async sharing
