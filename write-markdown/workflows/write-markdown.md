# Write Markdown

Workflow สำหรับเขียนเอกสาร Markdown

## ขั้นตอน

1. **วางแผนโครงสร้าง**
   - ร่าง sections
   - จัดเรียง content
   - วางแผน formatting

2. **เขียนเนื้อหา**
   - ใช้ headers ที่ถูกต้อง
   - format text อย่างเหมาะสม
   - เพิ่ม code blocks
   - ใส่ links และ images

3. **ตรวจสอบและจัดรูปแบบ**
   - ตรวจสอบ syntax
   - ตรวจสอบ links
   - ให้มั่นใจว่า consistent
