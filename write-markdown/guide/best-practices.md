# Best Practices สำหรับ Markdown

## การใช้ Headers

- ใช้ H1 เพียงครั้งเดียวสำหรับ title หลัก
- ใช้ hierarchy ที่ชัดเจน อย่าข้ามระดับ
- ใช้ Title Case สำหรับ headers ภาษาอังกฤษ
- ใช้ภาษาไทยสำหรับ headers ภาษาไทย
- เว้นบรรทัดว่างก่อนและหลัง headers

## การใช้ Code Blocks

- ระบุ language สำหรับ syntax highlighting
- ใช้ filename เมื่อจำเป็น
- ใช้ line numbers เมื่ออ้างอิงถึง line ที่เฉพาะเจาะจง
- ให้ code สั้นและอ่านง่าย
- ใช้ inline code สำหรับ terms หรือ keywords

## การใช้ Lists

- ใช้ unordered lists สำหรับ items ที่ไม่มีลำดับ
- ใช้ ordered lists สำหรับ steps หรือลำดับ
- ใช้ nested lists สำหรับ hierarchy
- ใช้ spacing ระหว่าง items ที่เกี่ยวข้อง
- หลีกเลี่ยงการใช้ lists ที่ซับซ้อนเกินไป

## การใช้ Tables

- ใช้ tables เมื่อต้องเปรียบเทียบข้อมูล
- ใช้ alignment ที่เหมาะสมกับข้อมูล
- ใช้ headers ที่ชัดเจน
- หลีกเลี่ยง tables ที่กว้างเกินไป
- ใช้ description ก่อน table เพื่ออธิบาย

## การใช้ Links

- ใช้ descriptive text สำหรับ links
- ใช้ absolute URLs สำหรับ external links
- ใช้ relative paths สำหรับ internal links
- ตรวจสอบว่า links ใช้งานได้
- หลีกเลี่ยง link spam

## การใช้ Images

- ใช้ alt text สำหรับ accessibility
- ใช้รูปภาพที่มีความละเอียดเหมาะสม
- ใช้ formats ที่รองรับทั่วไป (PNG, JPG, SVG)
- ใช้ relative paths สำหรับ internal images
- หลีกเลี่ยงรูปภาพที่ใหญ่เกินไป

## การใช้ Formatting

- ใช้ bold สำหรับ emphasis ที่สำคัญ
- ใช้ italic สำหรับ terms หรือ emphasis เบาๆ
- หลีกเลี่ยงการใช้ formatting ที่เกินไป
- ใช้ formatting อย่างสม่ำเสมอ
- ใช้ strikethrough สำหรับ deleted content

## การใช้ Blockquotes

- ใช้ blockquotes สำหรับ quotes หรือ emphasis
- ใช้ nested blockquotes สำหรับ replies
- หลีกเลี่ยงการใช้ blockquotes ที่ยาวเกินไป
- ใช้ spacing ที่เหมาะสม
- ใช้ attribution เมื่อจำเป็น

## การใช้ Horizontal Rules

- ใช้ horizontal rules สำหรับแยก sections
- หลีกเลี่ยงการใช้เกินไป
- ใช้ spacing ที่เหมาะสม
- ใช้เพื่อจัดกลุ่ม content ที่เกี่ยวข้อง

## การใช้ Frontmatter

- ใช้ YAML frontmatter สำหรับ metadata
- ใช้ fields ที่จำเป็นเท่านั้น
- ใช้ naming conventions ที่สม่ำเสมอ
- ตรวจสอบ syntax ของ YAML
- ใช้ description สำหรับ SEO
