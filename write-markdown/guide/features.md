# Features ของ Markdown

## Basic Syntax

### Headers
- 6 ระดับ headers (H1-H6)
- Alternative syntax ด้วย underline
- Automatic ID generation

### Emphasis
- Bold ด้วย `**text**` หรือ `__text__`
- Italic ด้วย `*text*` หรือ `_text_`
- Strikethrough ด้วย `~~text~~`

### Lists
- Unordered lists ด้วย `-`, `*`, หรือ `+`
- Ordered lists ด้วย numbers
- Nested lists ด้วย indentation
- Task lists ด้วย `[ ]` และ `[x]`

### Links
- Inline links ด้วย `[text](url)`
- Reference links ด้วย `[text][id]`
- Auto links ด้วย `<url>`
- Image links ด้วย `![alt](url)`

### Code
- Inline code ด้วย backticks
- Code blocks ด้วย triple backticks
- Syntax highlighting
- Line numbers และ filename

### Blockquotes
- Blockquotes ด้วย `>`
- Nested blockquotes
- Blockquotes พร้อม other elements

### Horizontal Rules
- Horizontal rules ด้วย `---`, `***`, หรือ `___`

## Extended Syntax

### Tables
- Tables พร้อม alignment
- Tables พร้อม nested elements
- Table headers และ footers

### Footnotes
- Footnote references
- Footnote definitions
- Automatic numbering

### Definition Lists
- Term definitions
- Multiple definitions
- Nested definitions

### Task Lists
- Task items พร้อม checkboxes
- Completed และ incomplete tasks
- Nested task lists

### Strikethrough
- Strikethrough text
- Combined กับ emphasis

### Highlighting
- Highlighted text
- Custom highlight colors

### Subscript และ Superscript
- Subscript ด้วย `~text~`
- Superscript ด้วย `^text^`

## GitHub Flavored Markdown (GFM)

### Autolinks
- Automatic link detection
- URL และ email addresses

### Disallowed Raw HTML
- Security filtering
- Allowed tags ที่จำกัด

### Task Lists
- Task lists พร้อม checkboxes
- Syntax highlighting

### Tables
- GFM table syntax
- Alignment options

### Strikethrough
- Strikethrough support
- Combined formatting

### Code Blocks
- Fenced code blocks
- Language specification
- Syntax highlighting

## CommonMark

### Strict Compliance
- CommonMark spec compliance
- Portable across parsers
- Consistent rendering

- Consistent behavior
- Well-defined rules

### Extensions
- Compatible extensions
