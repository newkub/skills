# Markdown Websites and Resources

## Official Documentation

### Markdown Guide
- **URL**: https://www.markdownguide.org
- **Description**: Comprehensive guide to Markdown with basic and extended syntax
- **Features**: Tutorials, cheat sheets, tools, and examples

### CommonMark Spec
- **URL**: https://spec.commonmark.org
- **Description**: Official specification for CommonMark
- **Features**: Complete specification, test cases, and examples

### GitHub Flavored Markdown
- **URL**: https://github.github.com/gfm/
- **Description**: GitHub's Markdown specification
- **Features**: GFM syntax, tables, task lists, strikethrough

## Tools and Editors

### Typora
- **URL**: https://typora.io
- **Description**: WYSIWYG Markdown editor
- **Features**: Live preview, themes, export options

### VS Code
- **URL**: https://code.visualstudio.com
- **Description**: Code editor with Markdown support
- **Features**: Syntax highlighting, preview, extensions

### Obsidian
- **URL**: https://obsidian.md
- **Description**: Knowledge base with Markdown
- **Features**: Linking, plugins, graph view

### Notion
- **URL**: https://notion.so
- **Description**: All-in-one workspace with Markdown
- **Features**: Rich text, databases, collaboration

## Converters and Processors

### Pandoc
- **URL**: https://pandoc.org
- **Description**: Universal document converter
- **Features**: Convert between formats, filters, templates

### Markdown-it
- **URL**: https://markdown-it.github.io
- **Description**: Markdown parser for JavaScript
- **Features**: Extensible, fast, CommonMark compliant

### Remark
- **URL**: https://remark.js.org
- **Description**: Markdown processor powered by plugins
- **Features**: AST-based, plugin ecosystem, transforms

### Vale
