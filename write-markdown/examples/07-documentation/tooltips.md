## HTML Tooltips

````markdown
<span title="This is a tooltip">Hover over me</span>

<a href="#" title="Click to learn more">Learn more</a>
````

## Abbreviations

````markdown
<abbr title="HyperText Markup Language">HTML</abbr>
<abbr title="Cascading Style Sheets">CSS</abbr>
<abbr title="Application Programming Interface">API</abbr>
````

## Emoji Tooltips

````markdown
🚀 <span title="Rocket - Launch new features">Launch</span>
⚡ <span title="Lightning - Fast performance">Fast</span>
🔒 <span title="Lock - Secure encryption">Secure</span>
````

## Definition Tooltips

````markdown
**Term**: <span title="Definition of the term">Hover for definition</span>
````
