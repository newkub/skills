## Caution Blocks

````markdown
> ⚠️ **Caution:** This action cannot be undone.
>
> 🚨 **Warning:** Backup your data before proceeding.
>
> 🔥 **Danger:** This will delete all files permanently.
````

## Security Warnings

````markdown
> 🔒 **Security Notice:** Never commit credentials to version control.
>
> 🛡️ **Privacy Warning:** This collects user data.
````

## Deprecation Warnings

````markdown
> 📦 **Deprecated:** This feature will be removed in v3.0
>
> ⏳ **End of Life:** Support ends on 2024-12-31
````
