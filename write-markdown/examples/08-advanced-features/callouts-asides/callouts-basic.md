## Callout Blocks

````markdown
> **Note:** This is important information
> 
> **Warning:** Be careful with this approach
> 
> **Tip:** Use this pattern for better performance
````

## Nested Lists

````markdown
1. Main item
   1. Sub item 1
   2. Sub item 2
      - Nested bullet
      - Another bullet
2. Second main item
````

## Collapsible Sections

````markdown
<details>
<summary>Click to expand</summary>

This content is hidden by default.

</details>
````
