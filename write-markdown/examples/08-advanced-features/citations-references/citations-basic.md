## Inline Citations

````markdown
According to Smith (2024)[^1], this approach is effective.

Research shows positive results[^2][^3].
````

## Reference List

````markdown
## References

[^1]: Smith, J. (2024). *Effective Approaches*. Journal Name.
[^2]: Doe, A. (2023). "Research Methods". Conference Proceedings.
[^3]: Team, B. (2024). GitHub Repository. <https://github.com/example>
````

## Bibliography Style

````markdown
### Books

- Author, A. (Year). *Title*. Publisher.

### Articles

- Author, B. (Year). "Title". *Journal*, Volume(Issue), Pages.
````
