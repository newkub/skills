## Heading Levels

````markdown
# H1 - Main Title

## H2 - Section

### H3 - Subsection

#### H4 - Detail

##### H5 - Minor point

###### H6 - Fine print
````

## Alternative Syntax

````markdown
Alt-H1
======

Alt-H2
------
````

## Custom IDs

````markdown
## Section Title {#section-id}

[Link to section](#section-id)
````

## Heading Best Practices

- Use single H1 per document
- Maintain logical hierarchy
- Keep headings descriptive but concise
- Use sentence case for readability
