## Task Lists

````markdown
- [x] Task 1 (Completed)
- [ ] Task 2 (Incomplete)
````

## Nested Lists

````markdown
1. Main item
   1. Sub item 1
   2. Sub item 2
      - Nested bullet
      - Another bullet
2. Second main item
````

## Definition Lists

````markdown
Term 1
: Definition 1

Term 2
: Definition 2
````

## Footnotes

````markdown
Here's a sentence with a footnote[^1].

[^1]: This is the footnote content.
````
