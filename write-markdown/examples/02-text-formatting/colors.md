## Inline Color Text

````markdown
<span style="color: red;">Red text</span>
<span style="color: #00ff00;">Green hex</span>
<span style="color: rgb(0,0,255);">Blue RGB</span>
````

## Status Colors

````markdown

- 🟠 Warning / Attention
- 🟡 Caution / Pending
- 🟢 Success / Active
- 🔵 Info / Normal
- 🟣 Special / Feature
````
