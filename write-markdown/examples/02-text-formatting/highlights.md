## Text Highlighting

````markdown
<mark>Highlighted text</mark>
==Marked text==
**Bold for emphasis**
*Italic for emphasis*
````

## Color Highlighting

````markdown
<span style="background-color: yellow;">Yellow highlight</span>
<span style="background-color: lightgreen;">Green highlight</span>
<span style="background-color: lightblue;">Blue highlight</span>
````

## Code Highlights

````markdown
```typescript
// Highlighted line
const important = "This is key";

function critical() {
  return true; // Key return
}
```
````

## Important Notes

````markdown
> 🔴 **IMPORTANT:** Do not skip this step!
>
> 🟡 **NOTE:** This affects performance.
>
> 🟢 **TIP:** Consider caching results.
````
