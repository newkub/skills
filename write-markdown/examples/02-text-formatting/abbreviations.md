## HTML Abbreviation

````markdown
<abbr title="HyperText Markup Language">HTML</abbr>
````

## First Use Pattern

````markdown
**API** (Application Programming Interface) is used to...

Later just use: API
````

## Abbreviation with Superscript

````markdown
HTML<sup>5</sup> is the latest version
````

## Definition on First Mention

````markdown
**REST**[^1]

[^1]: Representational State Transfer - an architectural style for distributed hypermedia systems
````

````markdown

````
