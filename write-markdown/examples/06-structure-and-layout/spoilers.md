## Collapsible Spoilers

````markdown
<details>
<summary>⚠️ Spoiler: Plot twist</summary>

The butler did it! This is the hidden spoiler content.

</details>
````

## Hover Spoilers

````markdown
<span title="Hidden spoiler text">Hover to reveal</span>
````

## Inline Spoilers

````markdown
||This is a spoiler that can be revealed||

Hidden answer: ||42||
````
