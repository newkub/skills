## Basic Task List

````markdown
- [x] Completed task
- [ ] Incomplete task
- [ ] Another task to do
````

## Nested Task List

````markdown
- [x] Main task
  - [x] Subtask 1
  - [x] Subtask 2
  - [ ] Subtask 3
- [ ] Another main task
````

## With Description

````markdown
- [ ] Task title
  - Description of what needs to be done
  - Additional notes
````

## Mixed List

````markdown
- Regular item
- [x] Task item
- Another regular item
- [ ] Another task
````
