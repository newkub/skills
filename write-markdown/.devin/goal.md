## Goal

ให้ AI สามารถเขียนเอกสาร Markdown ที่มีคุณภาพสูง ด้วยรูปแบบที่ถูกต้อง และใช้ templates ที่มีอยู่อย่างมีประสิทธิภาพ

## Scope

ใช้สำหรับการเขียนเอกสาร Markdown ทุกประเภท รวมถึง:
- เอกสาร project
- README files
- Documentation
- Technical guides
- Tutorials
- และอื่นๆ
