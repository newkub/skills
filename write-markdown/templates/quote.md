# Quote Format

## รูปแบบ Quote มาตรฐาน

### Blockquote

```markdown
> This is a blockquote
```

### Nested Blockquote

```markdown
> First level
>> Second level
>>> Third level
```

### Blockquote with Author

```markdown
> Quote text
>
> — Author Name
```

### Blockquote with Source

```markdown
> Quote text
>
> — Author Name, Source Title
```

### Callout/Alert (ถ้ารองรับ)

```markdown
:::tip
This is a tip
:::

:::warning
This is a warning
:::

:::danger
This is dangerous
:::

:::info
This is information
:::
```

### When to Use

- อ้างอิงคำพูด
- แสดง warnings
- แสดง tips
- แสดง important notes
- แสดง examples

### Best Practices

- ใช้ blockquote เมื่อต้องเน้นข้อความ
- ใช้ callouts เมื่อต้องแยกประเภท
- ให้ quote สั้นและชัดเจน
- อ้างอิง source เสมอเมื่อเป็น quote
