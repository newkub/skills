# List Format

## รูปแบบ List มาตรฐาน

### Unordered List

```markdown
- Item 1
- Item 2
- Item 3
```

### Ordered List

```markdown
1. First step
2. Second step
3. Third step
```

### Nested List

```markdown
- Parent item
  - Child item 1
  - Child item 2
- Another parent
```

### Task List

```markdown
- [x] Completed task
- [ ] Pending task
- [ ] Another pending task
```

### Definition List

```markdown
Term 1
: Definition 1

Term 2
: Definition 2
```

### When to Use

- แสดง steps หรือ procedures
- แสดง features หรือ options
- แสดง requirements
- แสดง checklist
- แสดง hierarchical data

### Best Practices

- ใช้ unordered list เมื่อลำดับไม่สำคัญ
- ใช้ ordered list เมื่อลำดับสำคัญ
- ใช้ task list เมื่อต้อง tracking
- หลีกเลี่ยง nested list ลึกเกิน 3 ระดับ
