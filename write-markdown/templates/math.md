# Math Format

## รูปแบบ Math มาตรฐาน

### Inline Math

```markdown
$E = mc^2$
```

### Block Math

```markdown
$$
E = mc^2
$$
```

### Multi-line Math

```markdown
$$
\begin{aligned}
a &= b + c \\
  &= d + e
\end{aligned}
$$
```

### Math with LaTeX

```markdown
$$
\int_{0}^{\infty} e^{-x^2} dx = \frac{\sqrt{\pi}}{2}
$$
```

### When to Use

- แสดง formulas
- แสดง equations
- แสดง mathematical expressions
- แสดง scientific notation

### Best Practices

- ใช้ inline math สำหรับ expressions สั้น
- ใช้ block math สำหรับ equations ยาว
- ใช้ LaTeX syntax ที่ถูกต้อง
- ให้ math อ่านง่ายและเข้าใจ
