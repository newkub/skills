# Header Format

## รูปแบบ Header มาตรฐาน

### H1 - Main Title

```markdown
# Main Title
```

### H2 - Section

```markdown
## Section
```

### H3 - Subsection

```markdown
### Subsection
```

### H4 - Sub-subsection

```markdown
#### Sub-subsection
```

### H5 - Detail

```markdown
##### Detail
```

### H6 - Sub-detail

```markdown
###### Sub-detail
```

### Alternative Syntax (Underline)

```markdown
H1
===

H2
---
```

### When to Use

- H1: Main title ของเอกสาร (ใช้เพียงครั้งเดียว)
- H2: Major sections
- H3: Subsections ภายใน H2
- H4: Details ภายใน H3
- H5-H6: รายละเอียดเฉพาะที่ (หลีกเลี่ยงใช้ถ้าไม่จำเป็น)

### Best Practices

- ใช้ hierarchy ที่ชัดเจน
- อย่าข้ามระดับ (เช่น จาก H1 ไป H3)
- ใช้ spacing ระหว่าง headers และ content
- ใช้ Title Case สำหรับ headers ภาษาอังกฤษ
- ใช้ภาษาไทยสำหรับ headers ภาษาไทย
