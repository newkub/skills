# Link Format

## รูปแบบ Link มาตรฐาน

### Inline Link

```markdown
[Link text](https://example.com)
```

### Link with Title

```markdown
[Link text](https://example.com "Hover text")
```

### Reference Link

```markdown
[Link text][reference-id]

[reference-id]: https://example.com "Hover text"
```

### Automatic Link

```markdown
<https://example.com>
```

### Email Link

```markdown
<email@example.com>
```

### Internal Link (Anchor)

```markdown
[Link text](#section-id)
```

### When to Use

- อ้างอิง external resources
- อ้างอิง internal sections
- อ้างอิง email addresses
- อ้างอิง files หรือ documents

### Best Practices

- ใช้ link text ที่สื่อความหมายชัดเจน
- ใช้ descriptive text แทน URL
- ตรวจสอบว่า links ยังใช้งานได้
- ใช้ reference links เมื่อมีการใช้ URL เดียวกันหลายครั้ง
