# Footnote Format

## รูปแบบ Footnote มาตรฐาน

### Basic Footnote

```markdown
Text with footnote[^1]

[^1]: Footnote content
```

### Multiple Footnotes

```markdown
Text with footnote[^1] and another[^2]

[^1]: First footnote
[^2]: Second footnote
```

### Inline Footnote

```markdown
Text with footnote^[Footnote content]
```

### Footnote with Links

```markdown
Text with footnote[^1]

[^1]: See [documentation](https://example.com)
```

### When to Use

- อ้างอิง sources
- แสดง additional information
- แสดง citations
- แสดง clarifications

### Best Practices

- ใช้ footnote เมื่อต้องการไม่ให้รบกวน flow
- ให้ footnote content สั้นและชัดเจน
- ใช้ sequential numbering
- หลีกเลี่ยง footnotes มากเกินจำเป็น
