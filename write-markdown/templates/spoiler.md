# Spoiler Format

## รูปแบบ Spoiler มาตรฐาน

### Basic Spoiler (ถ้ารองรับ)

```markdown
:::spoiler Spoiler Alert
Hidden content here
:::
```

### Spoiler with Title

```markdown
:::spoiler Click to reveal
Hidden content here
:::
```

### Inline Spoiler

```markdown
||Hidden text||
```

### When to Use

- ซ่อน plot twists
- ซ่อน solutions
- ซ่อน answers
- ซ่อน sensitive information

### Best Practices

- ใช้ descriptive spoiler title
- ให้ผู้ใช้เลือกดู
- ใช้เมื่อจำเป็นเท่านั้น
- หลีกเลี่ยง spoilers ใน content หลัก
