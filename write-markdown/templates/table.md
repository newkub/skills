# Table Format

## รูปแบบตารางมาตรฐาน

### Basic Table

```markdown
| Column 1 | Column 2 | Column 3 |
|----------|----------|----------|
| Value 1  | Value 2  | Value 3  |
| Value 4  | Value 5  | Value 6  |
```

### Table with Alignment

```markdown
| Left | Center | Right |
|:-----|:------:|------:|
| L    | C      | R     |
```

### Table with Description

ใช้เมื่อมีข้อมูลหลายรายการที่ต้องเปรียบเทียบ

### When to Use

- เปรียบเทียบ options
- แสดง parameters
- สรุป features
- แสดง errors และ solutions
