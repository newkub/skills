# Tag Format

## รูปแบบ Tag มาตรฐาน

### Basic Tag (ถ้ารองรับ)

```markdown
<Tag text="example" />
```

### Tag with Color

```markdown
<Tag text="example" color="blue" />
```

### Tag with Link

```markdown
<Tag text="example" link="/path" />
```

### Multiple Tags

```markdown
<Tag text="tag1" />
<Tag text="tag2" />
<Tag text="tag3" />
```

### When to Use

- แสดง categories
- แสดง labels
- แสดง keywords
- แสดง metadata

### Best Practices

- ใช้ tag text สั้น
- ใช้ colors ที่เหมาะสม
- หลีกเลี่ยง tags มากเกิน 5
- ใช้ tags เมื่อจำเป็นเท่านั้น
