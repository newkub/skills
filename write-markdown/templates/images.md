# Image Format

## รูปแบบ Image มาตรฐาน

### Basic Image

```markdown
![Alt text](image-url)
```

### Image with Title

```markdown
![Alt text](image-url "Hover text")
```

### Image with Size (HTML)

```markdown
<img src="image-url" alt="Alt text" width="500" height="300">
```

### Reference Image

```markdown
![Alt text][image-id]

[image-id]: image-url "Hover text"
```

### When to Use

- แสดง screenshots
- แสดง diagrams
- แสดง illustrations
- แสดง logos หรือ icons

### Best Practices

- ใช้ alt text ที่สื่อความหมายชัดเจน
- ใช้ alt text สำหรับ accessibility
- ใช้ images ที่มีขนาดเหมาะสม
- ใช้ formats ที่รองรับทั่วไป (PNG, JPG, SVG)
- ตรวจสอบว่า image URLs ยังใช้งานได้
