# Consistency Principles

## Why Consistency Matters

Consistency ทำให้เอกสาร:
- อ่านง่ายขึ้น
- เข้าใจได้เร็วขึ้น
- maintain ง่ายขึ้น
- ดูเป็นมืออาชีพ

## Naming Conventions

### Headers

- ใช้ Title Case สำหรับ English headers
- ใช้ภาษาไทยสำหรับ Thai headers
- สม่ำเสมอทั่วทั้งเอกสาร
- หลีกเลี่ยง abbreviations ที่ไม่ชัดเจน

### Files

- ใช้ kebab-case สำหรับ filenames
- ใช้ lowercase เท่านั้น
- ใช้ descriptive names
- หลีกเลี่ยง special characters

### Variables ใน Code

- ใช้ camelCase สำหรับ JavaScript/TypeScript
- ใช snake_case สำหรับ Python
- ใช PascalCase สำหรับ classes
- ตาม language conventions

## Formatting Consistency

### Spacing

- ใช้ double line breaks ระหว่าง paragraphs
- ใช้ single line breaks ระหว่าง list items
- สม่ำเสมอทั่วทั้งเอกสาร
- หลีกเลี่ยง inconsistent spacing

### Code Blocks

- ใช้ language specification เสมอ
- ใช้ filename เมื่อจำเป็น
- ใช้ syntax highlighting เสมอ
- สม่ำเสมอใน code style

### Lists

- ใช้ unordered lists สำหรับ items ที่ไม่มีลำดับ
- ใช้ ordered lists สำหรับ steps
- ใช้ task lists สำหรับ checklists
- สม่ำเสมอใน punctuation

## Structure Consistency

### Document Structure

- ใช้ hierarchy ที่สม่ำเสมอ
- อย่าข้าม header levels
- ใช้ sections ที่จัดกลุ่มได้
- สม่ำเสมอใน organization

### Section Order

- Introduction → Main Content → Conclusion
- Overview → Details → Examples
- Problem → Solution → Verification
- สม่ำเสมอทั่วทั้ง project

## Style Consistency

### Tone

- ใช้ tone ที่สม่ำเสมอ
- formal หรือ informal อย่างใดอย่างหนึ่ง
- หลีกเลี่ยง tone switches
- เหมาะสมกับ audience

### Voice

- ใช้ active voice ส่วนใหญ่
- ใช้ passive voice เมื่อเหมาะสม
- สม่ำเสมอใน perspective
- ชัดเจนใน subject

### Language

- ใช้ภาษาเดียวตลอดเอกสาร
- หรือใช้ bilingual อย่างสม่ำเสมอ
- หลีกเลี่ยง language mixing
- ชัดเจนใน terminology

## Terminology Consistency

### Terms

- ใช้ terms ที่สม่ำเสมอ
- กำหนด glossary หากจำเป็น
- หลีกเลี่ยง synonyms ที่สับสน
- ใช้ industry standards

### Acronyms

- กำหนด acronyms ในการใช้ครั้งแรก
- ใช้ acronyms อย่างสม่ำเสมอ
- หลีกเลี่ยง overuse
- ใช้ full forms ใน titles

## Link Consistency

### Internal Links

- ใช้ relative paths
- ใช้ descriptive text
- ตรวจสอบว่า links ใช้งานได้
- สม่ำเสมอใน format

### External Links

- ใช้ absolute URLs
- ใช้ descriptive text
- ตรวจสอบว่า links ใช้งานได้
- สม่ำเสมอใน format

## Reference Consistency

### Citations

- ใช้ citation style ที่สม่ำเสมอ
- ใช้ format ที่สม่ำเสมอ
- รวม references ที่ท้ายเอกสาร
- ตรวจสอบว่า references ถูกต้อง

### Cross-References

- ใช้ consistent format
- ใช้ descriptive text
- ตรวจสอบว่า references ถูกต้อง
- สม่ำเสมอใน style

## Example Consistency

### Code Examples

- ใช้ consistent language
- ใช้ consistent style
- ใช้ consistent formatting
- ใช้ consistent naming

### Data Examples

- ใช้ consistent format
- ใช้ realistic data
- ใช้ consistent units
- ใช้ consistent precision
