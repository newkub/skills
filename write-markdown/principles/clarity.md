# Clarity Principles

## Why Clarity Matters

Clarity ทำให้เอกสาร:
- เข้าใจได้ง่าย
- ลดความสับสน
- เพิ่มประสิทธิภาพ
- ลด errors

## Clear Language

### Simple Words

- ใช้ words ที่เข้าใจง่าย
- หลีกเลี่ยง jargon ที่ไม่จำเป็น
- อธิบาย technical terms
- ใช้ common vocabulary

### Short Sentences

- ใช้ sentences ที่สั้นและกระชับ
- หลีกเลี่ยง complex sentences
- ใช้ active voice
- จำกัด ideas ต่อ sentence

### Clear Structure

- ใช้ paragraphs ที่สั้น
- ใช้ headers ที่ชัดเจน
- ใช้ lists สำหรับ items
- ใช้ visual hierarchy

## Clear Explanations

### Step-by-Step

- แบ่ง tasks เป็น steps
- ใช้ numbered lists
- อธิบายแต่ละ step
- ให้ examples สำหรับแต่ละ step

### Before/After

- แสดง state ก่อนและหลัง
- ใช้ visual comparisons
- อธิบาย changes
- highlight improvements

### Cause/Effect

- อธิบาย causes
- อธิบาย effects
- แสดง relationships
- ให้ examples

## Clear Examples

### Real-World Examples

- ใช้ examples ที่ realistic
- ใช้ use cases ที่ common
- ใช้ data ที่ meaningful
- หลีกเลี่ยง abstract examples

### Complete Examples

- ให้ complete code
- ให้ complete configuration
- ให้ complete workflows
- หลีกเลี่ยง snippets ที่ incomplete

### Annotated Examples

- อธิบายแต่ละ part
- ใช้ comments ใน code
- highlight key points
- อธิบาย decisions

## Clear Visuals

### Diagrams

- ใช้ diagrams สำหรับ complex concepts
- ใช้ consistent style
- ใช้ clear labels
- อธิบาย diagrams

### Screenshots

- ใช้ screenshots สำหรับ UI
- ใช้ high resolution
- ใช้ clear annotations
- highlight relevant areas

### Tables

- ใช้ tables สำหรับ comparisons
- ใช้ clear headers
- ใช้ consistent alignment
- อธิบาย tables

## Clear Organization

### Logical Flow

- จัดเรียง content อย่าง logical
- ใช้ clear transitions
- ใช้ clear sections
- ใช้ clear hierarchy

### Grouping

- จัดกลุ่ม related content
- ใช้ clear sections
- ใช้ clear headers
- ใช้ clear boundaries

### Navigation

- ใช้ table of contents
- ใช้ clear links
- ใช้ breadcrumbs
- ใช้ backlinks

## Clear Context

### Prerequisites

- ระบุ prerequisites ชัดเจน
- อธิบาย requirements
- ให้ setup instructions
- ระบุ dependencies

### Scope

- ระบุ scope ชัดเจน
- อธิบาย what's covered
- อธิบาย what's not covered
- ระบุ assumptions

### Audience

- ระบุ target audience
- ปรับ content ตาม audience
- อธิบาย background knowledge
- ให้ additional resources

## Clear Actions

### Call to Action

- ระบุ actions ที่ต้องทำ
- ใช้ imperative verbs
- ให้ clear instructions
- ระบุ expected outcomes

### Next Steps

- ระบุ next steps ชัดเจน
- ให้ prioritized actions
- ให้ timelines
- ให้ resources

### Troubleshooting

- ระบุ common issues
- ให้ solutions
- ให้ workarounds
- ให้ support resources
