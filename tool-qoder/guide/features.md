# Features

ฟีเจอร์ทั้งหมดของ Qoder

## Editor Workspace Features

### NEXT Engine (Code Suggestions)

| Feature | Description |
|---------|-------------|
| **Whole-function generation** | Generate complete functions ไม่ใช่แค่บรรทัดเดียว |
| **Predictive suggestions** | คาดเดาขั้นตอนถัดไปจาก context |
| **Architectural consistency** | สอดคล้องกับ design patterns ของ project |

### Chat Features

| Feature | Description |
|---------|-------------|
| **Inline Chat** | Chat ในไฟล์โดยตรง |
| **Chat Panel** | Side panel สำหรับ conversational Q&A |
| **Context synthesis** | รวม knowledge base กับ project code |

## Quest Workspace Features

### Autonomous Delegation

| Feature | Description |
|---------|-------------|
| **Task Boards** | Kanban-style task management |
| **Progress Tracking** | ดูสถานะ real-time |
| **Artifact Review** | ตรวจสอบผลลัพธ์จาก agent |

### Cloud Agents

| Feature | Description |
|---------|-------------|
| **Session Management** | จัดการ agent conversations |
| **Environment Control** | Cloud execution environments |
| **Multi-step Execution** | ทำ tasks หลายขั้นตอน |
| **Tool Integration** | ใช้ code tools ได้ครบ |

## Knowledge Features

### Knowledge Engine

| Feature | Description |
|---------|-------------|
| **Auto-accumulation** | สะสม business knowledge อัตโนมัติ |
| **Semantic Search** | ค้นหาด้วยความหมาย |
| **Context Awareness** | เข้าใจ project context |

### Memory Stores

| Feature | Description |
|---------|-------------|
| **Knowledge Persistence** | เก็บความรู้ระหว่าง sessions |
| **Version Control** | ติดตามการเปลี่ยนแปลง |
| **Redaction** | ลบ content ที่ไม่ต้องการ |

## Integration Features

### Model Context Protocol (MCP)

| Feature | Description |
|---------|-------------|
| **External Tools** | เชื่อมต่อ databases, APIs |
| **Tool Discovery** | ค้นหา available tools |
| **Credential Management** | ใช้ Vaults อย่างปลอดภัย |

### Vaults

| Feature | Description |
|---------|-------------|
| **Secret Storage** | เก็บ API keys, passwords |
| **Organization Support** | แชร์ในทีม |
| **Archive Capability** | เก็บ vault ที่ไม่ใช้แล้ว |
