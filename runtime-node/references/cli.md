# CLI Reference - Node.js

## node

```bash
node file.js              # Run file
node --version            # Show version
node --watch file.js      # Watch mode
node --inspect file.js    # Debug mode
```

## npm

```bash
npm init                   # Initialize project
npm install                # Install deps
npm install <pkg>          # Add package
npm install -D <pkg>       # Dev dependency
npm test                   # Run tests
npm run <script>           # Run script
```

## bunx

```bash
bunx prettier .
bunx create-react-app
```

## Core Commands

| Command | Description |
|---------|-------------|
| `node -v` | Version |
| `npm -v` | npm Version |
| `npm init -y` | Quick init |
| `npm install` | Install deps |
