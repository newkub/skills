# Testing

## ภาพรวม

Libraries สำหรับ testing React applications

## React Testing Library

```bash
bun add -D @testing-library/react @testing-library/jest-dom @testing-library/user-event
```

**Features:**
- User-centric testing
- Accessibility testing
- Simple API
- Best practices

## Vitest

```bash
bun add -D vitest @vitest/ui jsdom
```

**Features:**
- Fast test runner
- ESM support
- Watch mode
- UI dashboard

## Playwright

```bash
bun add -D @playwright/test
```

**Features:**
- E2E testing
- Cross-browser testing
- Network interception
- Visual regression

## สรุป

Testing libraries:
- React Testing Library - User-centric, accessibility testing
- Vitest - Fast test runner, ESM support
- Playwright - E2E testing, cross-browser
