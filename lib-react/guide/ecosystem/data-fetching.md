# Data Fetching

## ภาพรวม

Libraries สำหรับ data fetching ใน React applications

## TanStack Query (React Query)

```bash
bun add @tanstack/react-query
```

**Features:**
- Caching
- Background updates
- Optimistic updates
- Pagination

## SWR

```bash
bun add swr
```

**Features:**
- Simple API
- Auto revalidation
- Focus tracking
- Interval polling

## Apollo Client

```bash
bun add @apollo/client graphql
```

**Features:**
- GraphQL client
- Caching
- Real-time updates
- Type generation

## สรุป

Data fetching libraries:
- TanStack Query - Caching, background updates, pagination
- SWR - Simple API, auto revalidation
- Apollo Client - GraphQL, real-time updates
