# Form Handling

## ภาพรวม

Libraries สำหรับ form handling ใน React applications

## React Hook Form

```bash
bun add react-hook-form
```

**Features:**
- Minimal re-renders
- Built-in validation
- TypeScript support
- Easy integration

## Formik

```bash
bun add formik yup
```

**Features:**
- Mature library
- Large community
- Schema validation
- Field arrays

## สรุป

Form handling libraries:
- React Hook Form - Minimal re-renders, built-in validation
- Formik - Mature, large community, schema validation
