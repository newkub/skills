# Animation

## ภาพรวม

Libraries สำหรับ animation ใน React applications

## Framer Motion

```bash
bun add framer-motion
```

**Features:**
- Declarative animations
- Gestures
- Drag and drop
- Layout animations

## React Spring

```bash
bun add react-spring
```

**Features:**
- Physics-based animations
- Hooks API
- Interpolation
- Performance optimized

## สรุป

Animation libraries:
- Framer Motion - Declarative, gestures, drag and drop
- React Spring - Physics-based, hooks API
