# Dependency Security

## ภาพรวม

วิธีการ secure dependencies ใน React applications

## 1. Audit Dependencies

Audit dependencies สำหรับ vulnerabilities

```bash
bun audit
```

## 2. Update Dependencies

Keep dependencies up to date

```bash
bun update
```

## 3. Lock File

Commit lock file สำหรับ consistency

```bash
git add bun.lockb
```

## สรุป

Dependency security:
1. Audit dependencies สำหรับ vulnerabilities
2. Keep dependencies up to date
3. Commit lock file สำหรับ consistency
