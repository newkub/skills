# React Forms

## 1. Controlled Components
- **React controls** สำหรอ form state
- ใช้ state สำหรอ form values
- ใช้ onChange handlers สำหรอ updates
- มี single source of truth

## 2. Uncontrolled Components
- **DOM controls** สำหรอ form values
- ใช้ refs สำหรอ accessing values
- ไม่ต้องการ state management
- เหมาะกับ simple forms

## 3. Form Validation
- **Client-side validation** สำหรอ user feedback
- **Real-time validation** สำหรอ immediate feedback
- **Schema validation** ด้วย libraries เช่น Yup, Zod
- **Custom validation rules** สำหรอ business logic

## 4. Form Libraries
- **React Hook Form** สำหรอ performance-focused forms
- **Formik** สำหรอ comprehensive form solution
- **Final Form** สำหรอ subscription-based forms
- **React Final Form** สำหรอ React integration

## 5. Form State Management
- **Form values** สำหรอ current form data
- **Validation errors** สำหรอ error messages
- **Touched fields** สำหรอ user interaction tracking
- **Form submission state** สำหรอ async operations

## 6. Advanced Form Patterns
- **Multi-step forms** สำหรอ complex workflows
- **Dynamic forms** สำหรอ conditional fields
- **Array fields** สำหรอ repeating form sections
- **Nested forms** สำหรอ complex data structures

## 7. Form Accessibility
- **Label associations** สำหรอ screen readers
- **Error announcements** สำหรอ accessibility
- **Keyboard navigation** สำหรอ accessibility
- **ARIA attributes** สำหรอ enhanced accessibility

## 8. Form Performance
- **Debounced validation** สำหรอ performance
- **Optimized re-renders** สำหรอ large forms
- **Lazy validation** สำหรอ progressive validation
- **Form memoization** สำหรอ optimization
