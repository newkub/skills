# framework-next

## When to use

- เมื่อต้องการสร้าง React applications ด้วย SSR/SSG/ISR
- เมื่อต้องการ SEO-friendly web applications
- เมื่อต้องการ performance สูงและ optimized loading
- เมื่อต้องการ App Router และ modern React features
