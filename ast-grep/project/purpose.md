# Purpose of AST-grep

AST-grep is a structural search and rewrite tool that uses Abstract Syntax Tree (AST) pattern matching to find and transform code across multiple programming languages.

## Core Purpose

To provide developers with a powerful, language-aware alternative to text-based tools like grep and sed for code analysis and transformation.

## Key Objectives

1. **Precision**: Match code structure, not just text
2. **Scalability**: Handle large codebases efficiently
3. **Flexibility**: Support complex pattern matching scenarios
4. **Automation**: Enable automated code refactoring
5. **Multi-language**: One tool for all programming languages

## Why AST Matters

Traditional text-based tools struggle with:
- Understanding code structure
- Handling syntax variations
- Maintaining semantic correctness
- Cross-language consistency

AST-grep solves these by working at the syntactic structure level.
