# อัปเดต Skills Documentation

## เมื่อใดควรใช้

ใช้ workflow นี้เมื่อคุณต้องการ:

- อัปเดต SKILL.md files ทั่วทุก skill directories
- ทำให้ skill documentation formats และ structures เป็นมาตรฐาน
- ใช้ skill guidelines และ writing standards ใหม่
- รักษาคุณภาพและความสอดคล้องของ skill
- อัปเดต skill metadata และ references

## Quick Start

1. อ่าน SKILL.md files ปัจจุบันใน directories ทั้งหมด
2. ใช้โครงสร้าง SKILL.md template มาตรฐาน
3. อัปเดต skill descriptions และ capabilities
4. ตรวจสอบความสอดคล้องกับ skill guidelines
5. ทดสอบ skill references และ links ทั้งหมด

## Steps

### 1. อ่าน Skill Files ปัจจุบัน

ตรวจสอบ SKILL.md files ที่มีอยู่ใน skill directories ทั้งหมด
ระบุ sections ที่หายไปและ formatting inconsistencies
บันทึก skill patterns และข้อมูลที่ล้าสมัย

**Verification:** ยืนยันว่า SKILL files ทั้งหมดถูกบันทึกรายการและวิเคราะห์

### 2. ใช้ SKILL.md Template และ Write-Skills Guidelines

อัปเดต SKILL files ทั้งหมดให้ทำตาม standard template structure
ให้แน่ใจว่ามี sections ที่จำเป็น: เมื่อใดควรใช้, Quick Start, summary table
ใช้ consistent markdown formatting และ heading styles
ใช้ภาษาไทยสำหรับ descriptions แต่ technical terms ใช้ภาษาอังกฤษ
กำหนดประเภท skill ตาม write-skills classification

**Verification:** ตรวจสอบว่า structure ตรงกับ SKILL.md standards และ write-skills guidelines

### 3. อัปเดต Skill Descriptions

เขียน skill descriptions ที่ชัดเจนโดยใช้ active voice
อัปเดต เมื่อใดควรใช้ sections พร้อม use cases ปัจจุบัน
ให้แน่ใจว่า Quick Start sections กระชับและ actionable
เพิ่ม summary tables พร้อม file types และ rules

**Verification:** ยืนยันว่าข้อมูล skill ทั้งหมดถูกต้องและครบถ้วน

### 4. ตรวจสอบ Writing Guidelines Compliance

ตรวจสอบว่าประโยคทั้งหมดใช้ active voice เท่านั้น
ให้แน่ใจว่าประโยคสั้นกว่า 20 คำ
ลบ passive voice และภาษาที่ไม่ชัดเจน
ใช้ technical term usage ในภาษาไทยอย่างถูกต้อง

**Verification:** ยืนยันว่าสอดคล้องกับ write-skills guidelines

### 5. อัปเดต Skill References

ตรวจสอบ internal skill links และ references ทั้งหมด
อัปเดต workflow connections และ dependencies
ตรวจสอบ external resource links และ documentation
ให้แน่ใจว่า cross-references ทั้งหมดใช้งานได้

**Verification:** ทดสอบว่า skill references ทั้งหมดทำงานถูกต้อง

### 6. จัดประเภท Skills ตาม Write-Skills

กำหนดประเภท skill ให้ถูกต้อง: Library, Blog, Project, Product, Scripts, Business, Personal Dev, Communication, Research, Programming Language
สร้างโครงสร้างไดเรกทอรีตามประเภทที่กำหนด
สร้างไฟล์ที่จำเป็นตาม skill type requirements
ตรวจสอบว่า naming conventions ถูกต้อง

**Verification:** ยืนยันว่า skills ทั้งหมดเป็นไปตาม write-skills classification และ structure

## Expected Outcomes

- SKILL.md files ทั้งหมดใช้ template structure ที่สม่ำเสมอ
- Skill descriptions ชัดเจนและใช้ active voice
- Writing guidelines compliance ถูกบรรลุ
- Skill references และ links ใช้งานได้
- คุณภาพ documentation ตรงกับ write-workflows standards
- Skills ทั้งหมดถูกจัดประเภทตาม write-skills classification
- โครงสร้างไดเรกทอรีตรงกับ skill type requirements
- Naming conventions ถูกต้องและสม่ำเสมอ

## Error Handling

- ถ้า SKILL files หาย sections ให้เพิ่ม required template sections
- ถ้ามี writing guidelines violations เขียนใหม่ด้วย active voice
- ถ้า references เสีย อัปเดตหรือลบ broken links
- ถ้า skill descriptions ไม่ชัดเจน เขียนใหม่ตาม guidelines

## Best Practices

- ทำตาม SKILL.md template structure อย่างเคร่งครัด
- ใช้ active voice และรักษาประโยคให้สั้นกว่า 20 คำ
- รักษาความสม่ำเสมอใน skill documentation ทั้งหมด
- ทดสอบ skill references และ workflow connections ทั้งหมด
- อัปเดต skills เมื่อ capabilities หรือ requirements เปลี่ยน
- จัดประเภท skills ให้ถูกต้องตาม write-skills classification
- สร้างโครงสร้างไดเรกทอรีตาม skill type requirements
- ใช้ naming conventions ที่กำหนดอย่างเคร่งครัด
- สร้างไฟล์ที่จำเป็นตามประเภท skill (get-started, guide, examples, apis)
- ตรวจสอบ acceptance criteria สำหรับแต่ละ skill type
