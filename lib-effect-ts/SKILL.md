## When to use

- เมื่อต้องการ functional programming ใน TypeScript
- เมื่อต้องการ type-safe error handling
- เมื่อต้องการ dependency injection
- เมื่อต้องการ composable effects

## Skills Related

- `lang-typescript` - TypeScript programming language
