# lib-effect-ts

## Overview

Effect คือ TypeScript library สำหรับ functional programming ที่มี type-safe error handling, dependency injection และ composable effects ช่วยให้เขียนโค้ดที่ robust, testable และ maintainable ได้ง่ายขึ้น
