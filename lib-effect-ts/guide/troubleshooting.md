# Troubleshooting

## Common Issues

### Type Errors

- **Type Inference** - ตรวจสอบ type inference
- **Generic Types** - ใช้ generic types อย่างถูกต้อง
- **Type Guards** - ใช้ type guards สำหรับ runtime checks

### Runtime Errors

- **Effect Execution** - ตรวจสอบ effect execution
- **Service Resolution** - ตรวจสอบ service resolution
- **Error Handling** - ตรวจสอบ error handling

### Performance Issues

- **Memory Leaks** - ตรวจสอบ memory leaks
- **Inefficient Composition** - optimize effect composition
- **Runtime Overhead** - minimize runtime overhead
