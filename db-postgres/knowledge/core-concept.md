# PostgreSQL Core Concepts

## Overview
PostgreSQL is an advanced open-source relational database system.

## Key Concepts
- **Database**: Container for related data
- **Table**: Structure for storing records
- **Schema**: Logical grouping of tables
- **Index**: Data structure for fast lookups
- **View**: Virtual table based on query
- **Function**: Reusable code blocks
- **Trigger**: Automatic actions on events

## Data Types
- Numeric: INTEGER, BIGINT, DECIMAL
- Text: VARCHAR, TEXT, CHAR
- Date: DATE, TIMESTAMP, TIME
- Boolean: BOOLEAN
- JSON: JSON, JSONB

## ACID Properties
- **Atomicity**: All or nothing transactions
- **Consistency**: Data remains valid
- **Isolation**: Concurrent transactions don't interfere
- **Durability**: Changes persist
