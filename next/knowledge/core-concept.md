# Next.js Core Concepts

## Overview

Next.js is a React framework for building full-stack web applications.

## Key Concepts

- **App Router**: New routing system (app directory)
- **Pages Router**: Traditional routing (pages directory)
- **Server Components**: Components that run on server
- **Client Components**: Components that run on client
- **Layouts**: Shared UI between pages
- **Route Handlers**: API endpoints

## Rendering Strategies

- **SSR**: Server-Side Rendering
- **SSG**: Static Site Generation
- **ISR**: Incremental Static Regeneration
- **CSR**: Client-Side Rendering

## File-based Routing

- `page.tsx`: Route pages
- `layout.tsx`: Layout components
- `loading.tsx`: Loading states
- `error.tsx`: Error boundaries
- `not-found.tsx`: 404 pages
