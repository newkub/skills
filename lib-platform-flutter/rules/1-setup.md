# Flutter Setup

## When to Use

Use this guide when setting up Flutter development environment.

## Quick Steps

1. Download Flutter SDK from official website
2. Extract to desired location
3. Add Flutter to PATH
4. Run `flutter doctor` to check dependencies
5. Install required components

## Verification

- Check Flutter version: `flutter --version`
- Run doctor: `flutter doctor`
- Create test project: `flutter create test_app`
- Run test app: `flutter run`

## Common Issues

- Android Studio not installed
- Missing Android SDK
- Xcode not installed (macOS)
- PATH configuration problems
