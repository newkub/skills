# Installation

## Installation Command

```bash
# npm
npm install -D knip

# pnpm
pnpm add -D knip

# yarn
yarn add -D knip

# bun
bun add -D knip
```

## Verify Installation

```bash
npx knip --version
```

## Requirements

| Requirement | Version |
|-------------|---------|
| Node.js | 18+ |
| Package Managers | npm, pnpm, yarn, หรือ bun |
