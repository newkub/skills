# framework-electron

## Overview

แนวทางการพัฒนา Electron ตาม best practices สำหรับ cross-platform desktop applications ที่ใช้ web technologies (HTML, CSS, JavaScript) ร่วมกับ Node.js และ Chromium

## File Structure

| Folder | Description |
|--------|-------------|
| guide/ | คู่มือและ tutorials สำหรับการใช้งาน |
| references/ | CLI commands และ configuration reference |
| knowledge/ | ข้อมูลเพิ่มเติมเกี่ยวกับ concepts |
