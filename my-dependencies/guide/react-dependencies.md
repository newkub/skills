## คำแนะนำ

| หมวดหมู่ | แนะนำ | เหตุผล |
|---------|-------|--------|
| **State** | zustand หรือ jotai | Simple, fast |
| **Data Fetching** | @tanstack/react-query | Industry standard |
| **Routing** | react-router-dom | Most popular |
| **Forms** | react-hook-form + zod | Best performance |
| **UI** | @radix-ui + tailwind | Headless + flexible |
| **Styling** | tailwindcss หรือ unocss | Utility-first |
| **Animation** | framer-motion | Best API |
| **Testing** | @testing-library/react | Standard |
