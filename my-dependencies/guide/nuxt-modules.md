# Nuxt Modules

## UI & Components

| Module | ใช้สำหรับ | ติดตั้ง |
|--------|----------|---------|
| @nuxt/ui | Nuxt UI 2.0 - Tailwind CSS + Headless UI | `bun add @nuxt/ui` |
| @nuxtjs/tailwindcss | Tailwind CSS integration | `bun add -d @nuxtjs/tailwindcss` |
| @nuxt/icon | Icon module (Iconify) | `bun add @nuxt/icon` |
| @nuxt/image | Image optimization | `bun add @nuxt/image` |
| @nuxt/fonts | Font optimization | `bun add @nuxt/fonts` |
| @unocss/nuxt | UnoCSS integration | `bun add -d @unocss/nuxt` |
| @nuxtjs/color-mode | Dark mode | `bun add @nuxtjs/color-mode` |
| shadcn-nuxt | shadcn/ui for Nuxt | `bun add shadcn-nuxt` |
