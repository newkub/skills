## คำแนะนำ

| หมวดหมู่ | แนะนำ | เหตุผล |
|---------|-------|--------|
| **Framework** | @sveltejs/kit | Official, full-featured |
| **State** | svelte/store (built-in) | Native reactivity |
| **Data** | @tanstack/svelte-query | Best async state |
| **UI** | @skeletonlabs/skeleton หรือ melt-ui | Modern, customizable |
| **Styling** | tailwindcss | Great ecosystem |
| **Forms** | felte | Lightweight |
| **Animation** | svelte/transition (built-in) | Native, performant |
| **Testing** | @testing-library/svelte | Standard |
