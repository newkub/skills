## คำแนะนำ

| หมวดหมู่ | แนะนำ | เหตุผล |
|---------|-------|--------|
| **Framework** | vue + vue-router | Official |
| **State** | pinia | Official, TypeScript |
| **Data Fetching** | @tanstack/vue-query | Best async state |
| **Forms** | vee-validate + zod | Best validation |
| **UI** | @nuxt/ui หรือ @headlessui/vue | Modern, accessible |
| **Icons** | @iconify/vue | Universal |
| **Styling** | unocss หรือ tailwindcss | Fast, modern |
| **Animation** | @vueuse/motion | Vue-native |
| **Testing** | @vue/test-utils + vitest | Standard |
| **Utils** | @vueuse/core | Essential |
