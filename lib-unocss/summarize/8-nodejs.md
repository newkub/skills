# Node.js

| Feature | Usage | Example |
|---------|-------|---------|
| **Build Process** | Generate CSS at build time | `unocss.process()` |
| **File Watching** | Development mode | `chokidar.watch()` |
| **CLI Tools** | Command line usage | `unocss -o output.css` |
| **API Server** | CSS generation endpoint | `express.post('/css')` |
| **File System** | Read/write CSS files | `fs.writeFileSync()` |
| **Process Management** | Handle build processes | `child_process.spawn()` |
