# Error Handling

| Error Type | Solution | Prevention |
|------------|-----------|-------------|
| **Missing Classes** | ตรวจสอบ uno.config.js | Validate configuration |
| **Icon Not Found** | ตรวจสอบ icon collection | Install required icons |
| **Theme Override** | ตรวจสอบ theme inheritance | Use proper theme structure |
| **Build Failures** | ตรวจสอบ syntax errors | Lint configuration |
| **Runtime Errors** | ตรวจสอบ dynamic classes | Use safelist |
| **Integration Issues** | ตรวจสอบ plugin compatibility | Check version compatibility |
