## Learning Path

### Beginner

1. Start with `guide/installation.md`
2. Read `guide/quick-start.md`
3. Learn `guide/key-concept.md`
4. Practice with `key-concepts/null-safety.md`
5. Explore `key-concepts/data-classes.md`

### Intermediate

1. Study `guide/features.md`
2. Learn `key-concepts/coroutines.md`
3. Read `key-concepts/extension-functions.md`
4. Follow `principles/idiomatic-kotlin.md`
5. Apply `guide/best-practices.md`

### Advanced

1. Master `key-concepts/sealed-classes.md`
2. Study `guide/architecture.md`
3. Learn `principles/solid-for-kotlin.md`
4. Explore `guide/integration.md`
5. Reference `references/api.md`
