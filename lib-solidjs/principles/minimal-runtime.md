# Minimal Runtime

## Principle

SolidJS ออกแบบมาเพื่อ minimal runtime:
- **Small Bundle** - bundle size เล็ก
- **No Virtual DOM** - ไม่มี virtual DOM overhead
- **Compile-time** - compile-time optimizations

## Application

- **Minimize Bundle** - minimize bundle size
- **Use Tree Shaking** - ใช้ tree shaking
- **Lazy Load** - lazy load components
