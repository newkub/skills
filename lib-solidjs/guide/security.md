# Security

## Security Considerations

- **XSS Prevention** - SolidJS ป้องกัน XSS อัตโนมัติ
- **Sanitization** - sanitize user input
- **Content Security Policy** - ใช้ CSP headers

## Best Practices

- **Validate Input** - validate input ก่อน render
- **Use Trusted Sources** - ใช้ trusted sources สำหรับ data
- **Escape Output** - SolidJS escapes output อัตโนมัติ
