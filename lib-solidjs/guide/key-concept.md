# Key Concept

## What is SolidJS?

SolidJS is a declarative JavaScript library for building user interfaces with fine-grained reactivity

## Core Features

| Feature | Description |
|---------|-------------|
| Fine-grained reactivity | Direct DOM updates |
| No Virtual DOM | Direct DOM manipulation |
| TypeScript | Full TypeScript support |
| Small bundle | Minimal runtime |
| Fast performance | Competes with vanilla JS |

## Key Concepts

| Concept | Description |
|---------|-------------|
| Signals | Reactive state primitives |
| Components | Functions returning JSX |
| Effects | Side effects tracking |
| Memos | Derived reactive values |
| Stores | Nested reactive state |

## When to Use

- High-performance applications
- Real-time updates
- Low-latency UI
- Bundle size sensitive apps

## Comparison

| Feature | SolidJS | React | Vue |
|---------|---------|-------|-----|
| DOM | Direct | Virtual | Virtual |
| Reactivity | Signals | Hooks | Proxy |
| Learning | Medium | Medium | Easy |
| Bundle | Small | Medium | Small |
