# CLI Reference

## Vite Commands

| Command | Description |
|---------|-------------|
| `npm run dev` | Start dev server |
| `npm run build` | Build production |
| `npm run preview` | Preview build |

## Templates

```bash
# TypeScript
bunx degit solidjs/templates/ts my-app

# JavaScript
bunx degit solidjs/templates/js my-app
```

## Options

| Flag | Description |
|------|-------------|
| `--port` | Set port |
| `--host` | Set host |
| `--open` | Open browser |
