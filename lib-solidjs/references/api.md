# API Reference

## Core API

- **createSignal** - create reactive signals
- **createEffect** - create side effects
- **createMemo** - create derived signals
- **createStore** - create stores

## Component API

- **Component** - component function
- **For** - list rendering
- **Show** - conditional rendering
- **Suspense** - suspense boundaries

## Utilities

- **onMount** - mount callback
- **onCleanup** - cleanup callback
- **batch** - batch updates
- **untrack** - untrack dependencies
