# Features

## Email Sending

- **SMTP Relay** - ส่งอีเมลผ่าน SMTP
- **REST API** - ส่งอีเมลผ่าน HTTP API
- **Custom Domain** - ใช้ domain ของคุณเอง
- **Attachments** - รองรับ file attachments

## Email Routing

- **Catch-all** - รับอีเมลทั้งหมด
- **Specific Addresses** - route ตาม email address
- **Tag-based Routing** - route ตาม tags
- **Forwarding** - forward ไปยัง external addresses

## Workers Integration

- **Email Binding** - รับอีเมลใน Workers
- **MIME Parsing** - parse email content อัตโนมัติ
- **Reply** - reply อีเมลโดยตรงจาก Worker

## Deliverability

- **SPF/DKIM/DMARC** - authentication records
- **IP Warmup** - automatic IP warmup
- **Analytics** - tracking และ reporting
