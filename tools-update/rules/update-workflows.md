# อัปเดต Workflow Files

## เมื่อใดควรใช้
ใช้ workflow นี้เมื่อคุณต้องการ:
- อัปเดต workflow documentation ทั่วทุก directories
- ใช้ workflow writing guidelines และ standards ใหม่
- Refactor workflows ให้ตรงกับ best practices requirements
- รักษาคุณภาพและความสม่ำเสมอของ workflow
- อัปเดต workflow references และ dependencies

## Quick Start
1. อ่าน workflow files ปัจจุบันใน directories ทั้งหมด
2. ใช้ write-workflows guidelines กับไฟล์ทั้งหมด
3. อัปเดต workflow structures และ formatting
4. ตรวจสอบความสอดคล้องกับ best practices
5. ทดสอบ workflows และ references ที่อัปเดตทั้งหมด

## Steps

### 1. อ่าน Workflow Files ปัจจุบัน
ตรวจสอบ workflow files ที่มีอยู่ใน skill directories ทั้งหมด
ระบุ formatting issues และโครงสร้างที่ล้าสมัย
บันทึก workflow patterns ที่ต้องการปรับปรุง

**Verification:** ยืนยันว่า workflow files ทั้งหมดถูกบันทึกรายการและวิเคราะห์

### 2. ใช้ Writing Guidelines
อัปเดต workflows ทั้งหมดให้ใช้ active voice เท่านั้น
ให้แน่ใจว่าประโยคสั้นกว่า 20 คำ
ใช้ standard markdown formatting อย่างสม่ำเสมอ
ลบ passive voice และภาษาที่ไม่ชัดเจน

**Verification:** ตรวจสอบว่าประโยคทั้งหมดเป็นไปตาม writing guidelines requirements

### 3. อัปเดต Workflow Structures
ทำให้ section ordering และ headings เป็นมาตรฐาน
ให้แน่ใจว่า frontmatter และ formatting ถูกต้อง
ใช้ consistent naming conventions
ตรวจสอบว่า workflow references ใช้รูปแบบที่ถูกต้อง

**Verification:** ยืนยันว่า structures ตรงกับ write-workflows standards

### 4. ตรวจสอบ Best Practices Compliance
ตรวจสอบว่า workflow length ไม่เกิน 300 บรรทัด
ให้แน่ใจว่า step count อยู่ภายใต้ 15 steps
ตรวจสอบว่า workflows เป็น self-contained และ functional
ลบ magic numbers และ hardcoded values

**Verification:** ยืนยันว่า workflows ทั้งหมดสอดคล้องกับ best practices

### 5. อัปเดต Workflow References
ตรวจสอบว่า internal workflow links ทำงานถูกต้อง
อัปเดต cross-workflow dependencies และ references
ตรวจสอบ external resource links และ documentation
ให้แน่ใจว่า workflow connections ทั้งหมดใช้งานได้

**Verification:** ทดสอบว่า workflow references และ links ทั้งหมดทำงานได้อย่างเหมาะสม

## Expected Outcomes
- Workflow files ทั้งหมดใช้ formatting ที่สม่ำเสมอ
- Writing guidelines ถูกใช้อย่างสม่ำเสมอ
- Best practices compliance ถูกบรรลุใน workflows
- Workflow references และ dependencies ใช้งานได้
- คุณภาพ documentation ตรงกับ write-workflows standards

## Error Handling
- ถ้า workflows เกินขีดจำกัดความยาว refactor เป็น components ที่เล็กกว่า
- ถ้า references เสีย อัปเดต workflows ที่เชื่อมโยงทั้งหมด
- ถ้า formatting conflicts เกิดขึ้น ให้ความสำคัญกับ write-workflows standards
- ถ้าการทดสอบล้มเหลว ตรวจสอบและแก้ไข workflow sections ที่ได้รับผลกระทบ

## Best Practices
- อัปเดต workflows ตามลำดับ dependency ที่เป็นเหตุเป็นผล
- ทดสอบ workflow แต่ละอันก่อน batch updates
- เก็บ backup copies ก่อน structural changes ครั้งใหญ่
- บันทึก workflow modifications และ improvements ทั้งหมด
- ใช้ version control เพื่อติดตามการเปลี่ยนแปลง workflow อย่างเป็นระบบ
