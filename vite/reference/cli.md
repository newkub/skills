# Vite CLI Reference

## Commands

### vite

เริ่ม dev server:

```bash
vite
```

### vite build

Build สำหรับ production:

```bash
vite build
```

### vite preview

Preview production build:

```bash
vite preview
```

## Options

### --port

ระบุ port:

```bash
vite --port 3000
```

### --host

ระบุ host:

```bash
vite --host
```

### --mode

ระบุ mode:

```bash
vite --mode development
```

### --config

ระบุ config file:

```bash
vite --config vite.config.js
```
