# Windsurf All Features

Complete reference of all Windsurf features and capabilities.

## AI Features

### Cascade (Agentic AI)

| Feature | Description |
|---------|-------------|
| Deep codebase awareness | Understands entire project structure |
| Flow awareness | Tracks edits, commands, clipboard |
| Multi-step execution | Complex tasks across multiple files |
| Web search | Search documentation and web |
| Web tools | Browser, content collection, previews |
| App deploys | One-click deployment to internet |
| @ mentions | Reference functions, classes, files |
| Highlighted code | Mention or refactor selected code |

**Cascade Features by Category:**

#### Flow Awareness
- File tracking (edits, views)
- Terminal command tracking
- Clipboard monitoring
- Conversation history
- Intent inference

#### Web Tools
- **Browser**: Fully functional browser integration
- **Content collection**: Parse and chunk web pages
- **App deploys**: Package and share apps
- **Previews**: See live website in IDE

#### Customizations
- **MCP**: Connect custom tools (Figma, Slack, Stripe)
- **Rules**: Saved rulebooks with slash commands
- **Workflows**: Define Cascade behavior patterns
- **Memories**: Auto-save context between conversations
