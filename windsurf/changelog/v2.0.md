## Architecture

### New Components

```
Agent Command Center
├── Cascade Sessions
│   ├── In Progress
│   └── Completed
├── Devin Sessions
│   ├── In Progress
│   └── Completed
└── Task Board
    ├── Ready
    ├── In Progress
    └── Done
```

### Spaces Structure

```typescript
interface Space {
  id: string;

  agents: Agent[];

  context: Context;
}
```

## Migration Guide

### From 1.x to 2.0

1. **Update Windsurf**
   ```bash
   # Download from windsurf.com
   ```

2. **Configure Devin** (optional)
   ```json
   {
     "devin": {
       "enabled": true,
       "defaultModel": "opus"
     }
   }
   ```

3. **Review new features**
   - Agent Command Center
   - Spaces
   - Team features

### Breaking Changes
