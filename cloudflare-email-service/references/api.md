# API Documentation

API endpoints สำหรับ Cloudflare Email Service

## Email Routing API

- **GET** /accounts/:account_id/email/routing/rules
- **POST** /accounts/:account_id/email/routing/rules
- **PUT** /accounts/:account_id/email/routing/rules/:id
- **DELETE** /accounts/:account_id/email/routing/rules/:id

## Email Security API

- **GET** /accounts/:account_id/email/security/settings
- **PATCH** /accounts/:account_id/email/security/settings
