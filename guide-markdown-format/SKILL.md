## When to use

- เมื่อต้องการเขียนเอกสารด้วย Markdown
- เมื่อต้องการใช้รูปแบบ Markdown ที่ถูกต้อง
- เมื่อต้องการสร้าง templates สำหรับ Markdown
- เมื่อต้องการเรียนรู้รูปแบบ Markdown ขั้นสูง
- เมื่อต้องการ standardize Markdown formatting ในทีม

## Skills Related

- `/write-skills` - สำหรับการเขียน skills ให้เป็นมาตรฐาน
