# Horizontal Rule Format

## รูปแบบ Horizontal Rule มาตรฐาน

### Basic Horizontal Rule

```markdown
---
```

### Alternative Syntax

```markdown
***
___
```

### Horizontal Rule with Text (ถ้ารองรับ)

```markdown
---
*Section Divider*
---
```

### When to Use

- แบ่ง sections
- แบ่ง topics
- แสดง breaks
- แสดง transitions

### Best Practices

- ใช้ horizontal rule เมื่อต้องแบ่ง content ชัดเจน
- หลีกเลี่ยง overuse
- ใช้ syntax ที่สม่ำเสมอ
- ให้ spacing เหมาะสม
