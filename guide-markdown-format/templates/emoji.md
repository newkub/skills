# Emoji Format

## รูปแบบ Emoji มาตรฐาน

### Basic Emoji

```markdown
✅ Check
❌ Cross
⚠️ Warning
```

### Shortcode Emoji (ถ้ารองรับ)

```markdown
:check:
:cross:
:warning:
```

### Emoji in Text

```markdown
This is important ⚠️
```

### Emoji in Lists

```markdown
- ✅ Completed
- ⏳ In progress
- ❌ Failed
```

### When to Use

- แสดง status
- แสดง mood
- แสดง visual cues
- ทำให้ content น่าสนใจ

### Best Practices

- ใช้ emoji เมื่อเหมาะสม
- หลีกเลี่ยง overuse
- ใช้ emoji ที่เป็นที่รู้จัก
- พิจารณา accessibility
