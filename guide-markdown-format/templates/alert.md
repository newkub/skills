# Alert Format

## รูปแบบ Alert มาตรฐาน

### Tip Alert

```markdown
:::tip
This is a helpful tip
:::
```

### Warning Alert

```markdown
:::warning
Be careful with this
:::
```

### Danger Alert

```markdown
:::danger
This is dangerous
:::
```

### Info Alert

```markdown
:::info
This is important information
:::
```

### Note Alert

```markdown
:::note
This is a note
:::
```

### Alert with Title

```markdown
:::tip Title
This is a helpful tip
:::
```

### When to Use

- แสดง important information
- แสดง warnings
- แสดง tips
- แสดง notes
- แสดง cautions

### Best Practices

- ใช้ alert type ที่เหมาะสม
- ให้ content สั้นและชัดเจน
- หลีกเลี่ยง alerts มากเกินจำเป็น
- ใช้ title เมื่อจำเป็น
