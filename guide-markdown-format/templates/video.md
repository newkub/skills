# Video Format

## รูปแบบ Video มาตรฐาน

### Basic Video (HTML)

```markdown
<video src="video.mp4" controls></video>
```

### Video with Poster

```markdown
<video src="video.mp4" poster="poster.jpg" controls></video>
```

### YouTube Embed

```markdown
<iframe width="560" height="315" src="https://www.youtube.com/embed/VIDEO_ID" frameborder="0" allowfullscreen></iframe>
```

### Vimeo Embed

```markdown
<iframe src="https://player.vimeo.com/video/VIDEO_ID" width="640" height="360" frameborder="0" allowfullscreen></iframe>
```

### When to Use

- แสดง tutorials
- แสดง demos
- แสดง presentations
- แสดง walkthroughs

### Best Practices

- ใช้ optimized videos
- ให้ poster image
- ใช้ appropriate dimensions
- พิจารณา accessibility (captions)
