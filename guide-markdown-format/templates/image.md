# Image Format

## รูปแบบ Image มาตรฐาน

### Basic Image

```markdown
![Alt text](image.png)
```

### Image with Title

```markdown
![Alt text](image.png "Image title")
```

### Image with Size

```markdown
![Alt text](image.png){width=300 height=200}
```

### Image with Link

```markdown
[![Alt text](image.png)](https://example.com)
```

### Figure with Caption (ถ้ารองรับ)

```markdown
![Alt text](image.png)

*Figure: Image caption*
```

### When to Use

- แสดง screenshots
- แสดง diagrams
- แสดง examples
- แสดง UI mockups
- แสดง architecture diagrams

### Best Practices

- ใช้ descriptive alt text
- ใช้ optimized images
- ใช้ appropriate formats (PNG, SVG, JPG)
- ให้ images มีขนาดเหมาะสม
- ใช้ SVG สำหรับ icons และ diagrams
