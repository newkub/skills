# Admonition Format

## รูปแบบ Admonition มาตรฐาน

### Note Admonition

```markdown
!!!note
    This is a note
```

### Tip Admonition

```markdown
!!!tip
    This is a helpful tip
```

### Warning Admonition

```markdown
!!!warning
    Be careful with this
```

### Danger Admonition

```markdown
!!!danger
    This is dangerous
```

### Info Admonition

```markdown
!!!info
    This is information
```

### Success Admonition

```markdown
!!!success
    This was successful
```

### Admonition with Title

```markdown
!!!tip "Custom Title"
    This is a helpful tip
```

### Collapsible Admonition

```markdown
!!!note collapsible
    This is a collapsible note
```

### When to Use

- แสดง important information
- แสดง warnings
- แสดง tips
- แสดง notes
- แสดง best practices

### Best Practices

- ใช้ admonition type ที่เหมาะสม
- ให้ content สั้นและชัดเจน
- ใช้ title เมื่อจำเป็น
- หลีกเลี่ยง overuse
