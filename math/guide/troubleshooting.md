# Troubleshooting

## Computation

**ปัญหา**: อัลกอริทึมช้าเกินไป
- **วิธีแก้**: วิเคราะห์ Big O และเลือกอัลกอริทึมที่ดีกว่า

**ปัญหา**: Memory overflow
- **วิธีแก้**: วิเคราะห์ Space Complexity และใช้ memoization

## Discrete Math

**ปัญหา**: Graph traversal ไม่ทำงาน
- **วิธีแก้**: ตรวจสอบ cycle detection และ visited nodes

**ปัญหา**: Combinatorics ผิด
- **วิธีแก้**: ตรวจสอบการนับซ้ำ และใช้ inclusion-exclusion

## Information Theory

**ปัญหา**: Compression ไม่ลดขนาด
- **วิธีแก้**: ตรวจสอบ entropy และเลือก algorithm ที่เหมาะสม

**ปัญหา**: Error detection ไม่ทำงาน
- **วิธีแก้**: ใช้ checksum ที่เหมาะสมกับ error patterns

## Linear Algebra

**ปัญหา**: Matrix multiplication ช้า
- **วิธีแก้**: ใช้ optimized libraries และ GPU acceleration

**ปัญหา**: Numerical instability
- **วิธีแก้**: ใช้ algorithms ที่ stable และตรวจสอบ condition numbers

## Set Theory

**ปัญหา**: Set operations ช้า
- **วิธีแก้**: ใช้ hash-based sets แทน array-based

**ปัญหา**: Cardinality ผิด
- **วิธีแก้**: ตรวจสอบ duplicates และ empty sets
