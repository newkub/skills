# What

## คณิตศาสตร์คืออะไรสำหรับการพัฒนาซอฟต์แวร์

คณิตศาสตร์สำหรับการพัฒนาซอฟต์แวร์คือการประยุกต์ใช้แนวคิดคณิตศาสตร์เพื่อ:
- แก้ปัญหาทาง programming
- ออกแบบอัลกอริทึมที่มีประสิทธิภาพ
- เข้าใจ data structures และ algorithms
- พัฒนา applications ที่ซับซ้อน

## 5 สาขาหลัก

### Computation
ศึกษาการคำนวณและอัลกอริทึม เช่น:
- Time/Space complexity
- Algorithm design patterns
- Optimization techniques

### Discrete Mathematics
ศึกษาโครงสร้างเชิงจำนวนเต็ม เช่น:
- Sets, logic, graphs
- Combinatorics
- Number theory

### Information Theory
ศึกษาการส่งและเก็บข้อมูล เช่น:
- Entropy, compression
- Error detection/correction
- Channel capacity

### Linear Algebra
ศึกษาเวกเตอร์และเมทริกซ์ เช่น:
- Matrix operations
- Linear transformations
- Eigenvalues/vectors

### Set Theory
ศึกษากลุ่มของวัตถุ เช่น:
- Set operations
- Relations, functions
- Cardinality
