# FAQs

## คำถามที่พบบ่อย

### Q: ต้องเก่งคณิตศาสตร์มากแค่ไหน?

A: ไม่ต้องเป็น expert แต่ต้องเข้าใจพื้นฐาน:
- Big O notation
- พื้นฐาน linear algebra
- พื้นฐาน probability

### Q: คณิตศาตร์สาขาไหนสำคัญที่สุด?

A: ขึ้นกับ domain:
- Web dev: Discrete math, set theory
- ML/AI: Linear algebra, probability
- Systems: Computation, information theory

### Q: ต้อง implement เองหรือใช้ libraries?

A: ใช้ libraries เป็นหลัก:
- Implement เองเมื่อต้อง custom
- เข้าใจ concept สำคัญกว่า implementation

### Q: เรียนจากที่ไหนดี?

A: เรียนจากหลายแหล่ง:
- Online courses (Khan Academy, Coursera)
- Textbooks (ดูใน reference/)
- Practice problems (LeetCode, Project Euler)

### Q: คณิตศาสตร์ช่วยอะไรในงานจริง?

A: ช่วยหลายอย่าง:
- Optimize performance
- Design algorithms
- Debug complex issues
- Understand ML/AI
