# Purpose

## วัตถุประสงค์ของ Math Skill

Skill นี้สร้างขึ้นเพื่อรวบรวมความรู้ด้านคณิตศาสตร์ที่จำเป็นสำหรับการพัฒนาซอฟต์แวร์ โดยครอบคลุม 5 สาขาหลัก:

1. **Computation** - ทฤษฎีการคำนวณและอัลกอริทึม
2. **Discrete Mathematics** - คณิตศาสตร์เชิงจำนวนเต็ม
3. **Information Theory** - ทฤษฎีสารสนเทศ
4. **Linear Algebra** - พีชคณิตเชิงเส้น
5. **Set Theory** - ทฤษฎีเซต

## เป้าหมาย

- ให้นักพัฒนาเข้าใจพื้นฐานคณิตศาสตร์ที่จำเป็น
- เชื่อมโยงคณิตศาสตร์กับการพัฒนาซอฟต์แวร์จริง
- ให้ references ที่ครบถ้วนสำหรับการศึกษาต่อ
