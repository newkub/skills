# Features

### Computation Features

| Feature | คำอธิบาย |
|---------|-----------|
| Big O Analysis | วิเคราะห์ความซับซ้อน |
| Algorithm Patterns | Patterns ทั่วไปของอัลกอริทึม |
| Optimization Techniques | เทคนิคการ optimize |
| Recursion | การเรียกตัวเองซ้ำ |
| Dynamic Programming | แก้ปัญหาโดยแบ่งย่อย |
