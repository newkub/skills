# When

## เมื่อไหร่ควรใช้คณิตศาสตร์

### Computation

เมื่อต้อง:
- วิเคราะห์ประสิทธิภาพอัลกอริทึม
- เปรียบเทียบ data structures
- Optimize code
- แก้ปัญหาที่ซับซ้อน

### Discrete Mathematics

เมื่อต้อง:
- ออกแบบ algorithms
- ทำ graph-based features
- ทำ data validation
- ทำ authentication

### Information Theory

เมื่อต้อง:
- บีบอัดข้อมูล
- ตรวจสอบความถูกต้องข้อมูล
- ส่งข้อมูลผ่าน network
- ทำ data encoding

### Linear Algebra

เมื่อต้อง:
- ทำ machine learning
- ทำ computer graphics
- ทำ signal processing
- ทำ data analysis

### Set Theory

เมื่อต้อง:
- ทำ database queries
- ทำ data filtering
- ทำ data modeling
- ทำ permission systems
