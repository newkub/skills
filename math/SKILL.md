# Math Skill

## วัตถุประสงค์

Skill นี้ครอบคลุมความรู้ด้านคณิตศาสตร์ที่จำเป็นสำหรับการพัฒนาซอฟต์แวร์ รวมถึง Computation, Discrete Mathematics, Information Theory, Linear Algebra และ Set Theory
