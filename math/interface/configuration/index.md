# Configuration

## Library Configuration

ถ้าใช้ libraries คณิตศาสตร์:

### NumPy

```python
import numpy as np
np.set_printoptions(precision=4)
```

### math.js

```javascript
const config = {
  epsilon: 1e-12,
  matrix: 'Array'
}
const math = create(all, config)
```
