# Programmatic API

คณิตศาสตร์เป็นความรู้พื้นฐาน ไม่มี API ที่เฉพาะเจาะจง แต่มี libraries หลายภาษาที่ให้ใช้:

## Python

```python
import numpy as np
import scipy.linalg
```

## JavaScript

```javascript
import { matrix, multiply } from 'mathjs'
```

## Rust

```rust
use nalgebra as na;
```

## TypeScript

```javascript
import * as math from 'mathjs'
```
