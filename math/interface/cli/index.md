# CLI

คณิตศาสตร์ไม่มี CLI ที่เฉพาะเจาะจง แต่ libraries บางตัวมี CLI tools:

## Python NumPy

ไม่มี CLI เฉพาะ ใช้ผ่าน Python script

## Julia

Julia เป็น language สำหรับคณิตศาสตร์ที่มี CLI:

```bash
julia script.jl
```

## MATLAB

MATLAB มี CLI สำหรับคำนวณคณิตศาสตร์:

```bash
matlab -r "command"
```
