## Key Features

- **100% Type-Safe** - Full TypeScript inference without code generation
- **File-Based Routing** - Auto-generate routes from file structure
- **Search Params API** - State management in URL with validation
- **Nested Routes** - Layout routes and route isolation
- **Data Loaders** - Built-in data fetching with caching
- **Code Splitting** - Automatic route-based code splitting
- **React & Solid** - First-class support for both frameworks
