# Computer Computation

คู่มือเกี่ยวกับ Computer Computation และ Theory of Computation ครอบคลุม topics ต่างๆ เกี่ยวกับ computational models, complexity theory, algorithms และ formal languages

## When to use

ใช้เมื่อต้องการ:
- เข้าใจทฤษฎี computation และ computational models
- เรียนรู้ complexity theory และ algorithm analysis
- เข้าใจ formal languages และ automata
- เตรียมสอบ theory of computation
- ออกแบบ algorithms ที่มีประสิทธิภาพ
- เข้าใจ limits ของ computation

- **Formal Languages**: Regular, CFL, CSL, RE
