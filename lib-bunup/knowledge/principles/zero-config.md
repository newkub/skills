# Zero-Config Philosophy

## Convention Over Configuration

Bunup ออกแบบมาเพื่อ zero-config:
- **Auto-detection** - detect entry points อัตโนมัติ
- **Sensible Defaults** - ใช้ defaults ที่เหมาะสม
- **Minimal Setup** - ตั้งค่าน้อยที่สุด

## When to Configure

ใช้ configuration เฉพาะเมื่อ:
- ต้องการ custom entry points
- ต้องการ specific formats
- ต้องการ custom output paths
- ต้องการ external dependencies

## Best Practice

เริ่มต้นด้วย zero-config แล้วเพิ่ม configuration เฉพาะที่จำเป็น
