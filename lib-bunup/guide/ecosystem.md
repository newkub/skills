# Ecosystem

## Bun Runtime

Bunup ออกแบบมาเพื่อทำงานกับ Bun runtime:
- **Native Integration** - integration กับ Bun APIs
- **Performance** - ใช้ประโยชน์จาก Bun's performance
- **Tooling** - ใช้ Bun's tooling ecosystem

## Package Managers

- **Bun** - Primary package manager
- **npm** - Compatible กับ npm
- **yarn** - Compatible กับ yarn
- **pnpm** - Compatible กับ pnpm

## CI/CD

- **GitHub Actions** - ใช้ Bun ใน GitHub Actions
- **CI Integration** - Integrate กับ CI/CD pipelines
- **Publishing** - Publish ไปยัง npm อัตโนมัติ
