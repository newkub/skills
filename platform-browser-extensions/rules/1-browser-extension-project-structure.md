# Browser Extension Project Structure

โครงสร้างโปรเจกต์ browser extension ที่ใช้ WXT ต้องมีโครงสร้างที่ถูกต้องเพื่อให้ทำงานได้อย่างเหมาะสม

## โครงสร้างพื้นฐาน

```
📂 {rootDir}/
├── .output/           # Build artifacts (auto-generated)
├── .wxt/              # Generated by WXT (TS config)
├── assets/            # CSS, images, assets
├── components/        # UI components (auto-imported)
├── composables/      # Composable functions (auto-imported)
├── entrypoints/      # Entrypoints ทั้งหมด
├── hooks/            # React/Solid hooks (auto-imported)
├── modules/          # WXT modules
├── public/           # Static files
├── utils/            # Utility functions (auto-imported)
├── .env              # Environment variables
├── .env.publish      # Environment variables for publishing
├── app.config.ts     # Runtime config
├── package.json      # Package manager file
├── tsconfig.json     # TypeScript config
├── web-ext.config.ts # Browser startup config
└── wxt.config.ts     # Main WXT config
```

## การตั้งค่า src/ Directory

ถ้าต้องการใช้ src/ directory:

```typescript
// wxt.config.ts
export default defineConfig({
  srcDir: 'src',
});
```

โครงสร้างจะเป็น:

```
📂 {rootDir}/
├── src/
│   ├── assets/
│   ├── components/
│   ├── composables/
│   ├── entrypoints/
│   ├── hooks/
│   └── utils/
├── public/
├── .env
├── .env.publish
├── app.config.ts
├── package.json
├── tsconfig.json
├── web-ext.config.ts
└── wxt.config.ts
```

## การตั้งค่า Directories อื่นๆ

```typescript
export default defineConfig({
  // Relative to project root
  srcDir: 'src',           // default: '.'
  modulesDir: 'wxt-modules', // default: 'modules'
  outDir: 'dist',           // default: '.output'
  publicDir: 'static',      // default: 'public'
  
  // Relative to srcDir
  entrypointsDir: 'entries', // default: 'entrypoints'
});
```

## Entrypoints Directory

Entrypoints directory คือที่เก็บ entrypoints ทั้งหมดของ extension:

```
📂 entrypoints/
├── background.ts          # Background script
├── popup.html             # Popup page
├── options.html           # Options page
├── content.ts             # Content script
├── newtab.html            # New tab page
└── ...
```

## Public Directory

Public directory ใช้สำหรับ static files เช่น icons, images:

```
📂 public/
├── icon-16.png
├── icon-24.png
├── icon-48.png
├── icon-96.png
└── icon-128.png
```

WXT จะ auto-discover icons จากชื่อไฟล์ที่ตรงกับ pattern ต่อไปนี้:
- `icon-16.png`
- `icon-16x16.png`
- `icon@16w.png`
- `icon@16h.png`
- `icon@16.png`
- `icon/16.png` หรือ `icons/16.png`
- `icon/16x16.png` หรือ `icons/16x16.png`

## Auto-imported Directories

Directories ต่อไปนี้จะถูก auto-import:
- `components/` - UI components
- `composables/` - Composable functions
- `hooks/` - React/Solid hooks
- `utils/` - Utility functions

## Modules Directory

Modules directory ใช้สำหรับ WXT modules:

```
📂 modules/
├── my-module/
│   ├── package.json
│   └── ...
└── ...
```

## Environment Files

- `.env` - Environment variables สำหรับ development
- `.env.publish` - Environment variables สำหรับ publishing

## Config Files

- `wxt.config.ts` - Main WXT configuration
- `web-ext.config.ts` - Browser startup configuration
- `tsconfig.json` - TypeScript configuration
- `app.config.ts` - Runtime configuration

## Best Practices

1. **ใช้ src/ directory** เพื่อแยก source code จาก configuration files
2. **จัดระเบียบ entrypoints** ตามประเภทของ entrypoint
3. **ใช้ auto-imports** เพื่อลด boilerplate code
4. **ตั้งชื่อ icons** ตาม pattern ที่ WXT รองรับ
5. **แยก concerns** โดยใช้ directories ที่เหมาะสม
6. **ใช้ modules** เพื่อ reuse code ข้าม extensions
