# CLI Reference

Nanostores is primarily used via npm, no dedicated CLI.

## Package Manager

```bash
npm install nanostores
npm install @nanostores/react
npm install @nanostores/vue
npm install @nanostores/solid
npm install @nanostores/svelte
```

## DevTools

```bash
npm install @nanostores/logger
```

## Development

```bash
npm run dev
npm run build
npm run test
```
