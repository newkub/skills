# Key Concept

## What is Nanostores?

Nanostores is a tiny state manager for React, Vue, Svelte, Solid, and vanilla JS

## Core Features

| Feature | Description |
|---------|-------------|
| Tiny | <1KB |
| Universal | All frameworks |
| Simple | Easy to learn |
| Fast | Minimal overhead |
| TypeScript | Full support |

## Key Concepts

| Concept | Description |
|---------|-------------|
| Atom | Simple value store |
| Map | Object store |
| Computed | Derived state |
| Context | Framework integration |

## When to Use

- Small to medium apps
- Framework-agnostic apps
- Micro-frontends
- Shared state
