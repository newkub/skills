# Git All Features

## Basic Commands
- `git init`: สร้าง repository ใหม่
- `git clone`: คัดลอก repository จาก remote
- `git add`: เพิ่มไฟล์ไปยัง staging area
- `git commit`: บันทึกการเปลี่ยนแปลง
- `git status`: ดูสถานะปัจจุบัน
- `git log`: ดูประวัติ commits

## Branching & Merging
- `git branch`: จัดการ branches
- `git checkout`: สลับ branches
- `git merge`: รวม branches
- `git rebase`: ย้าย commits ไป branch อื่น

## Remote Operations
- `git remote`: จัดการ remote repositories
- `git fetch`: ดึงข้อมูลจาก remote
- `git pull`: ดึงและรวมข้อมูลจาก remote
- `git push`: ส่งข้อมูลไป remote

## Advanced Features
- `git stash`: เก็บการเปลี่ยนแปลงชั่วคราว
- `git cherry-pick`: นำ commits มาใช้
- `git revert`: ย้อนกลับ commits
- `git reset`: รีเซ็ต commits
- `git bisect`: ค้นหา bug ด้วย binary search

## Configuration
- `git config`: ตั้งค่า Git
- `.gitignore`: กำหนดไฟล์ที่ไม่ต้องการติดตาม
- `.gitattributes`: กำหนดคุณสมบัติไฟล์
