# Vercel

Vercel เป็น cloud platform สำหรับ front-end developers ให้บริการ deploy และ host web applications พร้อม features สำหรับ CI/CD, edge functions และ serverless APIs

## คุณสมบัติหลัก

- **Instant Deployments**: Deploy ด้วย git ได้ทันที
- **Preview Deployments**: Preview ทุก PR ก่อน merge
- **Edge Network**: Global CDN พร้อม edge functions
- **Serverless Functions**: APIs แบบ serverless
- **Built-in Analytics**: Performance และ analytics
- **Zero Config**: Auto-detect framework
- **Open Next.js**: รองรับ Next.js เป็นพิเศษ
- **Environment Variables**: จัดการ secrets ได้ง่าย
- **Integrations**: เชื่อมต่อกับ databases, CMS, etc.

## เมื่อใดควรใช้

- ต้องการ deploy Next.js, React, Vue, Svelte apps
- ต้องการ preview deployments สำหรับ team
- ต้องการ serverless APIs ที่ scale ได้
- ต้องการ edge functions สำหรับ low latency
- ต้องการ CI/CD ที่ตั้งค่าง่าย
