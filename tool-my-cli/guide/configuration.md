# Configuration

## Basic Configuration

สร้าง configuration file สำหรับ tool-my-cli:

```json
{
  "tool": {
    "enabled": true
  }
}
```

## Configuration Options

| Option | Description | Default |
|--------|-------------|---------|
| option1 | คำอธิบาย option 1 | default1 |
| option2 | คำอธิบาย option 2 | default2 |

## Environment Variables

```env
TOOL_MY-CLI_API_KEY=your_key
```
