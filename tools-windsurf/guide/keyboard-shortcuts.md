# Keyboard Shortcuts

> คีย์ลัดสำหรับ Windsurf IDE

---

## 🎯 ทั่วไป

| คีย์ลัด | ฟังก์ชัน |
|---------|----------|
| `Ctrl + ,` | เปิด Settings |
| `Ctrl + Shift + P` | Command Palette |
| `Ctrl + Shift + X` | Extensions |
| `Ctrl + `` ` | Toggle Terminal |

---

## 💬 Cascade Chat

| คีย์ลัด | ฟังก์ชัน |
|---------|----------|
| `Ctrl + L` | เปิด/ปิด Chat Panel |
| `Ctrl + I` | Inline Edit (Cascade) |
| `Ctrl + Enter` | ส่งข้อความ |
| `Shift + Enter` | ขึ้นบรรทัดใหม่ |

## 📝 Cascade-Specific

| `/` | เริ่ม slash command |

---

## 💡 Tips

- ใช้ `Ctrl + Shift + P` เพื่อหาคำสั่งที่ไม่รู้คีย์ลัด
- กด `Ctrl + K` แล้วกดคีย์อื่นเพื่อ chord commands
- ปรับแต่งได้ใน Settings > Keyboard Shortcuts
