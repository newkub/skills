## [1.0.0] - 2026-03-14

### Added

- สร้าง `system-prompt.md` - รายการ tools ทั้งหมด (~50 tools)
- สร้าง `cascade.md` - ภาพรวม Cascade architecture
- สร้าง `best-practices.md` - แนวทางการใช้งาน
- สร้าง `troubleshooting.md` - แก้ไขปัญหา
- สร้าง `workflows.md` - การใช้และสร้าง workflows
- สร้าง `mcp-servers.md` - รายละเอียด MCP servers
- สร้าง `examples.md` - ตัวอย่างการใช้งาน 20 use cases
- สร้าง `tips-and-tricks.md` - เคล็ดลับการใช้งาน
- สร้าง `setup.md` - เริ่มต้นตั้งค่า
- สร้าง `glossary.md` - คำศัพท์เฉพาะทาง
- สร้าง `keyboard-shortcuts.md` - คีย์ลัด IDE
- สร้าง `configuration-reference.md` - การตั้งค่าทั้งหมด
- สร้าง `migration-guide.md` - ย้ายจาก IDE/AI อื่น
- สร้าง `advanced-usage.md` - Use cases ซับซ้อน
- สร้าง `changelog.md` - บันทึกการเปลี่ยนแปลง

### Features

- ครอบคลุม tools ทั้งหมดของ Windsurf Cascade
- รองรับการใช้งานตั้งแต่เริ่มต้นถึงระดับ advanced
- ตัวอย่างการใช้งานจริง 20 use cases
- Best practices และ troubleshooting guide
