## Goal

ให้ผู้ใช้เข้าใจและสามารถออกแบบ software architecture ได้อย่างมีประสิทธิภาพ

## Scope

ใช้สำหรับออกแบบระบบซอฟต์แวร์ในระดับ architectural, เลือก architectural style ที่เหมาะสม, สร้างระบบที่ scalable และ maintainable, เข้าใจ architectural patterns และ principles, และออกแบบ microservices หรือ monolith

## Execute

- อ่าน guide/ เพื่อเข้าใจ concepts และ best practices
- ศึกษา references/ สำหรับ documentation และ resources
- ปฏิบัติตาม workflows/ สำหรับการทำงานเฉพาะทาง
- ใช้ภาษาไทยในการอธิบาย
- ให้ examples ที่ชัดเจนและใช้งานได้จริง
- อ้างอิง sources ที่เชื่อถือได้
- อัปเดต content ให้ทันสมัยตาม version ล่าสุด

## Rules

- ใช้ภาษาไทยในการอธิบาย
- ให้ examples ที่ชัดเจนและใช้งานได้จริง
- อ้างอิง sources ที่เชื่อถือได้
- อัปเดต content ให้ทันสมัยตาม version ล่าสุด

## Expected Outcome

- เข้าใจ architectural styles และ patterns
- สามารถเลือก architecture ที่เหมาะสมกับ project
- สามารถ design scalable และ maintainable systems ได้
