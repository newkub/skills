# Software Architecture

แนวทางการออกแบบซอฟต์แวร์ในระดับ architectural — ครอบคลุม architectural styles, patterns, และ principles สำหรับสร้างระบบที่ scalable, maintainable, และ robust

## When to use

ใช้เมื่อต้องการ:
- ออกแบบระบบซอฟต์แวร์ในระดับ architectural
- เลือก architectural style ที่เหมาะสม
- สร้างระบบที่ scalable และ maintainable
- เข้าใจ architectural patterns และ principles
- ออกแบบ microservices หรือ monolith
- ปรับปรุง architecture ของระบบที่มีอยู่
