# Flutter Core Concepts

## Overview
Flutter is Google's UI toolkit for building natively compiled applications for mobile, web, and desktop.

## Key Concepts
- **Widgets**: Building blocks of Flutter UI
- **State**: Data that can change over time
- **BuildContext**: Widget location in widget tree
- **BuildContext**: Widget location information
- **Keys**: Identifiers for widgets
- **Lifecycle**: App and widget lifecycle events

## Widget Types
- **StatelessWidget**: Immutable widgets
- **StatefulWidget**: Mutable widgets
- **InheritedWidget**: Share data down widget tree
- **FutureBuilder**: Handle async operations
- **StreamBuilder**: Handle stream data

## Architecture Patterns
- **BLoC**: Business Logic Component
- **Provider**: Dependency injection
- **Riverpod**: Improved Provider
- **GetX**: All-in-one solution
