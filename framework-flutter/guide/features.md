# Features

## Flutter Core Features

| Feature | Description |
|---------|-------------|
| **Hot Reload** | รีโหลดโค้ดทันทีโดยไม่สูญเสีย state ของ app |
| **Widgets** | Reusable UI components ที่มี composable nature |
| **Dart Language** | ภาษาที่ optimized สำหรับ UI development |
| **Cross-Platform** | Deploy ไป iOS, Android, Web, Desktop จาก codebase เดียว |
| **Skia Engine** | High-performance 2D rendering engine |

## Widget Categories

### Basic Widgets

| Widget | Description |
|--------|-------------|
| `Text` | แสดงข้อความ |
| `Row` | จัด layout แนวนอน |
| `Column` | จัด layout แนวตั้ง |
| `Container` | Box model สำหรับ styling |
| `Image` | แสดงรูปภาพ |
| `Icon` | แสดงไอคอน |

### Material Widgets

| Widget | Description |
|--------|-------------|
| `Scaffold` | Basic Material Design layout |
| `AppBar` | Top app bar |
| `BottomNavigationBar` | Bottom navigation |
| `FloatingActionButton` | FAB button |
| `Card` | Material card |
| `ListTile` | List item |

### Layout Widgets

| Widget | Description |
|--------|-------------|
| `Stack` | ซ้อน widgets กัน |
| `GridView` | Grid layout |
| `ListView` | Scrollable list |
| `Wrap` | Wrap widgets ไม่ให้ล้น |
| `Expanded` | ให้ widget ขยายเต็มที่ |
| `Flexible` | Flexible layout control |

### Interactive Widgets

| Widget | Description |
|--------|-------------|
| `GestureDetector` | ตรวจจับ gestures |
| `InkWell` | Ripple effect on tap |
| `DragTarget` | Drop target |
| `Dismissible` | Swipe to dismiss |
