# Vite Features

## 1. Instant Server Start

Vite ใช้ ES Modules แทน bundling ทำให้ server เริ่มทำงานได้ทันที ไม่ต้องรอ bundle

## 2. Lightning Fast HMR

Hot Module Replacement ที่รวดเร็ว ไม่ว่า app จะใหญ่แค่ไหน

## 3. Rich Features

- TypeScript / JSX Support
- CSS Pre-processors (Sass, Less, Stylus)
- Asset Optimization
- Source Maps
- Async Chunk Loading

## 4. Optimized Build

ใช้ Rollup สำหรับ production build ที่มีประสิทธิภาพสูง:
- Automatic CSS Code Splitting
- Async Chunk Loading
- Preload Directives
- Dynamic Import Polyfill

## 5. Universal Plugin Interface

ใช้ Rollup plugin interface ที่เข้ากันได้กับ ecosystem ที่กว้างขวาง

## 6. Framework Agnostic

ใช้ได้กับทุก framework: Vue, React, Svelte, Solid, Preact, Lit

## 7. TypeScript Support

รองรับ TypeScript โดยตรง ไม่ต้องตั้งค่าเพิ่มเติม

## 8. Out of the Box

พร้อมใช้งานทันที ไม่ต้องตั้งค่าเยอะ:
- CSS Modules
- CSS Pre-processors
- PostCSS
- JSON Import
- Web Workers
- WASM
