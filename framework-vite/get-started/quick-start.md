# Vite Quick Start

## 1. Prerequisites

ก่อนเริ่มใช้งาน Vite ต้องมี:
- Node.js 18+ หรือเวอร์ชันที่ใหม่กว่า
- npm, yarn, หรือ pnpm

## 2. Installation

สร้างโปรเจกต์ Vite ใหม่ด้วยคำสั่ง:

```bash
# ใช้ npm
npm create vite@latest my-app

# ใช้ yarn
yarn create vite my-app

# ใช้ pnpm
pnpm create vite my-app
```

เลือก framework ที่ต้องการ:
- Vanilla
- Vue
- React
- Preact
- Lit
- Svelte
- Solid

## 3. Basic Usage

เข้าไปในโฟลเดอร์โปรเจกต์:

```bash
cd my-app
```

ติดตั้ง dependencies:

```bash
npm install
```

เริ่ม development server:

```bash
npm run dev
```

เปิด browser ที่ `http://localhost:5173`

## 4. Build for Production

สร้าง production build:

```bash
npm run build
```

Preview production build:

```bash
npm run preview
```
