## When to use

- เมื่อต้องการ ship code ครบวงจรจาก planning ไปจนถึง build
- เมื่อต้องการทดสอบคุณภาพโค้ดด้วย typecheck, lint, และ test
- เมื่อต้องการรัน development server และตรวจสอบการทำงาน
- เมื่อต้องการทำงานตามลำดับขั้นตอนที่เป็นระบบ
- เมื่อต้องการให้ code ผ่านการ verify ทุกด้านก่อน deploy

## Skills Related

- `/ship-code` - Ship code ครบวงจรจาก planning ไปจนถึง build
- `/run-verify` - ทดสอบคุณภาพโค้ดด้วย typecheck, lint, และ test
- `/run-dev` - รัน development server และตรวจสอบการทำงาน
