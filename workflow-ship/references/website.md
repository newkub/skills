# Website

## เว็บไซต์และเอกสารอย่างเป็นทางการ

### Official Documentation

Workflow-Ship เป็น workflow ที่อยู่ในระบบ Windsurf Skills ซึ่งเป็นส่วนหนึ่งของ Windsurf IDE

### Documentation Structure

เอกสารของ Workflow-Ship แบ่งเป็นส่วนต่างๆ ดังนี้:

#### Knowledge/Guide

- **key-concept.md** - แนวคิดหลักของ workflow-ship
- **how-it-works.md** - วิธีการทำงานของ workflow-ship
- **features.md** - ฟีเจอร์หลักของ workflow-ship
- **configuration.md** - การตั้งค่าและ configuration
- **quick-start.md** - เริ่มต้นใช้งานอย่างรวดเร็ว
- **best-practices.md** - แนวทางปฏิบัติที่ดีที่สุด
- **integration.md** - การเชื่อมต่อกับ workflows อื่นๆ
- **architecture.md** - สถาปัตยกรรมของ workflow-ship
- **structure.md** - โครงสร้างและ organization
- **performance.md** - การปรับปรุงประสิทธิภาพ
- **security.md** - ความปลอดภัยและ security best practices
- **migration.md** - การย้ายจาก workflow อื่นมาใช้ workflow-ship
- **ecosystem.md** - ระบบนิเวศและเครื่องมือที่เกี่ยวข้อง
- **testing.md** - การทดสอบและ validation
- **patterns.md** - Patterns ที่ใช้ใน workflow-ship
- **troubleshooting.md** - การแก้ปัญหาที่พบบ่อย
