## When to Use
ใช้เมื่อพัฒนา website ใหม่หรือปรับปรุง website ที่มีอยู่

## Quick Start
1. สร้าง project structure ตามที่กำหนด
2. ติดตั้ง dependencies ที่จำเป็น
3. ตั้งค่า configuration พื้นฐาน
4. พัฒนา components และ pages
5. ทดสอบและ deploy
