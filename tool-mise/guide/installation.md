# Installation

## Installation Command

```bash
npm install -D mise
```

หรือใช้ package managers อื่นๆ:

```bash
# pnpm
pnpm add -D mise

# yarn
yarn add -D mise

# bun
bun add -D mise
```

## Verify Installation

```bash
npx mise --version
```

## Requirements

- Node.js 18+ recommended
- npm, pnpm, yarn, หรือ bun
