# Rust Sources and References

## Official Documentation

### Core Documentation

- **The Rust Programming Language** - <https://doc.rust-lang.org/book/>
  - Comprehensive guide to Rust programming
  - Covers ownership, borrowing, lifetimes, and advanced topics
  - Updated for Rust 2024 edition

- **Rust by Example** - <https://doc.rust-lang.org/rust-by-example/>
  - Collection of runnable examples
  - Learn Rust by experimenting with code
  - Covers syntax, error handling, concurrency, and more

- **Standard Library API** - <https://doc.rust-lang.org/std/>
  - Complete API documentation for Rust standard library
  - Searchable and cross-referenced
  - Includes examples for all functions and types

### Tooling Documentation

- **Cargo Book** - <https://doc.rust-lang.org/cargo/>
  - Complete guide to Cargo package manager
  - Build configuration, dependencies, and workspaces
  - Publishing and packaging guidelines

- **Rustc Book** - <https://doc.rust-lang.org/rustc/>
  - Rust compiler documentation
  - Compiler options and optimizations
  - Target-specific compilation

- **Rustdoc Book** - <https://doc.rust-lang.org/rustdoc/>
  - Documentation generation tool
  - Writing effective documentation
  - Testing documentation examples
