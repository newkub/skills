# Memory Safety in Rust

## Overview

Rust guarantees memory safety through ownership. It prevents null pointers, buffer overflows, and data races. Safety happens at compile time.

## Key Concepts

### Memory Safety Guarantees

- No null pointers use Option<T>
- No buffer overruns with bounds checking
- No data races via ownership system
- No use-after-free with lifetimes
- No double free with ownership

### Stack vs Heap Allocation

- Stack provides fast, fixed-size allocation
- Heap offers slower, dynamic allocation
- Box<T> enables heap allocation
- Copy vs Move semantics control transfer

### Zero-Cost Abstractions

- Safety checks happen at compile time
- No runtime overhead for safety
- Optimizations preserve safety guarantees

## Examples

### Safe Memory Access

```rust
fn main() {
    let vec = vec![1, 2, 3];

    // Safe access with bounds checking
    let third = vec.get(2); // Returns Option<&i32>
    match third {
        Some(value) => println!("Third element: {}", value),
        None => println!("No third element"),
    }

    // Unsafe access panics if out of bounds
    // let third = vec[2]; // Use with caution
}
```

### Option for Null Safety

```rust
fn find_user(id: u32) -> Option<User> {
    if id == 1 {
        Some(User { id, name: "Alice".to_string() })
    } else {
        None
    }
}

fn main() {
    let user = find_user(1);
    match user {
        Some(u) => println!("Found user: {}", u.name),
        None => println!("User not found"),
    }
}
```

### Safe Concurrency

```rust
use std::thread;
use std::sync::Arc;
use std::sync::Mutex;

fn main() {
    let counter = Arc::new(Mutex::new(0));
    let mut handles = vec![];

    for _ in 0..10 {
        let counter_clone = Arc::clone(&counter);
        let handle = thread::spawn(move || {
            let mut num = counter_clone.lock().unwrap();
            *num += 1;
        });
        handles.push(handle);
    }

    for handle in handles {
        handle.join().unwrap();
    }

    println!("Result: {}", *counter.lock().unwrap());
}
```

## Best Practices

1. Use Option for nullable values
2. Prefer Vec over raw arrays
3. Use Arc<Mutex<T>> for shared state
4. Leverage type system for invariants
5. Avoid unsafe code when possible

## Unsafe Rust

Unsafe blocks allow:

- Raw pointer dereferencing
- Calling unsafe functions
- Accessing mutable static variables
- Creating unsafe traits

Document why unsafe is necessary. Ensure safety manually.
