# Rust Usage

## Basic Project Operations

### Creating a New Project
```bash
# Create binary project
cargo new my_project
cd my_project

# Create library project
cargo new my_lib --lib

# Create project in specific directory
cargo new my_project --bin /path/to/directory
```

### Building Projects
```bash
# Debug build
cargo build

# Release build (optimized)
cargo build --release

# Build specific target
cargo build --target x86_64-unknown-linux-musl

# Build with features
cargo build --features "async,database"
```

### Running Projects
```bash
# Run debug build
cargo run

# Run release build
cargo run --release

# Run with arguments
cargo run -- --arg1 --arg2 value

# Run specific binary
cargo run --bin my_binary
```

## Testing

### Running Tests
```bash
# Run all tests
cargo test

# Run specific test
cargo test test_name

# Run tests in specific module
cargo test module_name

# Run tests with output
cargo test -- --nocapture

# Run release tests
cargo test --release
```

### Writing Tests
```rust
// Unit tests in same file
#[cfg(test)]
mod tests {
    use super::*;

    #[test]
    fn test_addition() {
        assert_eq!(2 + 2, 4);
    }

    #[test]
    fn test_panic() {
        panic!("This test will fail");
    }
}

// Integration tests in tests/ directory
// tests/integration_test.rs
use my_project::add;

#[test]
fn test_integration() {
    assert_eq!(add(2, 3), 5);
}
```

## Dependency Management

### Adding Dependencies
```bash
# Add dependency from crates.io
cargo add serde

# Add with specific version
cargo add serde --version "1.0.150"

# Add with features
cargo add serde --features "derive"

# Add development dependency
cargo add criterion --dev

# Add local dependency
cargo add my_lib --path "../my_lib"
```

### Updating Dependencies
```bash
# Update all dependencies
cargo update

# Update specific dependency
cargo update serde

# Update to latest compatible versions
cargo update --allow-prerelease
```

### Removing Dependencies
```bash
# Remove dependency
cargo rm serde

# Remove development dependency
cargo rm criterion --dev
```

## Code Quality Tools

### Formatting
```bash
# Format all code
cargo fmt

# Check formatting without changing files
cargo fmt --check

# Format specific file
cargo fmt -- src/main.rs
```

```bash

cargo clippy
```

## Benchmarking

### Running Benchmarks
```bash
# Install criterion
cargo add criterion --dev

# Run benchmarks
cargo bench

# Run specific benchmark
cargo bench benchmark_name

# Run with output format
cargo bench -- --output-format html
```

### Writing Benchmarks
```rust
use criterion::{black_box, criterion_group, criterion_main, Criterion};

fn fibonacci(n: u64) -> u64 {
    match n {
        0 => 1,
        1 => 1,
        n => fibonacci(n - 1) + fibonacci(n - 2),
    }
}

fn bench_fibonacci(c: &mut Criterion) {
    c.bench_function("fibonacci_20", |b| {
        b.iter(|| fibonacci(black_box(20)))
    });
}

criterion_group!(benches, bench_fibonacci);
criterion_main!(benches);
```

## Debugging

### Debug Builds
```bash
# Build with debug info
cargo build

# Run with debugger
gdb target/debug/my_project

# Run with lldb
lldb target/debug/my_project
```

### Debugging Macros
```rust
// Debug print macro
#[macro_export]
macro_rules! debug_print {
    ($($arg:tt)*) => {
        if cfg!(debug_assertions) {
            println!($($arg)*);
        }
    };
}

// Usage
debug_print!("Debug info: {}", value);
```

### Logging
```bash
# Add logging dependency
cargo add tracing
cargo add tracing-subscriber --features "env-filter"

# Use in code
use tracing::{info, warn, error};

fn main() {
    tracing_subscriber::fmt::init();
    
    info!("Application started");
    warn!("Something unusual happened");
    error!("An error occurred");
}
```

## Performance Analysis

### Profiling
```bash
# Install profiling tools
cargo install cargo-flamegraph

# Generate flame graph
cargo flamegraph --bin my_project

# Profile with perf (Linux)
perf record --call-graph=dwarf ./target/release/my_project
perf report

# Profile with Instruments (macOS)
instruments -t "Time Profiler" ./target/release/my_project
```

### Benchmarking Different Approaches
```rust
use std::time::Instant;

fn benchmark_approaches() {
    let data = vec![1; 1_000_000];
    
    // Approach 1: Iterator
    let start = Instant::now();
    let sum1: i32 = data.iter().sum();
    let duration1 = start.elapsed();
    
    // Approach 2: Loop
    let start = Instant::now();
    let mut sum2 = 0;
    for &item in &data {
        sum2 += item;
    }
    let duration2 = start.elapsed();
    
    println!("Iterator: {:?}, Loop: {:?}", duration1, duration2);
}
```

## Cross-Platform Development

### Cross-Compilation
```bash
# Install target
rustup target add x86_64-unknown-linux-musl

# Build for target
cargo build --target x86_64-unknown-linux-musl

# Run tests on target
cargo test --target x86_64-unknown-linux-musl
```

### WebAssembly
```bash
# Install WebAssembly target
rustup target add wasm32-unknown-unknown

# Build for WebAssembly
cargo build --target wasm32-unknown-unknown

# Install wasm-pack for JavaScript interop
cargo install wasm-pack
wasm-pack build --target web
```

## Continuous Integration

### GitHub Actions
```yaml
name: CI
on: [push, pull_request]

jobs:
  test:
    runs-on: ubuntu-latest
    steps:
    - uses: actions/checkout@v3
    - uses: actions-rs/toolchain@v1
      with:
        toolchain: stable
        override: true
        components: rustfmt, clippy
    
    - name: Check formatting
      run: cargo fmt --check
    
    - name: Run clippy
      run: cargo clippy -- -D warnings
    
    - name: Run tests
      run: cargo test
```

## Common Workflows

### Development Workflow
```bash
# 1. Create feature branch
git checkout -b feature/new-feature

# 2. Make changes
# Edit code...

# 3. Run tests
cargo test

# 4. Check formatting
cargo fmt --check

# 5. Run linter
cargo clippy -- -D warnings

# 6. Build release
cargo build --release

# 7. Commit changes
git add .
git commit -m "Add new feature"

# 8. Push and create PR
git push origin feature/new-feature
```

### Release Workflow
```bash
# 1. Update version in Cargo.toml
# Edit version number...

# 2. Run full test suite
cargo test --all-features

# 3. Build release artifacts
cargo build --release --target x86_64-unknown-linux-musl
cargo build --release --target x86_64-pc-windows-gnu

# 4. Create release tag
git tag -a v1.0.0 -m "Release version 1.0.0"
git push origin v1.0.0

# 5. Publish to crates.io (if library)
cargo publish
```
