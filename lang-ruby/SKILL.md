## When to Use

- Web development (Ruby on Rails)
- Scripting and automation
- DevOps tools
- Rapid prototyping
- API development
- Web services

## Core Features

- **Object-Oriented**: Everything is an object
- **Dynamic Typing**: Flexible type system
- **Metaprogramming**: Powerful code generation
- **Blocks and Procs**: First-class closures
- **Mixins**: Alternative to multiple inheritance
- **Gems**: Rich package ecosystem
