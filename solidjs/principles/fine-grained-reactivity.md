# Fine-Grained Reactivity

## Principle

SolidJS ออกแบบมาเพื่อ fine-grained reactivity:
- **Granular Updates** - updates ที่ granular
- **No Virtual DOM** - ไม่ใช้ virtual DOM
- **Direct DOM** - direct DOM manipulation

## Application

- **Use Signals** - ใช้ signals สำหรับ state
- **Avoid Coarse Updates** - หลีกเลี่ยง coarse updates
- **Optimize Dependencies** - optimize signal dependencies
