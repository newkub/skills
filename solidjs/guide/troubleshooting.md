# Troubleshooting

## Common Issues

### Reactivity Issues

- **Signals Not Updating** - ตรวจสอบ signal dependencies
- **Re-renders** - หลีกเลี่ยง unnecessary re-renders
- **Memory Leaks** - cleanup effects อย่างถูกต้อง

### Build Errors

- **TypeScript Errors** - ตรวจสอบ TypeScript configuration
- **Vite Errors** - ตรวจสอบ Vite configuration
- **Module Resolution** - ตรวจสอบ module resolution

### Performance Issues

- **Slow Renders** - optimize component renders
- **Large Bundle** - optimize bundle size
- **Memory Usage** - optimize memory usage
