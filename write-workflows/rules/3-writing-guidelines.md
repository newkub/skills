# Writing Guidelines Rules

## Strict Rules
- ทุกประโยคต้องใช้ active voice และไม่เกิน 20 คำ
- ห้ามใช้คำเชื่อมที่ไม่ได้ระบุ
- ห้ามใช้ค่าคงที่ที่ไม่ยืดหยุ่น
- ทุก technical term ต้องใช้ภาษาอังกฤษเท่านั้น
- ทุก step ต้องมี verification ที่ชัดเจน
- ห้ามใช้ passive voice โดยเด็ดขาด
- ห้ามใช้คำที่ไม่ชัดเจนหรือหลายความหมาย
- ทุกประโยคต้องมี subject + verb + object ชัดเจน
- ห้ามใช้ภาษาไทยใน headings หรือ technical terms
- ทุก step ต้องมี expected outcome ที่ชัดเจน

## Writing Standards

### Section Ordering
- **ความยาว:** สูงสุด 20 คำต่อประโยค
- **เสียง:** ใช้ active voice เท่านั้น
- **โทน:** ตรง สั่งการ ทำได้จริง
- **ความชัดเจน:** ประโยคต้องมี subject + verb + object ชัดเจน
- **การเว้นวรรค:** เว้นว่าง 1 บรรทัดด้านล่าง heading
- **การเรียงลำดับ:** AI ต้องปฏิบัติตามลำดับที่ระบุอย่างเคร่งครัด ไม่ข้ามขั้นตอน

### Sentence Structure
ใช้เฉพาะคำเชื่อมที่ระบุ:
`ถ้า`, `แล้ว`, `ก็ต่อเมื่อ`, `หลังจาก`, `เช่น`, `และ`, `หรือ`, `จากนั้น`, `เพื่อ`, `โดย`

**Forbidden:** คำเชื่อมแบบภาษาพูด, คำที่ไม่ชัดเจน

### Connectors
**ห้ามใช้ค่าคงที่ที่ไม่ยืดหยุ่น:** ระบุว่าสามารถปรับได้
**ต้องระบุทางเลือก:** ให้หลายวิธีทำได้

### Workflow References
**ใช้ markdown link สำหรับเชื่อมโยง workflows:**
- ใช้ `[workflow-name](workflow-name.md)` แทน `@[/workflow-name]`
- ห้ามใช้ `@[/...]` โดยเด็ดขาด
- ระบุชื่อไฟลที่ถูกต้องทุกตัวอักษร
- ห้ามใช้ absolute paths ใน references

## Verification
- ตรวจสอบความยาวประโยค <= 20 คำ
- ยืนยันการใช้ active voice เท่านั้น
- ตรวจสอบว่าใช้คำเชื่อมที่ระบุเท่านั้น
- ยืนยันว่า technical terms เป็นภาษาอังกฤษ
- ตรวจสอบว่าทุก step มี verification ชัดเจน
