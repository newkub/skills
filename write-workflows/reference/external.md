# External References

## Purpose

รวบรวมแหล่งข้อมูลอ้างอิงภายนอกสำหรับการเขียน workflows และการพัฒนาที่เกี่ยวข้อง

## When to Apply

ใช้แหล่งข้อมูลนี้เมื่อต้องการ:

1. **ศึกษาเทคนิคใหม่** - เรียนรู้เครื่องมือและเทคโนโลยีใหม่
2. **แก้ไขปัญหา** - หา解决方案 จาก community resources
3. **ติดตาม best practices** - เรียนรู้จาก industry leaders
4. **อัพเดทความรู้** - ติดตาม trends และ updates

## Scope

- External documentation และ resources
- Tools และ frameworks ที่เกี่ยวข้อง
- Best practices และ guidelines
- Community resources และ tutorials

## Usage Guidelines

### How to Use These References

1. **Learning New Technologies** - เริ่มจาก official documentation
2. **Problem Solving** - ใช้ community resources และ Q&A sites
3. **Best Practices** - ศึกษาจาก industry leaders
4. **Keeping Updated** - ติดตาม blogs และ communities

### Evaluating Resources

- **Authority** - ตรวจสอบว่าเป็นแหล่งข้อมูลที่น่าเชื่อถือ
- **Currency** - ตรวจสอบว่าข้อมูลเป็นปัจจุบัน
- **Relevance** - ตรวจสอบว่าเกี่ยวข้องกับที่ทำอยู่
- **Completeness** - ตรวจสอบว่าครอบคลุมหัวข้อที่ต้องการ

## Maintenance

### Keeping References Current

- ตรวจสอบ links ประจำงวด
- อัพเดท resources ที่เลิกใช้
- เพิ่ม resources ใหม่ที่เกี่ยวข้อง
- จัดระเบียบตามหมวดหมู่

### Quality Assurance

- ตรวจสอบว่า links ใช้งานได้
- ตรวจสอบว่า content เป็นปัจจุบัน
- ตรวจสอบว่าเกี่ยวข้องกับ workflow development
- จัดลำดับความสำคัญของ resources
