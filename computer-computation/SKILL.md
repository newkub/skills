## Key Concepts

| Concept | คำอธิบาย |
|---------|----------|
| **Turing Machine** | เครื่องจำลองที่ compute ได้ทุกอย่าง |
| **Church-Turing Thesis** | ทุก model เทียบเท่ากัน |
| **NP-Complete** | Hardest problems in NP |
| **Halting Problem** | ตัวอย่างของ undecidable problem |
| **Chomsky Hierarchy** | ประเภทของ formal languages |
