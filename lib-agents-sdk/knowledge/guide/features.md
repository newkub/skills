# Features

## Core Features

- **Persistent State** - SQLite-backed state persistence
- **Callable RPC** - WebSocket-based RPC methods
- **Scheduling** - One-time, recurring, and cron tasks
- **Workflows** - Durable multi-step background processing
- **Durable Execution** - Survives DO eviction
- **Queue** - Built-in FIFO queue with retries
- **Retries** - Exponential backoff with jitter

## Integrations

- **MCP** - Connect to MCP servers or build your own
- **Email** - Receive and reply to emails
- **Webhooks** - Receive external webhooks
- **Push Notifications** - Web Push + VAPID
- **Voice** (experimental) - STT/TTS
- **Browser Tools** (experimental) - CDP browser automation

## Observability

- **Diagnostics Channel** - Events for state, RPC, schedule, lifecycle
- **Logging** - Built-in logging capabilities
