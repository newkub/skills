# Security

## Security Considerations

- **Input Validation** - validate user input
- **CORS** - ตั้งค่า CORS อย่างเหมาะสม
- **Headers** - ใช้ security headers
- **Environment Variables** - ใช้ env vars สำหรับ secrets

## Best Practices

- **Sanitize Data** - sanitize input ก่อนใช้
- **Rate Limiting** - ใช้ rate limiting สำหรับ API
- **HTTPS** - ใช้ HTTPS ใน production
- **Secrets Management** - ใช้ secrets manager
