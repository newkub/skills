# Getting Started with Tauri

## การติดตั้ง CLI

ติดตั้ง Tauri CLI:

```bash
npm install -g @tauri-apps/cli
# หรือ
pnpm add -g @tauri-apps/cli
```

## การสร้าง Project

สร้าง project ใหม่:

```bash
tauri init
```

หรือใช้ template:

```bash
npm create tauri-app@latest
```

## การรัน Development

```bash
npm run tauri dev
# หรือ
pnpm tauri dev
```

## การ Build

```bash
npm run tauri build
# หรือ
pnpm tauri build
```
