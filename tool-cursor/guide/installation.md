# Installation

## Installation Command

```bash
npm install -D cursor
```

หรือใช้ package managers อื่นๆ:

```bash
# pnpm
pnpm add -D cursor

# yarn
yarn add -D cursor

# bun
bun add -D cursor
```

## Verify Installation

```bash
npx cursor --version
```

## Requirements

- Node.js 18+ recommended
- npm, pnpm, yarn, หรือ bun
