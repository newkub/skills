# Best Practices

## AI Usage

| Practice | คำอธิบาย |
|----------|----------|
| **ใช้ Ctrl+K สำหรับ generate** | สร้าง code ได้เร็ว |
| **ใช้ Ctrl+L สำหรับ explain** | อธิบาย code ที่ซับซ้อน |
| **ใช้ Tab สำหรับ complete** | accept suggestion ได้เร็ว |
| **เลือก context ที่ถูกต้อง** | เลือกไฟล์ที่เกี่ยวข้องก่อนใช้ AI |

## Keyboard Shortcuts

| Practice | คำอธิบาย |
|----------|----------|
| **จำ shortcuts หลัก** | Ctrl+K, Ctrl+L, Ctrl+I |
| **ใช้ Tab บ่อยๆ** | รับ suggestion ได้เร็ว |
| **ใช้ Ctrl+Enter** | generate หลาย lines |

## VS Code Migration

| Practice | คำอธิบาย |
|----------|----------|
| **ใช้ extensions เดิม** | VS Code extensions ทำงานได้เลย |
| **export settings** | migrate settings จาก VS Code |
| **ใช้ keybindings เดิม** | ปรับได้ถ้าต้องการ |

## Common Pitfalls

| Pitfall | วิธีหลีกเลี่ยง |
|---------|---------------|
| **AI แนะนำ code ผิด** | ตรวจสอบก่อน accept |
| **Context ไม่ตรง** | เลือกไฟล์ที่ถูกต้องก่อนใช้ AI |
| **Model ไม่เหมาะกับงาน** | เลือก model ให้เหมาะกับ task |
| **การใช้ AI มากเกินไป** | ใช้เมื่อจำเป็น |

## Performance Tips

| Tip | คำอธิบาย |
|-----|----------|
| **ใช้ Fast model** | สำหรับ simple tasks |
| **จำกัด context** | ปิดไฟล์ที่ไม่ใช้ |
| **ใช้ inline AI** | สำหรับ quick edits |
