# Quick Start

## Basic Usage

### 1. Launch Cursor

```bash
# Open Cursor with a specific directory
cursor .

# Open Cursor with a specific file
cursor index.ts

# Open Cursor with multiple files
cursor src/index.ts src/app.ts
```

### 2. AI Commands

| Command | Description |
|---------|-------------|
| `Ctrl+K` | Open AI command input |
| `Ctrl+L` | Chat with AI about current file |
| `Ctrl+I` | Inline AI completion |

### 3. First Project

```bash
# 1. Initialize a new project
mkdir my-project
cd my-project
npm init -y

# 2. Open in Cursor
cursor .

# 3. Start coding with AI assistance
# - Use Ctrl+K to generate code
# - Use Ctrl+L to explain code
# - Use Ctrl+I for inline completions
```
