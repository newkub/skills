# CLI Commands

Command-line interface for Cursor

## Installation

```bash
# Download from cursor.sh
# or use package manager
```

## Commands

| Command | Description | Example |
|---------|-------------|---------|
| `cursor <path>` | Open directory in Cursor | `cursor .` |
| `cursor <file>` | Open specific file | `cursor index.ts` |
| `cursor <file1> <file2>` | Open multiple files | `cursor src/index.ts src/app.ts` |

## Options

| Option | Description |
|--------|-------------|
| `--version` | Show version |
| `--help` | Show help |
| `--new-window` | Open in new window |

## Key Shortcuts Reference

| Shortcut | Action |
|----------|--------|
| `Ctrl+K` | AI Command |
| `Ctrl+L` | AI Chat |
| `Ctrl+I` | Inline AI |
| `Ctrl+Shift+P` | Command Palette |
| `Ctrl+`` | Toggle Terminal |
| `Tab` | Accept suggestion |
| `Ctrl+Enter` | Generate code |

## Configuration

| File | Purpose |
|------|---------|
| `settings.json` | User settings |
| `keybindings.json` | Key bindings |
| `extensions.json` | Recommended extensions |
