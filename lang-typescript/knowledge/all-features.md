## All Features

คุณสมบัติทั้งหมดของ TypeScript

### Core Features

- **Basic Types**: string, number, boolean, array, tuple
- **Object Types**: interfaces, types, classes
- **Advanced Types**: union, intersection, conditional types
- **Generics**: การสร้าง reusable code
- **Decorators**: metadata และ annotations
- **Modules**: import/export systems

### Tooling Features

- **Compiler**: tsc สำหรับ compilation
- **Language Server**: IntelliSense และ error checking
- **Source Maps**: debugging support
- **Declaration Files**: .d.ts สำหรับ libraries

### Advanced Features

- **Type Guards**: runtime type checking
- **Mapped Types**: การสร้าง types จาก existing types
- **Template Literal Types**: types จาก string patterns
- **Variadic Tuple Types**: การจัดการ tuples แบบ dynamic

### Configuration

- **tsconfig.json**: compiler configuration
- **Project References**: การแบ่ง projects
- **Path Mapping**: custom module resolution
