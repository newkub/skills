# Quick Start

## เริ่มต้นใช้งาน

### 1. เรียกใช้ skill

```
/write-dot-devin
```

### 2. ตั้งค่า rules

```
/write-devin-project-rules
```

### 3. ตั้งค่า hooks

```
/write-devin-project-hooks
```

### 4. ตรวจสอบ

ตรวจสอบว่า `.devin/` directory ถูกสร้างและมีไฟล์ครบถ้วน

## ตัวอย่าง

สร้าง .devin structure สำหรับ project ใหม่:

```
/write-dot-devin
```

Cascade จะสร้าง:
- `.devin/rules/` - Project rules
- `.devin/hooks/` - Automation hooks
- `.devin/workflows/` - Custom workflows
