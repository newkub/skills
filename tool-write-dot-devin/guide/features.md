# Features

## Features หลัก

| Feature | Description |
|---------|-------------|
| **Auto Rules** | สร้าง project rules อัตโนมัติตามมาตรฐาน |
| **Auto Hooks** | สร้าง project hooks อัตโนมัติสำหรับ automation |
| **Standards Compliance** | ทำตามมาตรฐาน workflow อัตโนมัติ |
| **Consistent Structure** | โครงสร้าง .devin ที่สม่ำเสมอ |
| **English Content** | เนื้อหาทั้งหมดเป็นภาษาอังกฤษ |

- Project rules generation
- Project hooks generation
- Workflow integration
- Custom configuration
