# Configuration

## .devin Directory Structure

```text
.devin/
├── rules/
│   ├── project-rules.md
│   └── ...
├── hooks/
│   ├── pre-commit.md
│   └── ...
```

## Configuration Files

### rules/project-rules.md

Rules หลักสำหรับ project:

```yaml
---
title: Project Rules
description: Rules สำหรับ project นี้
---
```

### hooks/

Automation hooks สำหรับ events ต่างๆ

## Customization

สามารถปรับแต่ง rules และ hooks ตามความต้องการของ project
