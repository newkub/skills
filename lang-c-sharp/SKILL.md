## When to Use

- ต้องการ cross-platform development ด้วย .NET
- ต้องการ strongly-typed language
- ต้องการ rich standard library
- ต้องการ enterprise-grade applications
- ต้องการ integration กับ Microsoft ecosystem
- ต้องการ async/await ที่ดี

## Core Features

- **Strong Typing**: Static typing พร้อม type inference
- **Async/Await**: Native asynchronous programming
- **LINQ**: Language Integrated Query
- **Garbage Collection**: Automatic memory management
- **Cross-Platform**: .NET Core/.NET 5+ runs everywhere
- **Rich Standard Library**: Extensive BCL
- **Modern Syntax**: Pattern matching, records, etc.
- **Interoperability**: COM, P/Invoke, และ native libraries
