## When to Use

- Web development (Django, Flask, FastAPI)
- Data science and ML
- Automation and scripting
- Scientific computing
- Backend APIs
- DevOps and automation

## Core Features

- **Interpreted Language**: No compilation needed
- **Dynamic Typing**: Flexible type system
- **Readability**: Clean, English-like syntax
- **Extensive Libraries**: Rich standard library and ecosystem
- **Multiple Paradigms**: OOP, Functional, Procedural
- **Cross-platform**: runs everywhere
