# Project Structure

## Overview

WXT ใช้โครงสร้างโปรเจกต์ที่เป็นระบบและเคร่งครัด เพื่อให้การพัฒนา web extensions เป็นไปอย่างมีประสิทธิภาพ

## Required Structure

```
📂 {rootDir}/
├── .output/           # Build artifacts
├── .wxt/              # Generated by WXT (TS config)
├── assets/            # CSS, images, assets
├── components/        # UI components (auto-imported)
├── composables/      # Composable functions (auto-imported)
├── entrypoints/      # Entrypoints ทั้งหมด
├── hooks/            # React/Solid hooks (auto-imported)
├── modules/          # WXT modules
├── public/           # Static files
├── utils/            # Utility functions (auto-imported)
├── .env              # Environment variables
├── .env.publish      # Environment variables for publishing
├── app.config.ts     # Runtime config
├── package.json      # Package manager file
├── tsconfig.json     # TypeScript config
├── web-ext.config.ts # Browser startup config
└── wxt.config.ts     # Main WXT config
```

## Directory Descriptions

### .output/
- **Purpose**: เก็บ build artifacts ทั้งหมด
- **Generated**: สร้างโดย WXT เมื่อ run build
- **Do not edit**: ไม่ควรแก้ไขไฟล์ในโฟลเดอร์นี้

### .wxt/
- **Purpose**: Generated by WXT, contains TS config
- **Generated**: สร้างโดย WXT
- **Do not edit**: ไม่ควรแก้ไขไฟล์ในโฟลเดอร์นี้

### assets/
- **Purpose**: เก็บ CSS, images, และ assets อื่นๆ
- **Processing**: จะถูก process โดย WXT
- **Usage**: Import จาก entrypoints หรือ components

### components/
- **Purpose**: เก็บ UI components
- **Auto-imported**: Auto-import โดย default
- **Usage**: ใช้ได้ทันทีโดยไม่ต้อง import

### composables/
- **Purpose**: เก็บ composable functions สำหรับ Vue
- **Auto-imported**: Auto-import โดย default
- **Usage**: ใช้ได้ทันทีโดยไม่ต้อง import

### entrypoints/
- **Purpose**: เก็บ entrypoints ทั้งหมด
- **Critical**: โฟลเดอร์ที่สำคัญที่สุด
- **Usage**: ทุกไฟล์ในนี้จะถูก bundle เป็นส่วนต่างๆ ของ extension

### hooks/
- **Purpose**: เก็บ hooks สำหรับ React และ Solid
- **Auto-imported**: Auto-import โดย default
- **Usage**: ใช้ได้ทันทีโดยไม่ต้อง import

### modules/
- **Purpose**: เก็บ WXT modules สำหรับโปรเจกต์
- **Usage**: Extend WXT functionality
- **Reference**: [WXT Modules](https://wxt.dev/guide/essentials/wxt-modules)

### public/
- **Purpose**: เก็บ static files
- **Processing**: ไม่ถูก process โดย WXT
- **Usage**: Copy ไปยัง output folder ตามเดิม

### utils/
- **Purpose**: เก็บ utility functions
- **Auto-imported**: Auto-import โดย default
- **Usage**: ใช้ได้ทันทีโดยไม่ต้อง import

### .env
- **Purpose**: Environment variables
- **Usage**: ใช้ใน development และ build
- **Reference**: [Environment Variables](https://wxt.dev/guide/essentials/config/environment-variables)

### .env.publish
- **Purpose**: Environment variables สำหรับ publishing
- **Usage**: ใช้เมื่อ publish extension
- **Reference**: [Publishing](https://wxt.dev/guide/essentials/publishing)

### app.config.ts
- **Purpose**: Runtime config
- **Usage**: Config ที่ใช้ใน runtime
- **Reference**: [Runtime Config](https://wxt.dev/guide/essentials/config/runtime)

### package.json
- **Purpose**: Package manager file
- **Usage**: Dependencies และ scripts
- **Required**: จำเป็นสำหรับทุกโปรเจกต์

### tsconfig.json
- **Purpose**: TypeScript config
- **Usage**: Config การทำงานของ TypeScript
- **Generated**: สร้างโดย WXT

### web-ext.config.ts
- **Purpose**: Browser startup config
- **Usage**: Config การเปิด browser
- **Reference**: [Browser Startup](https://wxt.dev/guide/essentials/config/browser-startup)

### wxt.config.ts
- **Purpose**: Main WXT config
- **Usage**: Config หลักของ WXT
- **Required**: จำเป็นสำหรับทุกโปรเจกต์
- **Reference**: [WXT Config](https://wxt.dev/api/reference/wxt/interfaces/inlineconfig)

## Best Practices

1. **Keep entrypoints clean**: เก็บ logic หลักใน entrypoints และ reuse code ผ่าน components, composables, และ utils
2. **Use auto-imports**: ใช้ประโยชน์จาก auto-imports สำหรับ components, composables, hooks, และ utils
3. **Separate concerns**: แยก logic ตามความเหมาะสม (UI ใน components, logic ใน composables, utilities ใน utils)
4. **Don't edit generated files**: ไม่ควรแก้ไขไฟล์ใน .output/ และ .wxt/
5. **Use public for static assets**: ใช้ public/ สำหรับ static files ที่ไม่ต้องการ processing

## Common Mistakes

1. **Not using entrypoints/**: สร้าง files นอก entrypoints/ จะไม่ถูก bundle
2. **Editing .output/**: ไฟล์ใน .output/ จะถูก overwrite เมื่อ build
3. **Ignoring auto-imports**: ไม่ใช้ auto-imports ทำให้ code ยาวและซ้ำซ้อน
4. **Wrong directory structure**: ไม่ตั้งชื่อโฟลเดอร์ตามที่ WXT คาดหวัง
