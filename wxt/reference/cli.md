# WXT CLI Reference

## Commands

### wxt

เริ่ม development mode:

```bash
wxt
```

### wxt build

Build extension:

```bash
wxt build
```

### wxt zip

Zip extension:

```bash
wxt zip
```

### wxt publish

Publish extension:

```bash
wxt publish
```

### wxt clean

Clean build artifacts:

```bash
wxt clean
```

## Options

### -b, --browser

ระบุ target browser:

```bash
wxt build -b chrome
wxt build -b firefox
wxt build -b edge
wxt build -b safari
```

### -m, --mode

ระบุ mode:

```bash
wxt build -m production
```

### -w, --watch

Watch mode:

```bash
wxt build -w
```
