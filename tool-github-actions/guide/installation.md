# Installation

## No Installation Required

GitHub Actions มีอยู่แล้วใน GitHub - ไม่ต้องติดตั้งอะไรเพิ่มเติม

## Workflow File Location

```
.github/
└── workflows/
    └── ci.yml
```

## Verify GitHub Actions

ไปที่ `https://github.com/{owner}/{repo}/actions` เพื่อดู workflows

## Requirements

| Requirement | Description |
|-------------|-------------|
| GitHub Account | ต้องมี GitHub account |
| Repository | repository ต้องอยู่บน GitHub |
| Write permissions | ต้องมี write permissions เพื่อ commit workflow files |
