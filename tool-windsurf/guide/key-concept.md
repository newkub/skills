# Key Concept

## Purpose

แนวคิดหลักและหลักการทำงานของ Windsurf ที่ทำให้เป็น AI-powered code assistant

## What is Windsurf?

Windsurf เป็น AI code assistant ที่ใช้ large language models สำหรับ:
- Code completion
- Code generation
- Refactoring
- Debugging
- Documentation

## Core Concepts

### 1. AI Model

Windsurf ใช้ AI models สำหรับ:
- Code understanding
- Natural language processing
- Context awareness

### 2. Agent Mode

```bash
# Agent commands
/agent write tests for this function
/agent refactor to use hooks
/agent explain this code
```

### 3. Workflow

```
Input → AI Model → Context → Output
```
