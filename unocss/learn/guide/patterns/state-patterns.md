# State Patterns

## Hover Pattern

ใช้ hover states

```html
<button class="bg-blue-500 hover:bg-blue-600 text-white">
  Button
</button>
```

## Focus Pattern

ใช้ focus states

```html
<input class="border focus:ring-2 focus:ring-blue-500" />
```

## Active Pattern

ใช้ active states

```html
<button class="bg-blue-500 active:bg-blue-700 text-white">
  Button
</button>
```
