# Code Quality

| Aspect | Best Practice | Example |
|--------|---------------|---------|
| **Class Organization** | ใช้ semantic class names | `btn-primary` แทน `bg-blue-500 text-white px-4 py-2` |
| **Consistency** | ใช้รูปแบบเดียวกันทั่วโปรเจกต์ | `flex-center` สำหรับทุกการจัดกลาง |
| **Readability** | จัดกลุ่ม classes ตามหน้าที่ | `flex items-center justify-center` |
| **Maintainability** | ใช้ shortcuts สำหรับ patterns ซ้ำ | `card` สำหรับ card components |
| **Documentation** | บันทึก shortcuts และ theme | Comment ใน uno.config.js |
