# Best Practices

## Performance

- ใช้ on-demand generation เพื่อลดขนาด CSS
- กำหนด safelist สำหรับ dynamic classes
- ใช้ shortcuts สำหรับ patterns ที่ใช้บ่อย

## Organization

- จัดระเบียบ shortcuts ตาม component
- ใช้ semantic class names
- แยก configuration ตาม environment

## Development

- เปิด inspect mode ขณะ development
- ใช้ TypeScript definitions
- ตั้งค่า ESLint rules สำหรับ UnoCSS

## Maintenance

- เก็บ configuration ไว้ใน version control
- ทดสอบ CSS output ใน CI/CD
- อัพเดท UnoCSS version เป็นประจำ
