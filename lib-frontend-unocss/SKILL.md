## When to Execute

เมื่อต้องการติดตั้ง UnoCSS ในโปรเจกต์ใหม่ หรือปรับปรุงการใช้ UnoCSS ในโปรเจกต์ที่มีอยู่

## Quick Start

1. ติดตั้ง UnoCSS และ presets ที่จำเป็น
2. สร้างไฟล์ uno.config.js พร้อม basic configuration
3. เพิ่ม UnoCSS plugin ใน build tool (Vite/Webpack)
4. เริ่มใช้ UnoCSS classes ใน HTML/components
5. ตั้งค่า shortcuts และ theme ตามความต้องการ
