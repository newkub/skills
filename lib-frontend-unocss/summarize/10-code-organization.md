# Code Organization

| Structure | Purpose | Example |
|-----------|---------|---------|
| **Component Shortcuts** | Reusable component styles | `btn`, `card`, `modal` |
| **Layout Shortcuts** | Common layout patterns | `flex-center`, `grid-3-cols` |
| **Theme Files** | Centralized design tokens | `colors.js`, `spacing.js` |
| **Utility Files** | Helper functions | `cssUtils.js` |
| **Config Layers** | Environment-specific configs | `uno.dev.js`, `uno.prod.js` |
| **Documentation** | Style guide reference | `style-guide.md` |
