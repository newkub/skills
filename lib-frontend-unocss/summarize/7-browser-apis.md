# Browser APIs

| API | Integration | Example |
|-----|-------------|---------|
| **Intersection Observer** | Lazy loading styles | `observer.observe(element)` |
| **Resize Observer** | Responsive adjustments | `new ResizeObserver(callback)` |
| **Mutation Observer** | DOM change detection | `new MutationObserver(callback)` |
| **LocalStorage** | Theme persistence | `localStorage.setItem('theme', 'dark')` |
| **MediaQuery API** | Breakpoint detection | `window.matchMedia('(min-width: 768px)')` |
| **CSS Custom Properties** | Dynamic theming | `element.style.setProperty('--color', 'blue')` |
