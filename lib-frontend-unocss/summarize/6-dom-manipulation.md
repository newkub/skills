# DOM Manipulation

| Technique | Purpose | Example |
|-----------|---------|---------|
| **Class Toggling** | เปลี่ยนสถานะ UI | `element.classList.toggle('active')` |
| **Attribute Mode** | ใช้ attributes แทน classes | `element.setAttribute('flex', '')` |
| **Dynamic Styling** | ปรับ style ตาม interaction | `element.className = 'bg-blue-500'` |
| **Event Handling** | เพิ่ม interactive styles | `onmouseover="this.classList.add('hover')"` |
| **Responsive Classes** | เปลี่ยน layout ตามขนาด | `element.classList.add('md:flex')` |
| **Animation Classes** | เพิ่ม animation effects | `element.classList.add('animate-pulse')` |
