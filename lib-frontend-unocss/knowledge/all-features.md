# All Features

## Core Features

- **Instant On-demand**: สร้าง CSS เมื่อต้องการ
- **Fully Customizable**: ปรับแต่งได้ทั้งหมด
- **High Performance**: ทำงานเร็วและเบา
- **Framework Agnostic**: ใช้กับ framework ได้ทุกตัว

## Presets

- **preset-uno**: Tailwind CSS compatible
- **preset-attributify**: Attribute-based styling
- **preset-icons**: Icon system
- **preset-typography**: Typography utilities
- **preset-web-fonts**: Web fonts loading

## Integrations

- **Vite**: Plugin สำหรับ Vite
- **Webpack**: Loader สำหรับ Webpack
- **PostCSS**: Plugin สำหรับ PostCSS
- **CLI**: Command line tools

## Advanced Features

- **Shortcuts**: Custom class combinations
- **Theme**: Custom design tokens
- **Transformers**: CSS transformation rules
- **Inspect Mode**: Development debugging
