# 🤖 AI Agent Workflow Pipeline (ตามลำดับมาตรฐาน)

## When to Execute

ใช้เมื่อต้องการทำงานแบบอัตโนมัติตลอดเวลา 24/7 โดย AI Agent ที่สามารถตัดสินใจและเรียนรู้ด้วยตนเอง

## Quick Start

1. **Goal**: กำหนดเป้าหมายสุดท้ายที่ชัดเจน
2. **Sense**: รับรู้ข้อมูลจากสิ่งแวดล้อม
3. **Understand**: วิเคราะห์และทำความเข้าใจ context
4. **Plan**: วางแผนการทำงาน
5. **Decide**: ตัดสินใจเลือกทางเลือก
6. **Act**: ลงมือปฏิบัติการ
7. **Observe**: สังเกตผลลัพธ์
8. **Reflect**: ประเมินและเรียนรู้
9. **Improve**: ปรับปรุงต่อเนื่อง

---

## 1️⃣ Goal — กำหนดเป้าหมาย

| Action   | ความหมาย           |
| -------- | ------------------ |
| Goal     | กำหนดเป้าหมายสุดท้าย |
| Define   | กำหนดขอบเขต        |
| Identify | ระบุปัญหา          |
| Scope    | ล็อกขอบเขตงาน      |

**Verification:** ตรวจสอบว่าเป้าหมายชัดเจนและวัดผลได้

---

| -------- | ---------------- |

| Collect  | รวบรวมข้อมูล     |

```
Goal → Sense → Understand → Plan → Decide → Act → Observe → Reflect → Improve
```

**Verification:** ตรวจสอบว่าลำดับถูกต้อง

# 🆚 Agent vs Dev Workflow

| Agent Stage | Dev Stage | ความแตกต่างหลัก |
| ----------- | --------- | ---------------- |
| Goal        | Define    | Agent มีเป้าหมายชัดเจน |
| Sense       | -         | Agent รับรู้ข้อมูลตลอด |
| Understand  | Design    | Agent วิเคราะห์ context |
| Plan        | Plan      | คล้ายกัน |
| Decide      | -         | Agent ตัดสินใจอย่างอิสระ |
| Act         | Implement | Agent ปฏิบัติการ |
| Observe     | Test      | Agent สังเกตผลลัพธ์ |
| Reflect     | Review    | Agent เรียนรู้จากผล |
| Improve     | Improve   | คล้ายกัน |

**Verification:** ตรวจสอบว่าการเปรียบเทียบถูกต้อง

---

# 🔄 Agent Continuous Loop

```
[GOAL] → [SENSE] → [UNDERSTAND] → [PLAN] → [DECIDE] → [ACT] → [OBSERVE] → [REFLECT] → [IMPROVE] → (กลับไป SENSE)
```

**Verification:** ตรวจสอบว่า loop ทำงานถูกต้อง

**หมายเหตุ:** Agent ทำงานแบบวนซ้ำตลอดเวลา ไม่ใช่แค่ครั้งเดียว และสามารถตัดสินใจด้วยตนเองได้

## 📋 ตารางสรุป Agent Workflow

| ขั้นตอน | Action Verbs | ผลลัพธ์ที่คาดหวัง | Verification |
| -------- | ------------ | ---------------- | ------------ |
| **Goal** | Define, Identify, Scope | เป้าหมายชัดเจน | วัดผลได้ |
| **Sense** | Observe, Monitor, Collect | ข้อมูลสมบูรณ์ | ถูกต้องครบถ้วน |
| **Understand** | Analyze, Process, Context | เข้าใจโจทย์ | Context ถูกต้อง |
| **Plan** | Strategy, Prioritize, Sequence | แผนสมบูรณ์ | เป็นไปได้ |
| **Decide** | Choose, Evaluate, Commit | ตัดสินใจลงมือทำ | มีเหตุผล |
| **Act** | Execute, Implement, Perform | ดำเนินการสำเร็จ | สำเร็จ |
| **Observe** | Monitor, Track, Measure | ผลลัพธ์ถูกต้อง | ตรงตามเป้าหมาย |
| **Reflect** | Review, Learn, Insight | บทเรียนถูกต้อง | เรียนรู้ได้ |
| **Improve** | Adapt, Optimize, Evolve | ปรับปรุงมีประสิทธิภาพ | ดีขึ้น |

## 🔄 การเปรียบเทียบกับ Dev Workflow

| ----------- | --------- | ---------------- | --------------- |
| Goal | Define | Agent รับจาก Configuration | ชัดเจนตลอด |

| Understand | Design | Agent วิเคราะห์ Context | เข้าใจลึกกว่า |
| Plan | Plan | คล้ายกัน | Agent ทำได้เร็วกว่า |

| Act | Implement | Agent ปฏิบัติการ | 24/7 ทำงาน |
| Observe | Test | Agent สังเกตตลอด | Continuous monitoring |
| Reflect | Review | Agent เรียนรู้จากผล | Learning rate สูง |
| Improve | Improve | คล้ายกัน | Agent เร็วกว่า |
