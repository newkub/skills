# CLI Reference

## Commands

orpc uses unjs/orpc which may include CLI tools for development.

### Development

```bash
# Run development server
orpc dev

# Build for production
orpc build

# Type checking
orpc typecheck
```

### Project Init

```bash
# Create new project
orpc init

# Add to existing project
orpc add
```

## Options

| Flag | Description |
|------|-------------|
| --help | Show help information |
| --version | Show version number |
| --port | Set port number |
| --watch | Enable watch mode |
