# Framework

## Overview

เปรียบเทียบ frameworks สำหรับ web development

## Framework Comparison

| Framework | Category | Key Strength |
|-----------|----------|--------------|
| **React** | UI Library | Ecosystem, flexibility |
| **Vue** | Progressive Framework | Approachable, documentation |
| **Svelte** | Compiler | Performance, bundle size |
| **Angular** | Full Framework | Enterprise, TypeScript |
| **Next.js** | Meta-framework | SSR, routing |
| **Nuxt** | Meta-framework | SSR, Vue ecosystem |

## React Ecosystem

| Category | Libraries |
|---------|-----------|
| **State** | Zustand, Jotai, Redux Toolkit |
| **Routing** | React Router |
| **Data Fetch** | TanStack Query, SWR |
| **Styling** | CSS Modules, Styled Components |
| **Forms** | React Hook Form, Formik |

## Vue Ecosystem

| Category | Libraries |
|---------|-----------|
| **State** | Pinia |
| **Routing** | Vue Router |
| **Data Fetch** | Vue Query |
| **Styling** | UnoCSS, Tailwind |
| **Build** | Vite |

## Svelte Ecosystem

| Category | Libraries |
|---------|-----------|
| **State** | Svelte stores |
| **Routing** | SvelteKit Router |
| **Styling** | Vanilla CSS, UnoCSS |
| **Build** | SvelteKit, Vite |

## Meta-Frameworks

| Feature | Next.js | Nuxt | SvelteKit |
|---------|--------|------|-----------|
| **Rendering** | SSR, SSG, ISR | SSR, SSG, ISR | SSR, SSG |
| **Routing** | File-based | File-based | File-based |
| **API Routes** | Built-in | Built-in | +Form actions |
| **TypeScript** | Native | Native | TypeScript |
| **Deployment** | Vercel, Node.js | Node.js, Edge | Node.js, Edge |

## When to Choose

| Requirement | Recommended |
|-------------|-------------|
| **Simple static sites** | Astro, SvelteKit |
| **Large React app** | Next.js, Remix |
| **Vue app** | Nuxt |
| **Maximum performance** | Svelte |
| **Enterprise/LTS** | Angular |
| **Rapid prototyping** | Vite + React/Vue |

## Summary

| Framework | Best For |
|-----------|----------|
| **React** | Large apps, ecosystem flexibility |
| **Vue** | Approachable, clear documents |
| **Svelte** | Performance, small bundles |
| **Next.js** | React + SEO (SSR) |
| **Nuxt** | Vue + SEO (SSR) |
| **SvelteKit** | Svelte + SSR |
