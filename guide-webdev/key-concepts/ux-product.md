# UX Product Design

## Overview

หลักการออกแบบ product ที่ user-centered

## UX Process

### 1. Discovery

| Phase | Deliverable | Purpose |
|-------|-------------|---------|
| **User Research** | User interviews | Understand needs |
| **Competitive Analysis** | Comparison matrix | Learn from others |
| **Pain Points** | Problem statements | Focus on problems |

### 2. Definition

| Phase | Deliverable | Purpose |
|-------|-------------|---------|
| **Personas** | User archetypes | Target users |
| **User Flows** | Step-by-step paths | Optimal journeys |
| **Jobs to Be Done** | Motivation analysis | Why users act |

### 3. Design

| Phase | Deliverable | Purpose |
|-------|-------------|---------|
| **Wireframes** | Low-fidelity layouts | Structure |
| **Prototypes** | Interactive mockups | Testing |
| **Design System** | Component library | Consistency |

### 4. Validation

| Phase | Deliverable | Purpose |
|-------|-------------|---------|
| **Usability Testing** | Task completion rates | Find issues |
| **A/B Testing** | Conversion metrics | Optimize |
| **Analytics** | User behavior data | Measure |

## Product Metrics

### 1. Engagement Metrics

| Metric | Definition | Target |
|--------|------------|--------|
| **DAU/MAU** | Daily active ratio | > 20% |
| **Session Duration** | Time per visit | Industry-specific |
| **Bounce Rate** | Single-page sessions | < 40% |
| **Page Depth** | Pages per session | > 2.0 |

### 2. Conversion Metrics

| Metric | Definition | Target |
|--------|------------|--------|
| **Conversion Rate** | Goal completions | Industry-specific |
| **Funnel Drop-off** | Stage abandonment | < 20% per stage |
| **Activation Rate** | First-time success | > 40% |

### 3. Retention Metrics

| Metric | Definition | Target |
|--------|------------|--------|
| **Day 1/7/30 Retention** | Returning users | Growing |
| **Churn Rate** | Lost users | < 5% monthly |
| **LTV** | Lifetime value | Growing |

## Design Principles

| Principle | Application |
|-----------|-------------|
| **Don't Make Me Think** | Intuitive interfaces |
| **Consistency** | Predictable behavior |
| **Feedback** | Immediate response |
| **Recovery** | Easy error recovery |
| **Progressive Disclosure** | Layer complexity |

## Summary

| Aspect | Practice |
|--------|----------|
| **Process** | Discover → Define → Design → Validate |
| **Metrics** | Engagement, conversion, retention |
| **Principles** | Usability, feedback, consistency |
| **Testing** | Usability tests, A/B tests |
