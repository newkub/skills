# Key Concept

## Overview

แนวคิดหลักของการพัฒนาเว็บที่ควรเข้าใจก่อนเริ่มต้น

## Scope

- HTML/CSS/JavaScript Fundamentals
- DOM Manipulation
- Browser APIs
- Modern Web Architecture
- Performance Principles

## Core Concepts

### 1. Web Architecture Layers

| Layer | Description | Technologies |
|-------|-------------|--------------|
| **Presentation** | UI และ user interaction | HTML, CSS, JavaScript |
| **Application** | Business logic และ data processing | JavaScript, Web APIs |
| **Data** | Data storage และ retrieval | LocalStorage, IndexedDB, APIs |

### 2. Frontend vs Backend

| Aspect | Frontend | Backend |
|--------|----------|---------|
| **Location** | Client-side (browser) | Server-side |
| **Languages** | JS, CSS, HTML | Node.js, Python, Go, etc. |
| **Focus** | User experience | Business logic, data |
| **Delivery** | Bundled และ served | API endpoints |

### 3. Modern Web Stack

```text
┌─────────────────────────────────────────┐
│            Presentation Layer           │
│   (React/Vue/Svelte + CSS/Tailwind)     │
├─────────────────────────────────────────┤
│            State Management             │
│        (Pinia/Zustand/Redux)            │
├─────────────────────────────────────────┤
│            Data Layer                   │
│      (TanStack Query/SWR/Fetch)        │
├─────────────────────────────────────────┤
│            API Layer                    │
│        (REST/GraphQL/WebSocket)         │
└─────────────────────────────────────────┘
```

### 4. Key Technologies

| Technology | Purpose | Examples |
|------------|---------|----------|
| **HTML5** | Semantic markup | `<header>`, `<main>`, `<nav>` |
| **CSS3** | Styling และ layout | Flexbox, Grid, animations |
| **JavaScript** | Interactivity | ES6+, async/await, modules |
| **Build Tools** | Bundling และ optimization | Vite, Webpack, esbuild |
| **TypeScript** | Type safety | Interfaces, generics |
