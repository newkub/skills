# Web Development Guide

แนวทางการพัฒนา web applications ครบถ้วนจากพื้นฐานถึงขั้นสูง

## Overview

เรียนรู้การพัฒนา web applications แบบครบวงจร ครอบคลุมตั้งแต่พื้นฐาน HTML/CSS/JavaScript ไปจนถึง modern web architecture และ best practices

## Quick Start

1. ติดตั้ง Node.js (`nvm install --lts`)
2. สร้าง project (`npm create vite@latest my-app -- --template react-ts`)
3. รัน dev server (`npm run dev`)
4. เริ่มพัฒนาใน `src/`
