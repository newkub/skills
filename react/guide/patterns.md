# React Design Patterns

## ภาพรวม

Design patterns ที่ใช้กับ React เพื่อเขียน code ที่ maintainable และ scalable

## Topics

- [Component Patterns](patterns/component-patterns.md) - Container/Presentational, HOC, Render Props, Custom Hooks
- [State Patterns](patterns/state-patterns.md) - State Reducer, State Colocation, Lifting State Up
- [Composition Patterns](patterns/composition-patterns.md) - Compound Components, Slot Pattern
- [Performance Patterns](patterns/performance-patterns.md) - Memoization, Lazy Loading, Virtual Scrolling
- [Data Fetching Patterns](patterns/data-fetching-patterns.md) - SWR, Query Invalidation

## สรุป

Design patterns ช่วยให้:
- Code มีความ organized และ maintainable
- Reusable logic ผ่าน hooks และ HOCs
- Flexible composition ผ่าน compound components
- Performance optimization ผ่าน memoization แล lazy loading
- Efficient data management ผ่าน caching และ revalidation
