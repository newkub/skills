# Styling

## ภาพรวม

Libraries สำหรับ styling ใน React applications

## Tailwind CSS

```bash
bun add -D tailwindcss postcss autoprefixer
```

**Features:**
- Utility-first CSS
- Responsive design
- Dark mode
- Custom configuration

## Styled Components

```bash
bun add styled-components
```

**Features:**
- CSS-in-JS
- Component-scoped styles
- Theming
- Dynamic styling

## Emotion

```bash
bun add @emotion/react @emotion/styled
```

**Features:**
- CSS-in-JS
- Performance optimized
- Source maps
- Type-safe styles

## สรุป

Styling libraries:
- Tailwind CSS - Utility-first, responsive design
- Styled Components - CSS-in-JS, component-scoped
- Emotion - CSS-in-JS, performance optimized
