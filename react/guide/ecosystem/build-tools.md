# Build Tools

## ภาพรวม

Build tools สำหรับ React applications

## Vite

```bash
bun add -D vite @vitejs/plugin-react
```

**Features:**
- Fast HMR
- Optimized builds
- Plugin ecosystem
- TypeScript support

## Next.js

```bash
bun create next-app my-app
```

**Features:**
- SSR/SSG
- API routes
- File-based routing
- Image optimization

## Remix

```bash
bun create remix@latest my-app
```

**Features:**
- Nested routing
- Data loading
- Progressive enhancement
- Web standards

## สรุป

Build tools:
