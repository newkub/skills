# State Management

## ภาพรวม

Libraries สำหรับ state management ใน React applications

## Redux

```bash
bun add redux react-redux @reduxjs/toolkit
```

**ใช้เมื่อ:**
- Complex state management
- Large-scale applications
- Need time-travel debugging

## Zustand

```bash
bun add zustand
```

**ใช้เมื่อ:**
- Simple global state
- Medium-scale applications
- Want minimal boilerplate

## Jotai

```bash
bun add jotai
```

**ใช้เมื่อ:**
- Atomic state management
- Need fine-grained reactivity
- Want composable state

## Recoil

```bash
bun add recoil
```

**ใช้เมื่อ:**
- Facebook-style state management
- Need derived state
- Want async state support

## สรุป

State management libraries:
- Redux - Complex state, large apps
- Zustand - Simple global state, medium apps
- Jotai - Atomic state, fine-grained reactivity
- Recoil - Derived state, async support
