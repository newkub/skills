# React Troubleshooting

## ภาพรวม

การแก้ไขปัญหาที่พบบ่อยใน React applications

## Topics

- [Common Issues](troubleshooting/common-issues.md) - ปัญหาทั่วไปเช่น infinite re-renders, stale closures, memory leaks
- [Performance Issues](troubleshooting/performance-issues.md) - ปัญหา performance เช่น slow rendering, large bundle size
- [State Management Issues](troubleshooting/state-management-issues.md) - ปัญหา state management เช่น props drilling, state synchronization
- [Debugging Tools](troubleshooting/debugging-tools.md) - Tools สำหรับ debugging

## สรุป

Troubleshooting best practices:
1. ใช้ React DevTools สำหรับ debugging
2. เขียน clean code และ avoid anti-patterns
3. ใช้ Error Boundaries สำหรับ handle errors
4. Profile performance อย่างสม่ำเสมอ
5. Monitor memory usage และ bundle size
6. Test thoroughly ก่อน deploy
