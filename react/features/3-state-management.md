# React State Management

## 1. Local Component State

- **useState** สำหรอ simple local state
- **useReducer** สำหรอ complex local state
- **State lifting** สำหรอ sharing state ระหว่าง components
- **Prop drilling** และวิธีการหลีกเลี่ยง

## 2. Context API

- **React Context** สำหรอ global state
- **createContext** สำหรอสร้าง context objects
- **useContext** สำหรอ consuming context
- **Provider pattern** สำหรอ context distribution

## 3. State Management Libraries

- **Redux** สำหรอ large-scale applications
- **Zustand** สำหรอ lightweight state management
- **Recoil** สำหรอ Facebook's state management solution
- **Jotai** สำหรอ atomic state management

## 4. Redux Pattern

- **Store** สำหรอ centralized state
- **Actions** สำหรอ state mutations
- **Reducers** สำหรอ pure functions
- **Middleware** สำหรอ side effects

## 5. State Synchronization

- **Server state** กับ client state synchronization
- **Optimistic updates** สำหรอ better UX
- **Cache invalidation** สำหรอ data freshness
- **Real-time updates** สำหรอ live data

## 6. Performance Considerations

- **State normalization** สำหรอ efficient updates
- **Memoization** สำหรอ preventing unnecessary re-renders
- **State partitioning** สำหรอ logical separation
- **Lazy loading** สำหรอ large state objects

## 7. State Persistence

- **Local storage** สำหรอ client-side persistence
- **Session storage** สำหรอ temporary persistence
- **IndexedDB** สำหรอ large data storage
- **State hydration** สำหรอ server-side rendering

## 8. Best Practices

- **Single source of truth** สำหรอ state consistency
- **Immutable updates** สำหรอ predictable state
- **State normalization** สำหรอ efficient storage
- **Separation of concerns** สำหรอ maintainable code
