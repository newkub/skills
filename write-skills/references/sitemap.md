# Write Skills Sitemap

## Documentation Structure

### Root Level

- `SKILL.md` - Index file หลักของ skill

### key-concepts/

แนวคิดสำคัญ

- `skill-types.md` - Skill type classification และ structure

### principles/

หลักการ

- `single-responsibility.md` - Single responsibility principle สำหรับ files

### guide/

เนื้อหาแนะนำและ best practices

- `best-practices.md` - Best practices สำหรับการเขียน skills
- `architecture.md` - โครงสร้างของ skills
- `configuration.md` - การตั้งค่า skills

### references/

เอกสารอ้างอิง

- `api.md` - API documentation สำหรับ skill types
- `cli.md` - CLI commands และ usage
- `website.md` - Link ไปยัง official documentation
- `sitemap.md` - Sitemap ของ documentation นี้

### workflows/

Workflows สำหรับ automation

- `write-skills.md` - สร้าง skill ใหม่
- `update-skills.md` - อัปเดต skill ที่มีอยู่
- `improve-skills.md` - ปรับปรุงคุณภาพ skill ตามมาตรฐาน

### .devin/

Rules และ configurations สำหรับ AI agent

- `goal.md` - เป้าหมายของ skill
- `scope.md` - Scope และ execute steps
- `execute.md` - Execute steps ทั้งหมด
- `expected.md` - Expected outcome
- `rules/always-on/` - Structure files ที่ต้องมีเสมอ
- `rules/glob/` - Files ที่ใช้ glob patterns
- `rules/model_decision/` - Template files สำหรับ model decision
- `workflows/` - Workflow files สำหรับ task automation
