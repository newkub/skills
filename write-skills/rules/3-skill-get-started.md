# Skill Get Started (เนื้อหาใน get-started/)

กำหนดเนื้อหาที่ต้องมีใน get-started/ folder

## 1. Required Files (ไฟล์ที่จำเป็น)

สร้างไฟล์ที่จำเป็นใน get-started/ folder

1. CREATE quick-start.md
2. CREATE features.md
3. CREATE core-principle.md

| ไฟล์ | คำอธิบาย | จำเป็น |
|------|----------|--------|
| quick-start.md | เริ่มต้นใช้งาน | ✓ |
| features.md | รายการฟีเจอร์ | ✓ |
| core-principle.md | หลักการสำคัญ | ✓ |

## 2. Optional Files (ไฟล์ที่ไม่จำเป็น)

สร้างไฟล์ที่เพิ่มเติมถ้าจำเป็น

1. CREATE cli.md (ถ้ามี CLI)
2. CREATE installation.md (ถ้าต้องติดตั้ง)

| ไฟล์ | คำอธิบาย | จำเป็น |
|------|----------|--------|
| cli.md | คำสั่ง CLI | ตามความจำเป็น |
| installation.md | การติดตั้ง | ตามความจำเป็น |

## 3. Quick Start Content (เนื้อหา quick-start.md)

เขียนเนื้อหาใน quick-start.md ตาม format

1. ADD prerequisites section
2. ADD installation steps
3. ADD basic usage examples

````markdown
## 1. Prerequisites

ก่อนเริ่มใช้งาน...

## 2. Installation

ติดตั้งด้วยคำสั่ง...

## 3. Basic Usage

ใช้งานพื้นฐาน...
````

| ส่วน | คำอธิบาย | จำเป็น |
|------|----------|--------|
| Prerequisites | ข้อกำหนดเบื้องต้น | ✓ |
| Installation | การติดตั้ง | ✓ |
| Basic Usage | การใช้งานพื้นฐาน | ✓ |

## 4. Features Content (เนื้อหา features.md)

เขียนเนื้อหาใน features.md ตาม format

1. LIST ฟีเจอร์หลัก
2. EXPLAIN แต่ละฟีเจอร์
3. ADD examples

````markdown
## 1. Feature 1

คำอธิบาย...

## 2. Feature 2

คำอธิบาย...
````

| ส่วน | คำอธิบาย | จำเป็น |
|------|----------|--------|
| Features List | รายการฟีเจอร์ | ✓ |
| Explanation | คำอธิบาย | ✓ |
| Examples | ตัวอย่าง | ✓ |

## 5. Core Principle Content (เนื้อหา core-principle.md)

เขียนเนื้อหาใน core-principle.md ตาม format

1. DEFINE หลักการสำคัญ
2. EXPLAIN แต่ละหลักการ
3. ADD examples

````markdown
## 1. Principle 1

คำอธิบาย...

## 2. Principle 2

คำอธิบาย...
````

| ส่วน | คำอธิบาย | จำเป็น |
|------|----------|--------|
| Principles | หลักการสำคัญ | ✓ |
| Explanation | คำอธิบาย | ✓ |
| Examples | ตัวอย่าง | ✓ |
