# Basic Pattern

## Purpose

ตัวอย่าง pattern ขั้นพื้นฐานที่แสดงโครงสร้างมาตรฐาน

## When to Use

ใช้ pattern นี้เมื่อ:

- กำลังเรียนรู้วิธีสร้าง patterns
- ต้องการ pattern ที่เรียบง่ายที่สุด
- ไม่แน่ใจว่าควรเริ่มต้นอย่างไร

## Implementation

### 1. เริ่มต้นด้วยหัวข้อชัดเจน

```markdown
# [Pattern Name]
```

### 2. อธิบายวัตถุประสงค์

```markdown
## Purpose

คำอธิบายสั้นๆ ว่า pattern นี้ทำอะไร
```

### 3. ระบุเงื่อนไขการใช้

```markdown
## When to Use

สถานการณ์ที่ควรใช้ pattern นี้
```

### 4. แสดงวิธีการ implement

```markdown
## Implementation

ขั้นตอนการ implement แบบ step-by-step
```

### 5. ให้ตัวอย่าง

```markdown
## Example

ตัวอย่างการใช้งานจริง
```

## Example

### Basic Pattern Structure

```markdown
# Simple Pattern

## Purpose

Pattern นี้ใช้สำหรับสร้างไฟล์ configuration พื้นฐาน

## When to Use

- เมื่อต้องการ config file ใหม่
- เมื่อต้องการ standard format
- เมื่อต้องการ consistency

## Implementation

1. สร้างไฟล์ใหม่
2. เพิ่ม basic structure
3. กรอกค่าที่จำเป็น
4. บันทึกไฟล์

## Example

```json
{
  "name": "my-project",
  "version": "1.0.0",
  "description": "Project description"
}
```

## Benefits

- **Consistent** - ทุก project ใช้รูปแบบเดียวกัน
- **Simple** - ง่ายต่อการเข้าใจและใช้งาน
- **Extensible** - สามารถเพิ่ม properties ได้
```

## Benefits

การใช้ pattern นี้ช่วยให้:

- **Standardized** - ทุก patterns มีโครงสร้างเดียวกัน
- **Discoverable** - ทราบได้ทันทีว่ามี content อะไรบ้าง
- **Maintainable** - ง่ายต่อการอัปเดทและแก้ไข
- **Reusable** - สามารถนำไปใช้กับ skills อื่นได้

## Tips

1. **Keep it simple** - เริ่มต้นด้วย pattern ที่เรียบง่าย
2. **Be specific** - ระบุว่า pattern แก้ปัญหาอะไร
3. **Provide examples** - ตัวอย่างช่วยให้เข้าใจง่ายขึ้น
4. **Test it** - ลองใช้ pattern กับกรณีจริง
