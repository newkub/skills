# 2-Usage Guidelines

## Purpose

คำแนะนำการใช้งาน basic skill อย่างมีประสิทธิภาพ

## Basic Usage

### 1. การเริ่มต้นใช้งาน

```bash
# Navigate to skill directory
cd basic-skill

# View skill structure
ls -la

# Read main documentation
cat SKILL.md
```

### 2. การอ่าน Patterns

```bash
# View available patterns
ls patterns/

# Read specific pattern
cat patterns/01-basic-pattern.md
```

### 3. การปฏิบัติตาม Rules

```bash
# Check rules
ls rules/

# Follow setup instructions
cat rules/1-setup.md
```

## Usage Patterns

### Learning Pattern
1. อ่าน SKILL.md ก่อนเพื่อเข้าใจภาพรวม
2. ศึกษา patterns ที่มีอยู่
3. ทำตาม rules ที่กำหนด
4. ลอง implement ตามตัวอย่าง

### Development Pattern
1. เริ่มจาก structure พื้นฐาน
2. เพิ่ม content ตามความต้องการ
3. ตรวจสอบด้วย verification checklist
4. ปรับปรุงตาม feedback

## Common Use Cases

### 1. การเรียนรู้ Structure
- ศึกษา directory organization
- ทำความเข้าใจ file naming
- เรียนรู้ content organization

### 2. การสร้าง Skill ใหม่
- ใช้เป็น template
- ปรับแต่งตามความต้องการ
- เพิ่ม features ที่จำเป็น

### 3. การ Review Skills
- ตรวจสอบ structure ถูกต้อง
- ตรวจสอบ content quality
- ตรวจสอบ compliance

## Best Practices

### Reading Order
1. SKILL.md (ภาพรวม)
2. patterns/ (รูปแบบ)
3. rules/ (กฎการใช้)
4. examples/ (ตัวอย่าง)

### Implementation Order
1. สร้าง structure ก่อน
2. เขียน content หลัง
3. ตรวจสอบสุดท้าย
4. ปรับปรุงตาม loop

## Troubleshooting

### Common Issues
- **Structure not found**: ตรวจสอบว่าสร้าง directories ครบ
- **Content missing**: ตรวจสอบ sections ที่จำเป็น
- **Naming errors**: ตรวจสอบ naming conventions

### Solutions
- ใช้ setup instructions ใหม่
- ตรวจสอบด้วย verification checklist
- อ้างอิงถึง related skills

## Success Criteria

✅ เข้าใจ structure พื้นฐาน  
✅ สามารถใช้ patterns ได้  
✅ ปฏิบัติตาม rules ได้  
✅ สร้าง skill ใหม่ได้  
✅ ตรวจสอบคุณภาพได้
