# Features (ฟีเจอร์และความสามารถ)

รายการฟีเจอร์และความสามารถที่ Write Skills มีให้ใช้

## 1. Standardized Structure (โครงสร้างมาตรฐาน)

Write Skills มีโครงสร้างที่เป็นมาตรฐานสำหรับทุก Skill

1. USE folder structure เดียวกัน
2. USE file naming convention เดียวกัน
3. USE content format เดียวกัน

| ประเภท | รูปแบบ | คำอธิบาย |
|--------|--------|----------|
| Folder | rules, get-started, templates | โครงสร้างมาตรฐาน |
| File Naming | {number}-{prefix}-{name}.md | naming convention |
| Content Format | /write-rules | format ที่ถูกต้อง |

## 2. Clear Organization (การจัดระเบียบที่ชัดเจน)

จัดระเบียบไฟล์และโฟลเดอร์ให้เข้าใจง่าย

1. GROUP rules ไว้ใน rules/
2. GROUP guides ไว้ใน get-started/
3. GROUP templates ไว้ใน templates/

| โฟลเดอร์ | รายการ | คำอธิบาย |
|--------|--------|----------|
| rules/ | 1-skill-folder-structure.md | Rules หลัก |
| get-started/ | quick-start.md | คู่มือเริ่มต้น |
| templates/ | skill-template.md | Template สำหรับสร้าง skill |

## 3. Consistent Naming (การตั้งชื่อที่สอดคล้อง)

ตั้งชื่อไฟล์และโฟลเดอร์ให้สอดคล้องกัน

1. USE prefix เดียวกัน (skill-)
2. USE naming convention เดียวกัน
3. USE format เดียวกัน

| ส่วน | Format | ตัวอย่าง |
|------|--------|----------|
| Prefix | skill- | skill-folder-structure |
| Rules | {number}-{prefix}-{name}.md | 1-skill-folder-structure.md |
| Guides | {prefix}-{name}.md | skill-concepts.md |

## 4. Easy Navigation (การนำทางที่ง่าย)

ทำให้การค้นหาและนำทางไปยังไฟล์ต่างๆ ง่ายขึ้น

1. CREATE SKILL.md เป็น index หลัก
2. ADD tables สรุปใน SKILL.md
3. ADD references ระหว่างไฟล์

| ประเภท | คำอธิบาย | ตัวอย่าง |
|--------|----------|----------|
| Index | SKILL.md เป็นหน้าแรก | ดูภาพรวมทั้งหมด |
| Tables | Rules, Knowledge, Guides | ค้นหาง่าย |
| References | Links ระหว่างไฟล์ | นำทางง่าย |
