# Directory Structure Overview

## โครงสร้างมาตรฐานสำหรับ Skills

## หลักการสำคัญ

1. **MUST Directories** - ต้องมีเสมอ: SKILL.md, execute/, knowledge/, reference/
2. **Optional Directories** - เพิ่มตามความจำเป็น
3. **Empty Directories** - ถ้าไม่มี content → ลบทิ้ง
4. **Naming Convention** - ใช้ kebab-case เสมอ
