# Single Responsibility Principle

แยกไฟล์ตาม responsibilities เพื่อให้ maintainable และ testable

## File Separation

แต่ละไฟล์ควรมีหน้าที่เดียวที่ชัดเจน

- ไฟล์มีหน้าที่เดียว
- หลีกเลี่ยงรวมหลายหัวข้อในไฟล์เดียว
- แยกไฟล์ตามความเฉพาะเจาะจง
- ชื่อไฟล์สะท้อนหน้าที่ของไฟล์

## Benefits

- อ่านง่ายและเข้าใจง่าย
- แก้ไขได้โดยไม่กระทบส่วนอื่น
- test ได้ง่าย
- reuse ได้ง่าย
