# File Naming

## การตั้งชื่อไฟล์

ใช้ `kebab-case` เสมอ ชื่อไฟล์ต้องสอดคล้องกับเนื้อหา

## กฎการตั้งชื่อ

- ใช้ `kebab-case` เสมอ (เช่น `skill-types.md`, `consistent-structure.md`)
- ใช้ชื่อสื่อความหมายโดยตรง ไม่ใช้ prefix ชื่อ skill
- ชื่อไฟล์ต้องสอดคล้องกับเนื้อหา
- ใช้ภาษาอังกฤษสำหรับชื่อไฟล์
- ใช้คำนามเอกพจน์ (singular) สำหรับ folder และไฟล์

## ตัวอย่างที่ถูกต้อง

- ✅ `skill-types.md` - อธิบาย skill types
- ✅ `consistent-structure.md` - อธิบายโครงสร้างที่สม่ำเสมอ
- ✅ `file-naming.md` - อธิบายการตั้งชื่อไฟล์

## ตัวอย่างที่ผิด

- ❌ `SkillTypes.md` - ไม่ใช้ PascalCase
- ❌ `skill_types.md` - ไม่ใช้ snake_case
