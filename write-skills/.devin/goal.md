สร้างหรือแก้ไข Devin Skills ให้เป็นมาตรฐานเดียวกัน เพื่อให้ maintainable และ consistent ทั่วทั้ง workspace

## วัตถุประสงค์

- สร้าง Devin Skills ใหม่ตามมาตรฐานโครงสร้างและ quality
- แก้ไข skills ที่มีอยู่ให้ตรงกับมาตรฐานใหม่
- ทำให้ทุก skill มี structure ที่สม่ำเสมอและ deterministic
- ทำให้ content มีคุณภาพและถูกต้องตาม best practices
- ทำให้ skills ง่ายต่อการ maintain และ extend
