# Getting Started (เริ่มต้นใช้งาน)

เริ่มต้นใช้งาน Write Skills เพื่อสร้าง Skills ที่มีคุณภาพ

## 1. Prerequisites (ข้อกำหนดเบื้องต้น)

ก่อนเริ่มใช้งาน ตรวจสอบว่าคุณมีสิ่งที่จำเป็น

1. CHECK ว่ามีความเข้าใจเกี่ยวกับ /write-rules
2. CHECK ว่ามีความเข้าใจเกี่ยวกับ Markdown format
3. CHECK ว่ามีความเข้าใจเกี่ยวกับ project structure

| ข้อกำหนด | คำอธิบาย | ตรวจสอบ |
|--------|----------|--------|
| /write-rules | เขียน workflow ตาม format | ✓ |
| Markdown | เขียน markdown พื้นฐาน | ✓ |
| Structure | เข้าใจ project structure | ✓ |

## 2. Installation (การติดตั้ง)

ไม่ต้องติดตั้งอะไร เพราะเป็นเอกสารแนวทาง

1. COPY ไฟล์ template
2. MODIFY ตามความต้องการ
3. SAVE ไฟล์ที่สร้าง

## 3. Create Your First Skill (สร้าง Skill แรก)

สร้าง Skill แรกของคุณ

1. CREATE folder structure
2. WRITE SKILL.md
3. CREATE rules files
4. CREATE get-started files

| ขั้นตอน | คำสั่ง | คำอธิบาย |
|--------|--------|----------|
| 1 | mkdir | CREATE folder structure |
| 2 | write | WRITE SKILL.md |
| 3 | write | CREATE rules files |
| 4 | write | CREATE get-started files |

## 4. Next Steps (ขั้นตอนถัดไป)

หลังจากสร้าง Skill แล้ว

1. REVIEW skill ที่สร้าง
2. VERIFY ว่าตรงตาม /write-rules
3. REFINE ตามความต้องการ

| ขั้นตอน | คำอธิบาย |
|--------|----------|
| REVIEW | ตรวจสอบ skill |
| VERIFY | ตรวจสอบ format |
| REFINE | ปรับปรุง skill |
