# Research Type

สร้าง research skills ด้วยโครงสร้างนี้

## Required files
- `SKILL.md` - Main documentation file
- `methodology/` - Methodology directory
- `data/` - Data directory
- `analysis/` - Analysis directory
- `publication/` - Publication directory
- `tools/` - Tools directory
- `ethics/` - Ethics directory

## Acceptance criteria
- Methodology is credible
- Analysis is correct and systematic
- Ethics covers all aspects

## File Structure
```
skill-name/
├── 1. SKILL.md
├── 2. methodology/
├── 3. data/
├── 4. analysis/
├── 5. publication/
├── 6. tools/
└── 7. ethics/
```
