# Skill Types

## Available Types

ดูรายละเอียดประเภท skills ทั้งหมาย:

- **[Library](library.md)** - เอกสารไลบรารีและ API
- **[Blog](blog.md)** - แนวทางการเขียนบล็อก
- **[Project](project.md)** - การจัดการโปรเจกต์
- **[Product](product.md)** - เอกสารผลิตภัณฑ์
- **[Scripts](scripts.md)** - สคริปต์และออโตเมชัน
- **[Business](business.md)** - การดำเนินธุรกิจ
- **[Personal Development](personal-development.md)** - การพัฒนาตนเอง
- **[Communication](communication.md)** - การสื่อสาร
- **[Research](research.md)** - การวิจัยและการวิเคราะห์
- **[Programming Language](programming-language.md)** - การเรียนรู้และพัฒนาภาษาโปรแกรม
- **[Idea](idea.md)** - การสร้างและพัฒนาไอเดีย
- **[Workflows](workflows.md)** - การออกแบบและจัดการ workflows
