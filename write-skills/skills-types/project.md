# Project Type

สร้าง project skills ด้วยโครงสร้างนี้

## Required files
- `SKILL.md` - Main documentation file
- `setup/` - Project setup directory
- `configuration/` - Config files directory
- `deployment/` - Deployment guides directory

## Acceptance criteria
- Setup guides work end-to-end
- Configuration covers all environments
- Deployment includes rollback steps

## File Structure
```
skill-name/
├── 1. SKILL.md
├── 2. setup/
├── 3. configuration/
└── 4. deployment/
```
