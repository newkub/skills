# Library Type

สร้าง library skills ด้วยโครงสร้างนี้

## Required files
- `SKILL.md` - Main documentation file
- `get-started/introduction.md` - Project overview
- `get-started/goal.md` - Objectives definition
- `get-started/configuration.md` - Setup instructions
- `get-started/usage.md` - Basic examples
- `get-started/key-concept.md` - Core concepts
- `get-started/core-principles.md` - Fundamental rules
- `guide/` - Advanced tutorials directory
- `examples/` - Code samples directory
- `apis/` - API documentation directory

## Acceptance criteria
- All required files must exist
- File paths follow exact naming convention
- Documentation covers all aspects

## File Structure
```
skill-name/
├── 1. SKILL.md
├── 2. get-started/
│   ├── 1. introduction.md
│   ├── 2. goal.md
│   ├── 3. configuration.md
│   ├── 4. usage.md
│   ├── 5. key-concept.md
│   └── 6. core-principles.md
├── 3. guide/
├── 4. examples/
└── 5. apis/
```
