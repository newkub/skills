# Business Type

สร้าง business skills ด้วยโครงสร้างนี้

## Required files
- `SKILL.md` - Main documentation file
- `strategy/` - Business strategy directory
- `operations/` - Operations directory
- `finance/` - Finance directory
- `marketing/` - Marketing directory
- `management/` - Management directory
- `resources/` - Resources directory

## Acceptance criteria
- Strategy covers all business dimensions
- Operations have clear steps
- Finance includes planning and control

## File Structure
```
skill-name/
├── 1. SKILL.md
├── 2. strategy/
├── 3. operations/
├── 4. finance/
├── 5. marketing/
├── 6. management/
└── 7. resources/
```
