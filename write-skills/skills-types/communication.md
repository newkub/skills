# Communication Type

สร้าง communication skills ด้วยโครงสร้างนี้

## Required files
- `SKILL.md` - Main documentation file
- `speaking/` - Speaking directory
- `writing/` - Writing directory
- `presentation/` - Presentation directory
- `listening/` - Listening directory
- `feedback/` - Feedback directory
- `cultural/` - Cultural communication directory

## Acceptance criteria
- Speaking skills have various techniques
- Writing has appropriate formats for contexts
- Presentations have clear structure

## File Structure
```
skill-name/
├── 1. SKILL.md
├── 2. speaking/
├── 3. writing/
├── 4. presentation/
├── 5. listening/
├── 6. feedback/
└── 7. cultural/
```
