# Personal Development Type

สร้าง personal development skills ด้วยโครงสร้างนี้

## Required files
- `SKILL.md` - Main documentation file
- `goals/` - Goals directory
- `habits/` - Habits directory
- `learning/` - Learning directory
- `productivity/` - Productivity directory
- `wellness/` - Wellness directory
- `planning/` - Planning directory

## Acceptance criteria
- Goals are clear and measurable
- Habits have systematic creation steps
- Learning has clear paths

## File Structure
```
skill-name/
├── 1. SKILL.md
├── 2. goals/
├── 3. habits/
├── 4. learning/
├── 5. productivity/
├── 6. wellness/
└── 7. planning/
```
