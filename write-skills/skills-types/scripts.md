# Scripts Type

สร้าง script skills ด้วยโครงสร้างนี้

## Required files
- `SKILL.md` - Main documentation file
- `scripts/` - Script files directory
- `dependencies/` - Requirements documentation
- `execution/` - Run instructions

## Acceptance criteria
- Scripts include error handling
- Dependencies list all requirements
- Execution covers all use cases

## File Structure
```
skill-name/
├── 1. SKILL.md
├── 2. scripts/
├── 3. dependencies/
└── 4. execution/
```
