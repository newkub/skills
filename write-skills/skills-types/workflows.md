# Workflows Type

สร้าง workflow skills ด้วยโครงสร้างนี้

## Required Files
- `SKILL.md` - Main documentation file
- `design/` - Workflow design and architecture directory
- `automation/` - Automation and integration directory
- `templates/` - Workflow templates and patterns directory
- `execution/` - Execution and monitoring directory

## Acceptance Criteria
- All required directories exist
- Design covers workflow architecture principles
- Automation includes integration patterns
- Templates provide reusable workflows

## File Structure
```
skill-name/
├── 1. SKILL.md
├── 2. design/
├── 3. automation/
├── 4. templates/
└── 5. execution/
```

## Verification Steps
1. Check all required directories exist
2. Verify design architecture completeness
3. Test automation integration patterns
4. Confirm template reusability
