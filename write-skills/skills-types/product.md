# Product Type

สร้าง product skills ด้วยโครงสร้างนี้

## Required files
- `SKILL.md` - Main documentation file
- `features/` - Feature documentation
- `user-guides/` - User instructions
- `admin/` - Administration guides

## Acceptance criteria
- Features list matches product capabilities
- User guides cover all workflows
- Admin guides include troubleshooting

## File Structure
```
skill-name/
├── 1. SKILL.md
├── 2. features/
├── 3. user-guides/
└── 4. admin/
```
