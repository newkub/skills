# Blog Type

สร้าง blog skills ด้วยโครงสร้างนี้

## Required Files
- `SKILL.md` - Main documentation file
- `styles/` - Writing guidelines directory
- `language/` - Language rules directory
- `format/` - Formatting standards directory
- `examples/` - Blog samples directory

## Acceptance Criteria
- All required directories exist
- Style guidelines cover writing standards
- Examples demonstrate proper formatting

## File Structure
```
skill-name/
├── 1. SKILL.md
├── 2. styles/
├── 3. language/
├── 4. format/
└── 5. examples/
```

## Verification Steps
1. Check all required directories exist
2. Verify style guidelines completeness
3. Test example formatting validity
4. Confirm structure matches template
