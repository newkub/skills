# Key Concept

## What is Anime.js?

Anime.js is a lightweight JavaScript animation library with a simple API for animating CSS properties, SVG, DOM nodes, and JavaScript objects

## Core Features

| Feature | Description |
|---------|-------------|
| Simple API | Easy to learn |
| Performance | Hardware accelerated |
| Multiple targets | Animate many elements |
| Timeline | Sequence animations |
| Easing | Built-in easing functions |

## Key Concepts

| Concept | Description |
|---------|-------------|
| Targets | Elements to animate |
| Properties | CSS properties |
| Keyframes | Animation steps |
| Timeline | Sequential animations |
| Easing | Timing functions |
