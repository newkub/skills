# Installation

## CDN

```html
<script src="https://cdnjs.cloudflare.com/ajax/libs/animejs/3.2.1/anime.min.js"></script>
```

## NPM

```bash
npm install animejs
```

## Yarn

```bash
yarn add animejs
```

## Bun

```bash
bun add animejs
```

## ES Modules

```javascript
import anime from 'animejs';
```

## CommonJS

```javascript
const anime = require('animejs');
```

## Verify Installation

```javascript
console.log(anime.version);
```
