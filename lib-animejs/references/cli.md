# CLI Reference

Anime.js is primarily used via CDN or npm, no CLI required.

## Package Manager

```bash
# npm
npm install animejs

# yarn
yarn add animejs

# bun
bun add animejs
```

## CDN Usage

```html
<script src="https://cdnjs.cloudflare.com/ajax/libs/animejs/3.2.1/anime.min.js"></script>
```

## Development Tools

| Tool | Usage |
|------|-------|
| DevTools | Debug animations in browser |
| Live Server | Hot reload during development |
| TypeScript | Type definitions (optional) |
