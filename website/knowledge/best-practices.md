## Website Best Practices

### Performance Best Practices
1. ใช้ lazy loading สำหรับ images และ components ที่ไม่จำเป็นต้องโหลดทันที
2. Optimize images ด้วย WebP หรือ AVIF format
3. ใช้ code splitting สำหรับ JavaScript bundles
4. ใช้ caching strategies ที่เหมาะสม
5. Minify CSS, JavaScript และ HTML

### Accessibility Best Practices
1. ใช้ semantic HTML tags (header, nav, main, footer)
2. เพิ่ม ARIA labels สำหรับ screen readers
3. ตรวจสอบ color contrast ratio (WCAG AA)
4. รองรับ keyboard navigation ทั้งหมด
5. ใช้ focus indicators ที่ชัดเจน
6. รองรับ prefers-reduced-motion

### SEO Best Practices
1. ใช้ meta tags ที่ครบถ้วน (title, description, og tags)
2. ใช้ semantic HTML และ heading hierarchy ที่ถูกต้อง
3. เพิ่ม structured data (JSON-LD)
4. สร้าง sitemap.xml และ robots.txt
5. ใช้ descriptive URLs และ alt text
6. ตรวจสอบ mobile-friendliness

### Code Quality Best Practices
1. ใช้ TypeScript สำหรับ type safety
2. ทำ code review อย่างสม่ำเสมอ
3. เขียน tests สำหรับ features สำคัญ
4. ใช้ linters และ formatters (ESLint, Prettier)
5. ทำ documentation สำหรับ components ที่ซับซ้อน

### User Experience Best Practices
1. ออกแบบ mobile-first approach
2. ใช้ consistent design system
3. ให้ feedback ทันทีเมื่อผู้ใช้ทำ action
4. ใช้ loading states ที่ชัดเจน
5. ทำ error handling ที่ดี
6. รองรับ dark mode
