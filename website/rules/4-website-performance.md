## Overview

This rule covers web performance metrics and optimization techniques.

## Bad Practices

- Not measuring Core Web Vitals
- Blocking rendering with large JavaScript bundles
- Not optimizing for mobile devices
- Not implementing service workers
- Not using performance monitoring tools

## Good Practices

- Monitor Core Web Vitals (LCP, FID, CLS)
- Use performance monitoring tools (Lighthouse, WebPageTest)
- Implement critical CSS and inline it
- Use service workers for offline support
- Optimize for mobile-first approach
- Use performance budgets
- Implement progressive enhancement
