## Overview

This rule covers SEO fundamentals to improve website visibility in search engines.

## Bad Practices

- Not using semantic HTML
- Missing meta tags (title, description)
- Not optimizing images with alt text
- Not having proper heading structure
- Not implementing structured data
- Not having sitemap.xml
- Not having robots.txt

## Good Practices

- Use semantic HTML5 elements
- Include proper meta tags (title, description, keywords)
- Optimize images with descriptive alt text
- Use proper heading hierarchy (H1, H2, H3)
- Implement structured data (Schema.org)
- Create and submit sitemap.xml
- Configure robots.txt properly
- Ensure mobile-friendly design
- Improve page load speed
- Create quality, relevant content
