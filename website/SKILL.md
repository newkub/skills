## When to Apply

This skill should be applied during the design and development phases of any web project to ensure fundamental principles are met, resulting in a better user experience and a more effective website.

- When creating a new website or application
- When redesigning an existing website
- During a UI/UX audit of a web property
- When optimizing web performance
- When implementing SEO strategies
