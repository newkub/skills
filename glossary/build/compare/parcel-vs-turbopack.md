# Parcel vs Turbopack

## เปรียบเทียบ

| หัวข้อ | Parcel | Turbopack |
|--------|--------|-----------|
| **Config** | Zero config | Vite-like minimal |
| **Speed** | Fast | Extremely fast (Rust) |
| **Dev Server** | Built-in | Webpack successor |
| **Production** | Optimized | Next.js focus |
| **Caching** | Disk cache | Persistent, granular |
| **Ecosystem** | General purpose | Next.js ecosystem |
| **HMR** | Fast | Lightning fast |
| **Bundling** | All-in-one | Incremental |
| **Maturity** | 2017, stable | 2022, evolving |
| **Best For** | Quick starts, prototyping | Next.js, scale |

## เมื่อไหร่ใช้อะไร

- **Parcel**: Zero-config needs, quick prototypes, simple apps
- **Turbopack**: Next.js apps, performance critical, scale
