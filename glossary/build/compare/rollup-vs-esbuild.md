# Rollup vs esbuild

## เปรียบเทียบ

| หัวข้อ | Rollup | esbuild |
|--------|--------|---------|
| **Speed** | Moderate | Extremely fast (Go) |
| **Output** | Optimized ESM/CJS | Fast bundling |
| **Tree Shaking** | Excellent | Good |
| **Plugins** | Rich ecosystem | Limited |
| **Config** | Extensive | Minimal |
| **TypeScript** | Via plugins | Native |
| **Use Case** | Libraries, optimization | Development, CI speed |
| **Production** | Preferred | Emerging |
| **Maturity** | 2015, proven | 2020, growing |
| **Best For** | NPM packages | App bundling |

## เมื่อไหร่ใช้อะไร

- **Rollup**: Library authors, tree-shaking priority, production bundles
- **esbuild**: Development speed, CI/CD, TypeScript projects
