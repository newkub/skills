# Boy Scout Rule

## คำอธิบาย
"Leave the code better than you found it" - ทำให้โค้ดดีขึ้นเมื่อแก้ไข

## ลักษณะเฉพาะ
- **Continuous Improvement**: ปรับปรุงโค้ดทุกครั้งที่แก้ไข
- **Small Refactoring**: แก้ไขเล็กๆ น้อยๆ ต่อเนื่อง
- **Code Hygiene**: รักษาความสะอาดของโค้ด
- **Technical Debt Prevention**: ป้องกันการสะสมของ technical debt

## การปฏิบัติ
- **Rename Variables**: ใช้ชื่อที่ชัดเจนขึ้น
- **Extract Functions**: แยก logic ที่ซ้ำกัน
- **Remove Dead Code**: ลบโค้ดที่ไม่ได้ใช้
- **Add Comments**: เพิ่มคำอธิบายที่จำเป็น
- **Fix Formatting**: จัดรูปแบบโค้ดให้สวยงาม

## ข้อดี
- Reduces technical debt
- Improves code quality over time
- Easier maintenance
- Better team collaboration

## ข้อเสีย
- Time investment
- Scope creep risk
- Review complexity
- Requires discipline

## เหมาะกับ
- All development teams
- Legacy code maintenance
- Code reviews
- Continuous integration
