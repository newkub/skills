# Formatters

## คำอธิบาย
เครื่องมือที่จัดรูปแบบโค้ดอัตโนมัติตาม style guide ที่กำหนด

## ลักษณะเฉพาะ
- **Consistent Formatting**: รูปแบบโค้ดสม่ำเสมอ
- **Auto-fix**: แก้ไข formatting issues อัตโนมัติ
- **Configurable**: ปรับแต่ง style rules ได้
- **IDE Integration**: ทำงานร่วมกับ editors

## ประเภทของ Formatters
- **JavaScript**: Prettier, Biome
- **TypeScript**: Prettier, dprint
- **Rust**: rustfmt
- **Python**: Black, isort

## ข้อดี
- Code consistency
- Reduced code review time
- Automatic formatting
- Team agreement

## ข้อเสีย
- Opinionated formatting
- Configuration debates
- Build step addition
- Learning curve

## เหมาะกับ
- Team projects
- Open source projects
- Code reviews
- Consistent code style
