# Remote vs Office vs Hybrid

## เปรียบเทียบ

| หัวข้อ | Remote | Office | Hybrid |
|--------|--------|--------|--------|
| **Collaboration** | Async-first, written | Sync, spontaneous | Mixed modes |
| **Commute** | None | Daily | 2-3 days/week |
| **Focus Time** | Deep work possible | Interrupted | Balance needed |
| **Hiring Pool** | Global | Local | Wider than local |
| **Overhead** | Home office setup | Office lease | Both |
| **Culture** | Intentional documentation | Watercooler moments | Coordination challenge |
| **Timezone** | 24h possible | Same hours | Flexibility |
| **Onboarding** | Structured, self-serve | Shadowing | Blended |
| **Innovation** | Slower serendipity | Whiteboard sessions | Scheduled innovation |
| **Wellbeing** | Isolation risk | Burnout risk | Best of both? |

## เมื่อไหร่ใช้อะไร

- **Remote**: Global talent, individual contributors, established processes
- **Office**: Early stage, rapid pivoting, hardware collaboration
- **Hybrid**: Best of both, requires intentional design
