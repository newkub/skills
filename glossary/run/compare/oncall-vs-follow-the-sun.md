# On-Call Rotation vs Follow-the-Sun

## เปรียบเทียบ

| หัวข้อ | On-Call Rotation | Follow-the-Sun |
|--------|------------------|----------------|
| **Coverage** | 24/7 with night shifts | Handoff between timezones |
| **Sleep Disruption** | Night pages | Normal working hours |
| **Response Time** | Minutes (on-call awake) | Hours (next day) |
| **Team Structure** | Single location | Global distribution |
| **Cost** | Shift premiums | Distributed headcount |
| **Context** | Same team fixes | Handoff documentation |
| **Burnout Risk** | Higher | Lower |
| **Complexity** | Simple scheduling | Coordination overhead |
| **Escalation** | Direct to on-call | Next timezone takes over |
| **Best For** | High severity, urgent | Business hours acceptable |

## เมื่อไหร่ใช้อะไร

- **On-Call Rotation**: Critical systems, immediate response required
- **Follow-the-Sun**: Global teams, non-critical, cost optimization
