# Structured vs Open Retrospectives

## เปรียบเทียบ

| หัวข้อ | Structured Format | Open Discussion |
|--------|-------------------|-----------------|
| **Format** | Mad/Sad/Glad, 4Ls, Sailboat | Free conversation |
| **Timeboxed** | Yes, per category | Organic flow |
| **Participation** | Everyone contributes | Extroverts dominate |
| **Documentation** | Template output | Scattered notes |
| **Safety** | Anonymous input possible | Direct conversation |
| **Novelty** | Rotating formats | Same every time |
| **Facilitation** | Requires preparation | Self-moderating |
| **Action Items** | Clear next steps | Fuzzy commitments |
| **Energy** | Engaging activities | Can become routine |
| **Best For** | New teams, conflict | Mature teams, trust |

## เมื่อไหร่ใช้อะไร

- **Structured**: Building safety, diverse voices, action orientation
- **Open**: High trust, experienced teams, complex feelings
