# Formal vs Informal Communication

## เปรียบเทียบ

| หัวข้อ | Formal Communication | Informal Communication |
|--------|---------------------|----------------------|
| **Medium** | Email, meetings, docs | Slack, hallway chats |
| **Documentation** | Written, archived | Ephemeral, verbal |
| **Response Time** | Scheduled, slower | Immediate |
| **Tone** | Professional, careful | Casual, spontaneous |
| **Decision Record** | Clear trail | Fuzzy memory |
| **Scope** | Cross-org, external | Team internal |
| **Preparation** | Required | Minimal |
| **Escalation** | Natural path | Avoided |
| **Onboarding** | Self-serve docs | Relationship-based |
| **Best For** | Stakeholders, compliance | Daily work, quick wins |

## เมื่อไหร่ใช้อะไร

- **Formal**: Decisions, stakeholders, compliance, remote onboarding
- **Informal**: Daily collaboration, problem solving, team building
