# Mob Programming vs Pair Programming

## เปรียบเทียบ

| หัวข้อ | Mob Programming | Pair Programming |
|--------|-----------------|------------------|
| **Team Size** | 3+ people | 2 people |
| **Setup** | One computer, projector | Two keyboards, one screen |
| **Driver Rotation** | Frequent (10 min) | As needed |
| **Knowledge** | Whole team knows all | Pair knows, wider gaps |
| **Decision Speed** | Immediate consensus | Two-person agreement |
| **Cost** | High (whole team) | Moderate |
| **Distractions** | Reduced | Some interruptions |
| **Skill Leveling** | Fast equalization | Gradual |
| **Use Case** | Complex problems, onboarding | Daily work, focus |
| **Energy** | Intense, draining | Sustainable |

## เมื่อไหร่ใช้อะไร

- **Mob Programming**: Complex architecture, team learning, critical decisions
- **Pair Programming**: Daily development, focused work, knowledge sharing
