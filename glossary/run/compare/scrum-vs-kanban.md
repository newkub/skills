# Scrum vs Kanban

## เปรียบเทียบ

| หัวข้อ | Scrum | Kanban |
|--------|-------|--------|
| **Cadence** | Fixed sprints (1-4 weeks) | Continuous flow |
| **Roles** | SM, PO, Dev Team | No prescribed roles |
| **Ceremonies** | 5 prescribed events | Optional, flexible |
| **Change During** | Locked in sprint | Anytime, WIP limits |
| **Metrics** | Velocity, burndown | Cycle time, throughput |
| **Commitment** | Sprint forecast | Pull when ready |
| **Estimation** | Required (story points) | Optional |
| **Board** | Reset each sprint | Persistent |
| **Best For** | Product teams, planning | Support, ops, flow |
| **Implementation** | Heavy, structured | Light, evolutionary |

## เมื่อไหร่ใช้อะไร

- **Scrum**: Product development, feature teams, predictable delivery
- **Kanban**: Maintenance, support, unpredictable work, continuous delivery
