# Pair Programming vs Solo Programming

## เปรียบเทียบ

| หัวข้อ | Pair Programming | Solo Programming |
|--------|------------------|------------------|
| **Code Quality** | Higher (immediate review) | Variable |
| **Knowledge Sharing** | Real-time transfer | Async, documentation |
| **Defects** | Fewer bugs | More bugs caught later |
| **Focus** | Sustained (accountability) | Prone to distraction |
| **Learning** | Accelerated mentorship | Self-paced |
| **Cost** | 2x person-hours | Standard cost |
| **Productivity** | Lower short-term | Higher short-term |
| **Morale** | Social, less isolation | Independent, flexible |
| **Onboarding** | Fast integration | Slower ramp-up |
| **Best For** | Complex tasks, juniors | Simple tasks, deep focus |

## เมื่อไหร่ใช้อะไร

- **Pair Programming**: Critical code, training, complex architecture
- **Solo Programming**: Deep work, familiar tasks, individual expertise
