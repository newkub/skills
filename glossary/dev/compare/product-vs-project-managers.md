# Product Managers vs Project Managers

## เปรียบเทียบ

| หัวข้อ | Product Managers (PM) | Project Managers (PM) |
|--------|-----------------------|-----------------------|
| **Focus** | What and Why | When and How |
| **Success Metric** | User value, market fit | On time, on budget |
| **Scope** | Product vision, roadmap | Project delivery |
| **Stakeholder** | Customers, business | Team, executives |
| **Decision** | Feature prioritization | Resource allocation |
| **Timeline** | Long-term, iterative | Fixed, milestones |
| **Flexibility** | Pivot based on feedback | Scope control |
| **Skills** | Domain, UX, analytics | Planning, risk, communication |
| **Outcome** | Product success | Project completion |
| **Best For** | Software products | Construction, consulting |

## เมื่อไหร่ใช้อะไร

- **Product Managers**: Software products, customer-centric, innovation
- **Project Managers**: Fixed scope, deadlines, budget constraints
