# Sync vs Async Code Review

## เปรียบเทียบ

| หัวข้อ | Sync Code Review | Async Code Review |
|--------|------------------|-------------------|
| **Timing** | Scheduled meeting | PR comments anytime |
| **Bandwidth** | High (voice, whiteboard) | Low (text only) |
| **Context** | Immediate clarification | Delayed questions |
| **Timezone** | Requires overlap | Any timezone |
| **Documentation** | Meeting notes | Comment thread |
| **Depth** | Deep dive possible | Surface level typical |
| **Social** | Relationship building | Transactional |
| **Urgency** | Hotfixes, complex PRs | Standard flow |
| **Tooling** | Screen share, in-person | GitHub, GitLab |
| **Best For** | Complex architecture, learning | Daily flow, distributed |

## เมื่อไหร่ใช้อะไร

- **Sync**: Complex changes, onboarding, critical systems
- **Async**: Daily workflow, clear changes, timezone distributed
