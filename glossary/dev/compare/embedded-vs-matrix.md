# Embedded Teams vs Matrix Organization

## เปรียบเทียบ

| หัวข้อ | Embedded Teams | Matrix Organization |
|--------|----------------|---------------------|
| **Structure** | Cross-functional, dedicated | Functional reporting, project-based |
| **Focus** | Product outcome | Functional excellence |
| **Manager** | Product/Tech lead | Two bosses (solid + dotted) |
| **Loyalty** | Team goal | Department goal |
| **Communication** | Co-located collaboration | Multiple channels |
| **Career Growth** | Generalist path | Specialist ladder |
| **Resource Allocation** | Fixed to product | Flexible to priority |
| **Context Switching** | Single focus | Multiple projects |
| **Best For** | Stable products, long-term | Consultancies, shared services |
| **Complexity** | Simple, clear | Complex, political |

## เมื่อไหร่ใช้อะไร

- **Embedded**: Product companies, stable roadmaps, ownership culture
- **Matrix**: Shared resources, multiple clients, expertise centers
