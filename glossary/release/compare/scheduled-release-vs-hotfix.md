# Scheduled Release vs Hotfix

## เปรียบเทียบ

| หัวข้อ | Scheduled Release | Emergency Hotfix |
|--------|-------------------|------------------|
| **Timing** | Planned date | Immediate |
| **Process** | Full QA, regression | Minimal testing |
| **Communication** | Release notes, marketing | Incident response |
| **Risk** | Managed, expected | High, unknown |
| **Rollback** | Standard procedure | Emergency revert |
| **Features** | Bundled | Single fix only |
| **Approval** | Release management | Emergency authority |
| **Monitoring** | Standard | Intensified |
| **Best For** | Regular updates | Production incidents |
| **Velocity** | Planned cadence | Interrupted flow |

## เมื่อไหร่ใช้อะไร

- **Scheduled Release**: Normal development, feature bundles, planning
- **Hotfix**: Critical bugs, security issues, downtime mitigation
