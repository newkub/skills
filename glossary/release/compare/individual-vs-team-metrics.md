# Individual Metrics vs Team Metrics

## เปรียบเทียบ

| หัวข้อ | Individual Metrics | Team Metrics |
|--------|--------------------|--------------|
| **Focus** | Personal output | Collective outcome |
| **Competition** | Pitting developers against | Collaboration incentive |
| **Gaming** | Optimize personal stats | Optimize system |
| **Knowledge Sharing** | Hoard to look better | Share to improve team |
| **Visibility** | Leaderboards, rankings | Dashboard trends |
| **Performance Review** | Individual contribution | Team impact |
| **Side Effects** | Hero culture, burnout | Shared accountability |
| **Examples** | Commits, lines of code | Velocity, cycle time, quality |
| **Best For** | Sales, commission roles | Software development |
| **Culture** | Individual achievement | We succeed together |

## เมื่อไหร่ใช้อะไร

- **Individual**: Sales teams, clear individual ownership, contractors
- **Team**: Software teams, complex interdependence, knowledge work
