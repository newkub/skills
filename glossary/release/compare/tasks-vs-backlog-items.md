# Tasks vs Backlog Items

## เปรียบเทียบ

| หัวข้อ | Tasks | Backlog Items |
|--------|-------|---------------|
| **Granularity** | Small, actionable | Varying sizes |
| **Origin** | Broken down from stories | Ideas, requests |
| **Estimation** | Hours | Points |
| **Assignment** | Individual | Team/ungrouped |
| **Completion** | Checkbox done | Story delivered |
| **Visibility** | Task board | Product backlog |
| **Scope** | Technical steps | User value |
| **Priority** | Order within story | Product priority |
| **Tooling** | Sub-tasks, checklists | Jira, Azure DevOps |
| **Best For** | Implementation tracking | Value delivery |

## เมื่อไหร่ใช้อะไร

- **Tasks**: Sprint execution, tracking progress, individual work
- **Backlog Items**: Prioritization, product planning, value focus
