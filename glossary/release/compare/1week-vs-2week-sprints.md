# 1-Week vs 2-Week Sprints

## เปรียบเทียบ

| หัวข้อ | 1-Week Sprints | 2-Week Sprints |
|--------|----------------|----------------|
| **Planning** | Lightweight | More detailed |
| **Adaptability** | Rapid pivoting | Stable iteration |
| **Overhead** | Higher ceremony ratio | Lower overhead |
| **Commitment** | Small batches | Larger goals |
| **Risk** | Less per sprint | More at stake |
| **Review** | Frequent feedback | More to demo |
| **Retrospective** | Weekly learning | Bi-weekly |
| **Predictability** | Lower velocity variance | Smoother trends |
| **Team Maturity** | Requires discipline | Tolerates learning |
| **Best For** | Fast iteration, ops | Feature development |

## เมื่อไหร่ใช้อะไร

- **1-Week**: Maintenance, support, rapid experimentation, ops
- **2-Week**: Product features, complex stories, stable teams
