# Epics vs User Stories

## เปรียบเทียบ

| หัวข้อ | Epics | User Stories |
|--------|-------|--------------|
| **Granularity** | Large, coarse-grained | Small, implementable |
| **Duration** | Multiple sprints | Single sprint |
| **Estimation** | Rough, t-shirt sizes | Points, hours |
| **Purpose** | Roadmap, grouping | Implementation |
| **Deliverable** | No direct delivery | Working software |
| **Hierarchy** | Parent container | Child work items |
| **Stakeholder** | Business, executives | Development team |
| **Progress** | Epic burndown | Sprint completion |
| **Splitting** | Broken into stories | Broken into tasks |
| **Best For** | Roadmap themes | Sprint planning |

## เมื่อไหร่ใช้อะไร

- **Epics**: Roadmap planning, grouping features, stakeholder communication
- **User Stories**: Sprint execution, implementation guidance, delivery
