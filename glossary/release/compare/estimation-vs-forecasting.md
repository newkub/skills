# Estimation vs Forecasting

## เปรียบเทียบ

| หัวข้อ | Estimation | Forecasting |
|--------|-----------|-------------|
| **Basis** | Expert judgment | Historical data |
| **Certainty** | Single point | Range (probability) |
| **Precision** | Hours, days | "60% confidence by X" |
| **Meeting Time** | Lengthy discussion | Data review |
| **Accuracy** | Often optimistic | More realistic |
| **Method** | Planning poker, gut feel | Monte Carlo, throughput |
| **Commitment** | Often treated as deadline | Probability-based |
| **Change** | Resisted | Expected |
| **Tooling** | Planning apps | Cycle time charts |
| **Best For** | Fixed bid, contracts | Agile delivery, flow |

## เมื่อไหร่ใช้อะไร

- **Estimation**: Fixed-price contracts, traditional project management
- **Forecasting**: Agile teams, flow-based delivery, probabilistic planning
