# OKRs vs KPIs

## เปรียบเทียบ

| หัวข้อ | OKRs | KPIs |
|--------|------|------|
| **Purpose** | Set ambitious goals | Measure ongoing performance |
| **Timeframe** | Quarterly, stretch | Continuous, baseline |
| **Success** | 70% is good | 100% target |
| **Scope** | Qualitative + quantitative | Purely quantitative |
| **Ownership** | Team/individual objectives | Department metrics |
| **Alignment** | Cross-functional | Siloed |
| **Innovation** | Encourages risk | Maintains status quo |
| **Cascading** | Company → Team → Individual | Fixed dashboards |
| **Review** | Weekly check-ins | Real-time dashboards |
| **Best For** | Growth, transformation | Operations, maintenance |

## เมื่อไหร่ใช้อะไร

- **OKRs**: Startup growth, innovation, strategic initiatives
- **KPIs**: Operational excellence, mature businesses, monitoring
