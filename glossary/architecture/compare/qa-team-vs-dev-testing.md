# QA Team vs Developer Testing

## เปรียบเทียบ

| หัวข้อ | Dedicated QA Team | Developer Testing |
|--------|-------------------|-------------------|
| **Responsibility** | Separate team | Own code |
| **Perspective** | User-focused | Implementation-focused |
| **Bug Discovery** | Black box testing | White box testing |
| **Speed** | Sequential handoff | Parallel, immediate |
| **Cost** | Headcount overhead | Embedded in dev |
| **Quality Mindset** | Gatekeeper | Built-in |
| **Test Types** | E2E, manual, exploratory | Unit, integration |
| **Release Blocker** | QA approval | CI/CD automated |
| **Shift Left** | Limited | Full |
| **Best For** | Regulated, complex UIs | Agile, continuous delivery |

## เมื่อไหร่ใช้อะไร

- **QA Team**: Healthcare, finance, complex enterprise software
- **Developer Testing**: Modern agile, CI/CD, developer ownership
