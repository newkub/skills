# Reactive vs Proactive Monitoring

## เปรียบเทียบ

| หัวข้อ | Reactive Monitoring | Proactive Monitoring |
|--------|---------------------|----------------------|
| **Trigger** | Alerts on failure | Alerts before failure |
| **Mindset** | Firefighting | Prevention |
| **Metrics** | Errors, outages | Trends, capacity, anomalies |
| **Response** | Incident response | Adjustments, scaling |
| **Cost** | Downtime expensive | Monitoring investment |
| **SLA Impact** | Breaches happen | Breaches prevented |
| **Tooling** | PagerDuty, logs | SLOs, predictive ML |
| **Team Stress** | High alert fatigue | Sustainable |
| **User Impact** | Visible outages | Invisible prevention |
| **Best For** | Legacy, unavoidable | Modern SRE, reliability |

## เมื่อไหร่ใช้อะไร

- **Reactive**: Legacy systems, limited resources, starting point
- **Proactive**: SRE culture, customer trust, scale economics
