# Manual Testing vs Automated Testing

## เปรียบเทียบ

| หัวข้อ | Manual Testing | Automated Testing |
|--------|----------------|-------------------|
| **Speed** | Slow, human-paced | Fast, repeatable |
| **Cost** | Recurring labor | Upfront investment |
| **Coverage** | Exploratory, creative | Consistent, comprehensive |
| **Regression** | Boring, error-prone | Reliable, tireless |
| **Setup** | Minimal | Significant |
| **Maintenance** | Per release | Per code change |
| **Feedback** | Delayed | Immediate in CI |
| **UX Evaluation** | Human judgment | No visual assessment |
| **Complexity** | Any user scenario | Codable scenarios |
| **Best For** | New features, usability | Regression, APIs, unit tests |

## เมื่อไหร่ใช้อะไร

- **Manual**: Exploratory, UX validation, edge cases
- **Automated**: CI/CD, regression, API contracts, performance
