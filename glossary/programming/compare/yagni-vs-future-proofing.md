# YAGNI vs Future-Proofing

## เปรียบเทียบ

| หัวข้อ | YAGNI (You Ain't Gonna Need It) | Future-Proofing |
|--------|--------------------------------|-----------------|
| **Philosophy** | Build only what's needed now | Anticipate future needs |
| **Complexity** | Minimal | Higher abstraction |
| **Flexibility** | Refactor when needed | Extension points built-in |
| **Cost** | Pay only for current | Upfront investment |
| **Risk** | Under-engineering | Over-engineering |
| **Change Cost** | Acceptable rewrite | Designed for change |
| **Prediction** | Avoid guessing | Based on roadmap |
| **Delivery** | Faster to market | Slower initial |
| **Debt** | Clean slate later | Accumulates complexity |
| **Best For** | Startups, uncertainty | Platforms, known scale |

## เมื่อไหร่ใช้อะไร

- **YAGNI**: MVPs, uncertain requirements, rapid iteration
- **Future-Proofing**: Platforms, APIs, known scale requirements
