# TDD vs BDD

## เปรียบเทียบ

| หัวข้อ | TDD (Test-Driven Development) | BDD (Behavior-Driven Development) |
|--------|-------------------------------|-----------------------------------|
| **Focus** | Unit tests, implementation | Business behavior, user stories |
| **Language** | Technical, developer-centric | Ubiquitous language, Gherkin |
| **Who Writes** | Developers | Developers + Product + QA |
| **Granularity** | Low-level functions | High-level features |
| **Test Syntax** | assert(), expect() | Given-When-Then |
| **Cycle** | Red-Green-Refactor | Discovery-Formulation-Automation |
| **Documentation** | Technical specs | Living documentation |
| **Tooling** | Jest, Vitest, xUnit | Cucumber, SpecFlow |
| **Collaboration** | Solo/Pair | Cross-functional |
| **Output** | Working code | Shared understanding |

## เมื่อไหร่ใช้อะไร

- **TDD**: Algorithm logic, complex calculations, library development
- **BDD**: User-facing features, team alignment, acceptance criteria
