# Static Typing vs Dynamic Typing

## เปรียบเทียบ

| หัวข้อ | Static Typing | Dynamic Typing |
|--------|---------------|----------------|
| **Checking** | Compile-time | Runtime |
| **Errors** | Early detection | Late discovery |
| **Refactoring** | Tool-assisted, safe | Manual, risky |
| **Documentation** | Types as docs | Comments needed |
| **Performance** | Often optimized | Runtime checks |
| **Flexibility** | Less (strict contracts) | More (duck typing) |
| **Learning** | Steeper curve | Faster start |
| **Examples** | TypeScript, Java, Rust | Python, JavaScript, Ruby |
| **Tooling** | Rich IDE support | Basic autocomplete |
| **Best For** | Large codebases, teams | Prototypes, small scripts |

## เมื่อไหร่ใช้อะไร

- **Static Typing**: Production systems, team collaboration, refactoring
- **Dynamic Typing**: Rapid prototyping, exploratory coding, simple scripts
