# Imperative vs Declarative Programming

## เปรียบเทียบ

| หัวข้อ | Imperative | Declarative |
|--------|-----------|-------------|
| **Approach** | How to do it | What to achieve |
| **Control Flow** | Explicit steps | Implicit engine |
| **State** | Mutable, step-by-step | Transformed, derived |
| **Examples** | C, Java, for loops | SQL, React, Haskell |
| **Readability** | More verbose | More concise |
| **Debugging** | Step through | Trace logic |
| **Optimization** | Manual | Engine optimizes |
| **Side Effects** | Common | Minimized |
| **Learning** | Procedural thinking | Functional thinking |
| **Best For** | Performance, control | Data flow, UI, queries |

## เมื่อไหร่ใช้อะไร

- **Imperative**: Performance critical, low-level, fine control needed
- **Declarative**: UI development, data queries, maintainability
