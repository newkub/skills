# Waterfall vs Agile

## เปรียบเทียบ

| หัวข้อ | Waterfall | Agile |
|--------|-----------|-------|
| **Process** | Sequential phases | Iterative, incremental |
| **Planning** | Upfront, detailed | Adaptive, rolling wave |
| **Change** | Resistant, costly | Embraced, welcome |
| **Delivery** | Big bang at end | Continuous value |
| **Feedback** | Late in cycle | Immediate, frequent |
| **Documentation** | Heavy, comprehensive | Just enough |
| **Risk** | Discovered late | Early identification |
| **Stakeholder** | Limited involvement | Constant collaboration |
| **Scope** | Fixed | Flexible, prioritized |
| **Best For** | Fixed requirements, compliance | Innovation, uncertainty |

## เมื่อไหร่ใช้อะไร

- **Waterfall**: Construction, healthcare, strict regulations
- **Agile**: Software products, startups, evolving markets
