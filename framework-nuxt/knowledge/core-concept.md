# Nuxt.js Core Concepts

## Overview
Nuxt.js is a Vue.js framework for building universal applications.

## Key Concepts
- **Auto-imports**: Automatic component and function imports
- **File-based routing**: Automatic route generation
- **Server Components**: Components that render on server
- **Client Components**: Interactive components
- **Composables**: Reusable composition functions
- **Plugins**: Extend Nuxt functionality

## Rendering Modes
- **SSR**: Server-Side Rendering
- **SSG**: Static Site Generation
- **SPA**: Single Page Application

## Directory Structure
- `pages/`: Route pages
- `components/`: Vue components
- `layouts/`: Layout templates
- `plugins/`: Nuxt plugins
- `middleware/`: Route middleware
- `server/`: Server API routes
