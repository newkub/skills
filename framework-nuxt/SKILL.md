# framework-nuxt

## When to use

- เมื่อต้องการสร้าง Vue.js applications ด้วย SSR/SSG
- เมื่อต้องการ SEO-friendly web applications
- เมื่อต้องการ auto-imports และ file-based routing
- เมื่อต้องการ modern Vue 3 features และ TypeScript support
