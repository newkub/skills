# lib-tsdown

## Overview

แนวทางการใช้ tsdown สำหรับ TypeScript library bundling — เครื่องมือที่ใช้ Rolldown (Rust-based) สำหรับสร้าง bundle อย่างรวดเร็ว รองรับ ESM, CJS, IIFE, UMD formats และ TypeScript declarations อัตโนมัติ
