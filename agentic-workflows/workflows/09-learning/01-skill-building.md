## Prerequisites

- ระบุทักษะที่ต้องการพัฒนา
- เข้าใจ current skill level และ target level
- มี resources และ time สำหรับ learning

## 3.1 Precondition

- Learning goals ชัดเจน
- Resources (courses, docs, mentors) พร้อม
- Practice environment พร้อมใช้งาน
- Timeline สำหรับ skill building ถูกกำหนด

## 3.2 Prepare

- สร้าง learning plan ที่ structured
- รวบรวม learning resources
- เตรียม practice projects หรือ exercises
- กำหนด milestones และ checkpoints

## 3.3 Execute

1. Learn theory และ concepts

   - ใช้ `search_web` หา learning resources
   - ใช้ `skill` โหลด skills ที่เกี่ยวข้อง
   - ใช้ `mcp2_query-docs` หา technical documentation
   - ใช้ `read_file` อ่าน tutorials และ guides

2. Practice hands-on

   - ใช้ `write_to_file` สร้าง practice projects
   - ใช้ `run_command` รัน exercises และ challenges
   - ใช้ `edit` แก้ไข code จาก feedback
   - ใช้ `todo_list` ติดตาม learning progress

3. Apply และ demonstrate

   - ใช้ `code_search` หา real-world applications
   - ใช้ `browser_preview` แสดง projects
   - ใช้ `create_memory` บันทึก achievements
   - สร้าง portfolio หรือ demonstrations

## 3.4 Validate

- [ ] Concepts เข้าใจอย่างถูกต้อง
- [ ] Practice exercises ทำสำเร็จ
- [ ] Skills ใช้งานได้จริง
- [ ] Knowledge ทดสอบแล้ว

## 3.5 Verify

- [ ] ยืนยันว่าถึง target skill level
- [ ] ตรวจสอบว่า apply ได้จริง
- [ ] ยืนยันว่าพร้อมใช้งาน
- [ ] ตรวจสอบว่า learning documented
