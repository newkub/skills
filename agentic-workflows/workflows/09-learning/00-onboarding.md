## Prerequisites

- มีสมาชิกใหม่หรือทีมที่ต้องการ onboard
- เข้าใจ roles และ responsibilities ของผู้ที่จะ onboard
- มี documentation และ resources พร้อม

## 3.1 Precondition

- Onboarding plan ถูกกำหนดแล้ว
- Access และ permissions พร้อมสำหรับสมาชิกใหม่
- Documentation และ training materials ครบถ้วน
- Mentor หรือ buddy ถูก assign แล้ว

## 3.2 Prepare

- รวบรวม onboarding checklist
- เตรียม accounts, access, และ tools
- จัดระเบียบ documentation และ resources
- กำหนด milestones สำหรับ onboarding

## 3.3 Execute

1. Setup environment และ access

   - ใช้ `list_dir` สำรวจ project structure
   - ใช้ `read_file` อ่าน setup guides
   - ใช้ `run_command` รัน setup scripts
   - ใช้ `write_to_file` สร้าง personal configs

2. Learn project และ domain

   - ใช้ `skill` โหลด knowledge เกี่ยวกับ project
   - ใช้ `read_file` อ่าน documentation
   - ใช้ `code_search` สำรวจ codebase
   - ใช้ `mcp2_query-docs` หา technical documentation

3. Complete onboarding tasks

   - ใช้ `todo_list` ติดตาม onboarding progress
   - ใช้ `run_command` รัน hello-world tasks
   - ใช้ `browser_preview` ทดสอบ local setup
   - ใช้ `create_memory` บันทึก learning journey

## 3.4 Validate

- [ ] Environment setup สมบูรณ์
- [ ] Access ทั้งหมดทำงานได้
- [ ] Basic tasks ทำได้สำเร็จ
- [ ] Documentation เข้าใจได้

## 3.5 Verify

- [ ] ยืนยันว่าพร้อมทำงานจริง
- [ ] ตรวจสอบว่าเข้าใจ project
- [ ] ยืนยันว่ารู้จักทีมและ processes
- [ ] ตรวจสอบว่า onboarding complete
