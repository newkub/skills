---

## 1. Prepare

- เข้าใจโครงสร้างโปรเจกต์เป้าหมาย
- อ่าน file patterns ที่กำหนดใน SKILL.md
- ตรวจสอบ dependencies ที่อาจได้รับผลกระทบ

## 2. Execute

1. จัดการไฟล์
   - ใช้ commands ที่มีอยู่ใน commands/
   - ตรวจสอบความปลอดภัยก่อนดำเนินการ
   - สำรองข้อมูลสำคัญ

2. จัดโครงสร้าง
   - ตั้งชื่อไฟล์ตาม naming convention
   - จัดเรียงไฟล์ให้เหมาะสม
   - อัพเดท references ที่เกี่ยวข้อง

## 3. Validate

- [ ] ตรวจสอบไฟล์ยังทำงานได้ปกติ
- [ ] ยืนยัน paths ถูกต้อง
- [ ] ตรวจสอบไม่มีไฟล์หาย
