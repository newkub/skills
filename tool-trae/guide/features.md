# Features

## Purpose

ฟีเจอร์หลักของ Trae IDE

## Core Features

### 1. AI Code Generation

| Feature | Description |
|---------|-------------|
| **Comment-to-Code** | เขียน comment แล้ว Trae สร้างโค้ดให้ |
| **Inline Completion** | แนะนำโค้ดขณะพิมพ์ |
| **Multi-language** | รองรับ Python, JavaScript, TypeScript และอื่นๆ |

### 2. Builder Mode

| Feature | Description |
|---------|-------------|
| **Planning First** | วางแผนก่อนเขียนโค้ด |
| **Step Preview** | ดูขั้นตอนที่จะทำก่อน execute |
| **Multi-file** | จัดการ project-wide changes |
| **Edit Plan** | แก้ไข plan ก่อน apply |

### 3. Chat Interface

| Feature | Description |
|---------|-------------|
| **Dual Modes** | General chat และ Inline chat |
| **Attachments** | แนบ screenshot, error log |
| **Context Awareness** | เข้าใจ code context ของ project |
| **Terminal Commands** | แนะนำและ run shell commands |

### 4. Free AI Models

| Model | Description |
|-------|-------------|
| **Claude 3.5 Sonnet** | Default model, balanced performance |
| **Claude 3.7** | Latest model, enhanced reasoning |

### 5. MCP Support

| Feature | Description |
|---------|-------------|
| **Tool Integration** | เชื่อมต่อกับ external tools |
| **Figma Plugin** | UI-aware development ผ่าน Figma |
| **Custom Agents** | สร้าง customizable agent system |

### 6. Terminal Integration

| Feature | Description |
|---------|-------------|
| **Command Suggestions** | แนะนำ commands จาก natural language |
| **Direct Execution** | Run commands ได้โดยตรงจาก chat |
| **Error Handling** | แสดง solutions เมื่อ command ผิดพลาด |
