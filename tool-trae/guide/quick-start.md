# Quick Start

## Purpose

คู่มือเริ่มต้นใช้งาน Trae IDE อย่างรวดเร็ว

## Prerequisites

| Requirement | Description |
|-------------|-------------|
| OS | Windows, macOS, Linux |
| Internet | ต้องมี internet สำหรับ AI features |
| Account | สมัคร free ที่ trae.ai |

## Installation Steps

### 1. Download

```bash
# ไปที่เว็บไซต์
https://trae.ai

# กดปุ่ม Download
```

### 2. Install

| OS | Action |
|----|--------|
| Windows | รันไฟล์ `.exe` installer |
| macOS | ลาก `.app` ไปที่ Applications |
| Linux | Extract แล้วรัน executable |

### 3. First Launch

```text
┌─────────────────────────────────────────┐
│  🚀 Trae IDE First Launch               │
├─────────────────────────────────────────┤
│                                         │
│  1. Welcome Screen                      │

│     - Light / Dark / System             │

│  3. AI Model Selection                  │
```

## Basic Usage

### Open/Create Project

```text
# วิธีที่ 1: File menu
File → Open Folder / New Folder

# วิธีที่ 2: Shortcut
Ctrl+O (Windows/Linux)
Cmd+O (macOS)
```

### Use AI Chat

```text
# เปิด Chat Panel
Ctrl+Shift+L (Windows/Linux)
Cmd+Shift+L (macOS)

# ส่งข้อความ
"Explain this function"
"Fix the bug in line 42"
"Add unit tests"
```

### Use Builder Mode

```text
# เปิด Builder Mode
Ctrl+B (Windows/Linux)
Cmd+B (macOS)

# Describe your task
"Create a login page with email validation"

# Review preview
# Confirm or edit plan
# Execute
```

### Terminal Suggestions

```text
# ใน Chat
"Show me how to install dependencies"

# AI จะแนะนำ command
# คุณเลือกได้:
# - Paste to terminal
# - Run directly
```

## Common Shortcuts

| Action | Windows/Linux | macOS |
|--------|---------------|-------|
| Open Chat | `Ctrl+Shift+L` | `Cmd+Shift+L` |
| Builder Mode | `Ctrl+B` | `Cmd+B` |
| Command Palette | `Ctrl+Shift+P` | `Cmd+Shift+P` |
| Quick Chat | `Ctrl+I` | `Cmd+I` |
| Toggle Terminal | `` Ctrl+` `` | `` Cmd+` `` |
