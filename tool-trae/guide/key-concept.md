# Key Concept

## Purpose

แนวคิดหลักของ Trae IDE

## What is Trae?

Trae (The Real AI Engineer) เป็น AI-powered code editor ที่พัฒนาโดย ByteDance ผู้สร้าง TikTok ถูกออกแบบมาเพื่อทำให้การเขียนโค้ดเร็วขึ้นและฉลาดขึ้นด้วย AI

## Core Philosophy

| Concept | Description |
|---------|-------------|
| **Builder Mode** | วางแผนก่อนเขียนโค้ด แยก task เป็นขั้นตอนชัดเจน |
| **Team-like** | ทำงานเหมือน teammate ที่เข้าใจ project ของคุณ |
| **Free Access** | เข้าถึง Claude 3.5 Sonnet และ 3.7 ได้ฟรี |
| **VS Code Base** | สร้างบนพื้นฐาน VS Code ทำให้คุ้นเคยง่าย |

## Key Distinctions from Other AI IDEs

| Feature | Trae | Others |
|---------|------|--------|
| **Pricing** | ฟรีทั้งหมด (early access) | Free tier จำกัด |
| **Models** | Claude 3.5/3.7 ฟรี | Premium models เสียเงิน |
| **Builder Mode** | Planning-first approach | Direct execution |
| **MCP Support** | รองรับ MCP | ไม่ทุกตัว |
