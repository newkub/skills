# tool-trae

แนวทางการใช้งาน Trae IDE - AI-powered code editor จาก ByteDance

## Overview

Trae (The Real AI Engineer) เป็น AI-powered code editor ที่พัฒนาโดย ByteDance ผู้สร้าง TikTok มาพร้อม Builder Mode สำหรับ planning-first development และ free access ไปยัง Claude 3.5 Sonnet และ Claude 3.7

## Key Features

| Feature | Description |
|---------|-------------|
| **Builder Mode** | Planning-first approach สำหรับ complex tasks |
| **Free AI Models** | Claude 3.5 Sonnet และ 3.7 ฟรี |
| **Chat Interface** | Dual modes: General chat และ Inline chat |
| **MCP Support** | เชื่อมต่อกับ external tools รวมถึง Figma |
| **VS Code Base** | ใช้ VS Code extensions ได้ |
