# Features

## Core Features

### Project Management

- `wrangler init` - Create new Worker project
- `wrangler dev` - Local development server
- `wrangler deploy` - Deploy to Cloudflare
- `wrangler delete` - Delete Worker

### Storage Services

- **KV** - Global key-value storage
- **R2** - S3-compatible object storage
- **D1** - SQLite database
- **Queues** - Message queue for async tasks

### Advanced Features

- **Durable Objects** - Stateful coordination
- **Vectorize** - Vector database for AI
- **Workers AI** - Run AI models on edge
- **Hyperdrive** - Accelerated database connections

### Development Tools

- **Hot Reload** - Auto-reload on file changes
- **Remote Development** - Use production resources locally
- **Type Generation** - Auto-generate TypeScript types
- **Secrets Management** - Secure environment variables

### Deployment Options

- **Workers.dev** - Free subdomain
- **Custom Domains** - Use your own domain
- **Routes** - Pattern-based routing
- **Cron Triggers** - Scheduled tasks

### Observability

- **Real-time Logs** - `wrangler tail`
- **Analytics** - Usage metrics
- **Error Tracking** - Built-in error monitoring
- **Performance Monitoring** - Execution metrics

## Platform Integration

- **Pages** - Static site deployment
- **Zero Trust** - Security integration
- **Email Routing** - Email handling
- **WebSockets** - Real-time communication
