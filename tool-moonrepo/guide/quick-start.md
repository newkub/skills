# Quick Start

## Installation

```bash
# Install moon globally
npm install -g @moonrepo/cli

# Or use npx
npx @moonrepo/cli init
```

## Initialize Workspace

```bash
moon init
```

## Run Tasks

```bash
# Run a task
moon run build

# Run task in specific project
moon run :build

# Run in all projects
moon run build --all
```
