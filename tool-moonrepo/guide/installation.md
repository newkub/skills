# Installation

## Installation Command

```bash
# npm
npm install -g @moonrepo/cli

# pnpm
pnpm add -g @moonrepo/cli

# yarn
yarn global add @moonrepo/cli

# bun
bun add -g @moonrepo/cli
```

## Verify Installation

```bash
moon --version
```

## Requirements

| Requirement | Version |
|-------------|---------|
| Node.js | 16+ |
| Rust | Latest (for building from source) |
