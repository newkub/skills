# tool-moonrepo

## Overview

แนวทางการใช้งาน moonrepo สำหรับ monorepo management และ task running

## What is Moonrepo?

moonrepo เป็น build system สำหรับ monorepos ที่เขียนด้วย Rust พร้อม native toolchain, smart hashing และ remote caching
