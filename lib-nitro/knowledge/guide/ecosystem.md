# Ecosystem

## Integrations

- **Nuxt** - Nitro เป็น server engine ของ Nuxt
- **Vite** - ใช้ Vite สำหรับ development
- **Cloudflare** - Deploy ไปยัง Cloudflare Workers
- **Vercel** - Deploy ไปยัง Vercel Edge Functions
- **Node.js** - Deploy ไปยัง Node.js servers

## Presets

Nitro มี presets สำหรับ deployment:
- **vercel-edge** - Vercel Edge Functions
- **cloudflare** - Cloudflare Workers
- **node** - Node.js servers
- **netlify** - Netlify Functions
- **azure** - Azure Functions
