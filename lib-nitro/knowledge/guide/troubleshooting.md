# Troubleshooting

## Common Issues

### Build Errors

- **Module Not Found** - ตรวจสอบ imports และ paths
- **Type Errors** - ตรวจสอบ TypeScript configuration
- **Compilation Errors** - ตรวจสอบ syntax และ dependencies

### Runtime Errors

- **404 Errors** - ตรวจสอบ route definitions
- **500 Errors** - ตรวจสอบ error handling
- **Timeout Errors** - ตรวจสอบ timeout settings

### Deployment Issues

- **Platform Errors** - ตรวจสอบ platform compatibility
- **Environment Variables** - ตรวจสอบ env vars ใน deployment
- **Build Size** - optimize bundle size
