# All Features

## Core Features

| Feature | Description |
|---------|-------------|
| **High Performance** | 50-100x faster than ESLint, built for large repositories and CI |
| **800+ Rules** | Extensive ruleset with ESLint compatibility including TypeScript, React, Jest, Vitest, Import, Unicorn, jsx-a11y |
| **Type-aware Linting** | Uses tsgo (TypeScript Go port) for full TypeScript compatibility and type system behavior |
| **Multi-file Analysis** | Project-wide module graph for cross-file checks like import/no-cycle |
| **ESLint Compatible** | Compatible with ESLint v8 configuration format (.oxlintrc.json) |
| **AI-friendly Diagnostics** | Structured diagnostics with precise spans and contextual data for AI understanding |

## Advanced Features

| Feature | Description |
|---------|-------------|
| **Correctness-focused Defaults** | Prioritizes high-signal correctness checks out of the box |
| **Migration Support** - @oxlint/migrate tool for automatic ESLint config migration |
| **Incremental Adoption** - eslint-plugin-oxlint to disable overlapping ESLint rules during transition |
| **Framework Support** - Supports .vue, .svelte, .astro by linting <script> blocks |
| **JS Plugins** - Custom JS plugins compatible with ESLint plugin ecosystem |
| **Reliability Priority** - Crashes and performance regressions treated as top priority bugs |

## Supported Languages

- JavaScript (.js, .mjs, .cjs)
- TypeScript (.ts, .mts, .cts)
- JSX (.jsx)
- TSX (.tsx)
- Framework files (.vue, .svelte, .astro)
