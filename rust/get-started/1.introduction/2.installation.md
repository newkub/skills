# Rust Installation

## System Requirements

### Supported Platforms

- Windows 10+ (x64)
- macOS 10.7+ (x64)
- Linux (x64, ARM64)
- FreeBSD (x64)

### Minimum Requirements

- 1GB RAM
- 1GB disk space
- Internet connection for initial setup

## Installation Methods

### Rustup (Recommended)

Install Rust using rustup, the official Rust toolchain installer:

```bash
# Unix-like systems
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh

# Windows (PowerShell)
Invoke-WebRequest -Uri https://win.rustup.rs/x86_64 -OutFile rustup-init.exe
.\rustup-init.exe
```

### Package Managers

#### Windows

```powershell
# Chocolatey
choco install rust

# Scoop
scoop install rustup
```

#### macOS

```bash
# Homebrew
brew install rust
```

#### Linux

```bash
# Ubuntu/Debian
sudo apt install rustc cargo

# Fedora
sudo dnf install rust cargo

# Arch Linux
sudo pacman -S rust
```

## Verification

### Check Installation

```bash
# Check Rust compiler version
rustc --version

# Check Cargo version
cargo --version

# Check rustup version
rustup --version
```

### Test Installation

```bash
# Create test project
cargo new hello_world
cd hello_world

# Run test
cargo run
```

## Configuration

### Default Toolchain

```bash
# Install stable toolchain
rustup install stable

# Set as default
rustup default stable

# List installed toolchains
rustup toolchain list
```

### Components

```bash
# Install additional components
rustup component add rustfmt
rustup component add clippy
rustup component add rust-src

# List available components
rustup component list --installed
```

## Environment Variables

### Common Variables

```bash
# Set Rust home directory
export RUSTUP_HOME="$HOME/.rustup"

# Set Cargo home directory
export CARGO_HOME="$HOME/.cargo"

# Add to PATH
export PATH="$CARGO_HOME/bin:$PATH"
```

### Cross-Compilation

```bash
# Install target for cross-compilation
rustup target add x86_64-unknown-linux-musl
rustup target add x86_64-pc-windows-gnu
rustup target add wasm32-unknown-unknown
```

## Troubleshooting

### Common Issues

#### Permission Errors (Linux/macOS)

```bash
# Fix permissions
sudo chown -R $USER:$(id -gn $USER) ~/.cargo ~/.rustup
```

#### Network Issues

```bash
# Use offline mode
cargo install --offline crate_name

# Use custom registry
export CARGO_REGISTRIES_CRATES_IO_PROTOCOL="sparse"
```

#### Path Issues

```bash
# Reload shell configuration
source ~/.bashrc  # or ~/.zshrc

# Verify PATH
echo $PATH | grep cargo
```

### Clean Installation

```bash
# Remove existing installation
rustup self uninstall

# Remove remaining files
rm -rf ~/.cargo ~/.rustup

# Reinstall
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
```
