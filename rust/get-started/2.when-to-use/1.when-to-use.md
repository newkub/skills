# When to Use Rust

## System Programming

Use Rust for operating systems development. Build device drivers and kernel modules. Create system utilities and tools.

## Web Development

Choose Rust for high-performance web services. Build backend APIs with frameworks. Create microservices with Actix or Axum.

## Embedded Systems

Develop firmware for microcontrollers. Program IoT devices efficiently. Build real-time systems with memory safety.

## Command Line Tools

Create fast and reliable CLI applications. Build cross-platform utilities. Develop package managers and dev tools.

## Game Development

Use Rust for game engines. Build high-performance game logic. Create tools for game development.

## Blockchain and Cryptocurrency

Develop secure blockchain applications. Build smart contracts efficiently. Create cryptocurrency wallets.

## Data Processing

Process large datasets efficiently. Build data pipelines with safety. Create analytics tools.

## Networking

Build network servers and clients. Create protocol implementations. Develop distributed systems.

## When Not to Use Rust

Avoid for quick prototypes. Don't use for simple scripts. Consider other languages for web frontends.

## Decision Factors

Consider performance requirements. Evaluate safety needs. Assess team expertise. Think about ecosystem support.
