# Performance in Rust

## Overview

Rust provides zero-cost abstractions. It offers performance comparable to C/C++. It maintains memory safety while preventing bugs.

## Key Concepts

### Zero-Cost Abstractions

- Abstractions compile to efficient code
- No runtime overhead for safety
- Optimizations preserve safety guarantees
- Performance matches hand-written code

### Memory Layout

- Use stack for local variables
- Use heap for dynamic data
- Ensure contiguous memory for cache locality
- Enable zero-copy operations when possible

### Compiler Optimizations

- Use LLVM backend for advanced optimizations
- Enable link-time optimization (LTO)
- Use profile-guided optimization (PGO)
- Leverage auto-vectorization

### Concurrency Performance

- Achieve fearless concurrency without data races
- Use lock-free data structures
- Implement async/await for non-blocking I/O
- Utilize thread pools and work-stealing

## Examples

### Efficient String Handling

```rust
fn process_strings_efficiently() {
    // Avoid unnecessary allocations
    let text = "Hello, world!";

    // Use &str when possible (no allocation)
    let words: Vec<&str> = text.split_whitespace().collect();

    // Use String::with_capacity to pre-allocate
    let mut result = String::with_capacity(100);
    for word in words {
        result.push_str(word);
        result.push(' ');
    }

    println!("Result: {}", result);
}
```

### Zero-Copy Operations

```rust
use std::borrow::Cow;

fn process_data(input: &str) -> Cow<str> {
    if input.is_ascii() {
        // No allocation needed
        Cow::Borrowed(input)
    } else {
        // Allocate only when necessary
        Cow::Owned(input.to_uppercase())
    }
}
```

### Memory-Efficient Data Structures

```rust
// Use Vec<T> for contiguous memory
struct Point {
    x: f64,
    y: f64,
}

fn process_points() {
    // Contiguous memory layout for better cache performance
    let mut points = Vec::with_capacity(1000);
    for i in 0..1000 {
        points.push(Point { x: i as f64, y: i as f64 });
    }

    // Iterator-based processing
    let sum: f64 = points.iter().map(|p| p.x + p.y).sum();
    println!("Sum: {}", sum);
}
```

### Async Performance

```rust
use tokio::time::{sleep, Duration};

async fn fetch_data_concurrently() {
    let futures = vec![
        fetch_data("source1"),
        fetch_data("source2"),
        fetch_data("source3"),
    ];

    // Run all futures concurrently
    let results = futures::future::join_all(futures).await;

    for result in results {
        println!("Fetched: {}", result);
    }
}

async fn fetch_data(source: &str) -> String {
    sleep(Duration::from_millis(100)).await;
    format!("Data from {}", source)
}
```

## Performance Best Practices

1. Prefer stack allocation over heap
2. Use iterators for zero-cost loops
3. Avoid unnecessary allocations
4. Pre-allocate with with_capacity()
5. Leverage SIMD auto-vectorization
6. Use async for I/O operations
7. Profile before optimizing

### Compiler Optimizations

#### Release Profile

```toml
# Cargo.toml
[profile.release]
lto = true           # Link-time optimization
codegen-units = 1    # Better optimization
panic = "abort"      # Smaller binary
strip = true         # Remove debug symbols
```

#### Benchmarking

```rust
use std::time::Instant;

fn benchmark_function() {
    let start = Instant::now();

    // Code to benchmark
    let result = expensive_computation();

    let duration = start.elapsed();
    println!("Computation took: {:?}", duration);
    println!("Result: {}", result);
}

fn expensive_computation() -> i64 {
    (1..=1_000_000).sum()
}
```
