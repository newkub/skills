Instructions for building Vite plugins:

1. Use tsdown for building libraries that use Node.js built-in modules
2. Every plugin should have 'w' prefix (e.g., wlinter, wformatter)
3. Follow the project structure rules in rules/project-structure.md
4. Follow the package.json rules in rules/package-json.md
