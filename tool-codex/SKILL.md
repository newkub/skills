# codex

## วัตถุประสงค์

Codex เป็น coding agent จาก OpenAI ที่ทำงานบนเครื่องคอมพิวเตอร์ของคุณ ช่วยในการเขียนโค้ด ทำความเข้าใจ codebase ตรวจสอบโค้ด แก้ไขบัก และทำให้งานพัฒนาซอฟต์แวร์เป็นไปโดยอัตโนมัติ
