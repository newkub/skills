## When to use

- เมื่อต้องการ coding agent ที่ทำงานบนเครื่องคอมพิวเตอร์
- เมื่อต้องการทำความเข้าใจ codebase อัตโนมัติ
- เมื่อต้องการตรวจสอบโค้ดและแก้ไขบัก
- เมื่อต้องการทำให้งานพัฒนาซอฟต์แวร์เป็นไปโดยอัตโนมัติ
