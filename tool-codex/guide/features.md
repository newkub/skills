# Features

## Core Features

| Feature | Description |
|---------|-------------|
| **Code Generation** | สร้างโค้ดจากคำอธิบาย รองรับหลายภาษา |
| **Code Understanding** | อ่านและอธิบายโค้ดที่ซับซ้อน |
| **Code Review** | วิเคราะห์โค้ดหาบักและข้อผิดพลาด |
| **Debug Assistance** | ช่วยตรวจหาและแก้ไขปัญหา |
| **Task Automation** | ทำงานซ้ำๆ โดยอัตโนมัติ |

## Development Features

| Feature | Description |
|---------|-------------|
| **Git Integration** | ทำงานกับ Git repository ได้ |
| **File Operations** | อ่าน เขียน แก้ไข ลบไฟล์ |
| **Terminal Commands** | รันคำสั่งใน terminal |
| **Project Context** | เข้าใจโครงสร้างโปรเจกต์ |
| **Multi-file Editing** | แก้ไขหลายไฟล์พร้อมกัน |

## Platform Features

| Feature | Description |
